# 從 LR2 或 beatoraja 轉移

本頁針對用過 LR2 或 beatoraja 的玩家，介紹如何將歌曲、成績與面板轉移到 BMZ Player。
BMZ Player 不會變更原軟體的檔案，因此轉移後仍可繼續使用 LR2 或 beatoraja。

## 1. 登錄歌曲資料夾

首先，將在 LR2 或 beatoraja 中使用的 BMS 資料夾也登錄到 BMZ Player。
請在 設定 → **曲庫** → **歌曲資料夾（BMS）** 中新增相同的資料夾。
不需要複製歌曲檔案。

**匯入成績前，請等待歌曲讀取完成。**
LR2 的成績會與 BMZ Player 已讀取的譜面比對後匯入，
因此尚未讀取的譜面的成績不會被匯入。

## 2. 匯入成績

在 設定 → **資料匯入** →「匯入成績」中匯入。

1. 按「選擇檔案…」，選擇原軟體的成績檔案。

   | 原軟體 | 要選擇的檔案 |
   | --- | --- |
   | LR2 | `LR2files/Database/Score/<玩家名稱>.db` |
   | beatoraja | `player/<玩家名稱>/score.db` |
   | LR2oraja | 與 beatoraja 相同位置的 `score.db` |

2. 在右側欄位中選擇原軟體的類型。
3. 在「輸入裝置」中選擇這些成績是用鍵盤還是控制器取得的。
4. 按「匯入」。

會顯示匯入的筆數與無法匯入的筆數。

想把匯入的成績也登錄到 IR 時，請先依[參加網路排名（IR）](02-setup.md)登入，再使用 設定 → **IR** 中的「批次傳送本機成績」。

### 看不到匯入的成績時

BMZ Player 會依規則（判定與血條的機制）分別儲存成績。
匯入的成績會依原軟體儲存到以下規則：

| 原軟體 | 儲存的規則 |
| --- | --- |
| beatoraja | beatoraja |
| LR2、LR2oraja | LR2oraja |
| LR2oraja（DX Mode） | DX MODE |

選曲畫面中看不到成績時，請確認 設定 → **遊玩** 的「規則」是否為匯入時的規則。
關於規則，請參閱[遊玩選項](05-play-options.md)。

## 3. 匯入重播（beatoraja）

也可以匯入 beatoraja 的重播。
在 設定 → **資料匯入** 中將上方的切換改為「匯入重播」，
然後指定 beatoraja 的 `player/<玩家名稱>` 資料夾、`replay` 資料夾或單一 `.brd` 檔案進行匯入。

## 4. 轉移面板

在 beatoraja 中使用的面板可以直接在 BMZ Player 中使用。

1. 按 設定 → **外觀** →「開啟額外面板資料夾」。
2. 從 beatoraja 的 `skin` 資料夾中整個複製所用的面板資料夾。
   如果面板使用了其他資料夾中的字型或圖片，也請一併複製。
3. 按「重新整理面板清單」，再從左側選擇畫面，從右側選擇面板。

面板選項不會被轉移，請視需要重新設定。

## 5. 重新檢查設定

按鍵指派、流速與判定時機不會被轉移。
請參閱[初始設定](02-setup.md)中的「設定按鍵與控制器」以及[判定時機與延遲調整](06-timing.md)進行設定。

### 與 LR2、beatoraja 的主要差異

- 設定集中在按 **F1** 開啟的設定視窗中。沒有啟動器。
- 流速有 5 種方式。想以與 LR2 或 beatoraja 相同的感覺遊玩時，請參閱[遊玩選項](05-play-options.md)了解如何選擇。
- 可以選擇將長條音符作為 LN、CN 還是 HCN 遊玩。成績依 LN 類型分別儲存。
