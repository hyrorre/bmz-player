# 遊玩選項

本頁介紹改變遊玩難度與顯示方式的選項。
選項可以在選曲畫面按 **E1** 等顯示的選項畫面中變更，也可以在 設定 → **遊玩** 中變更。

不確定時，直接使用初始設定開始遊玩也沒有問題。

## 血條

血條是表示遊玩狀態的計量條。判定良好時增加，失誤時減少。
不同類型的血條，增減方式與過關條件各不相同。

| 血條 | 特點 |
| --- | --- |
| ASSIST EASY | 最不容易減少的血條。過關也會被視為比 EASY 低的紀錄 |
| EASY | 比 NORMAL 更不容易減少的血條 |
| NORMAL | 標準的血條 |
| HARD | 從滿值開始，歸零時立即結束（失敗） |
| EX-HARD | 比 HARD 更容易減少的血條 |
| HAZARD | 連擊中斷即失敗 |

ASSIST EASY、EASY、NORMAL 在歌曲結束時血條達到過關線以上即為過關。
HARD、EX-HARD、HAZARD 只要中途不失敗、玩到最後即為過關。

初次遊玩建議從 NORMAL 開始，難以過關的歌曲建議使用 EASY 或 ASSIST EASY。

### 血條自動切換（GAS）

失敗時切換到其他血條繼續遊玩的功能。初始為 OFF。

| 方式 | 內容 |
| --- | --- |
| OFF | 不切換。在 HARD 等血條下失敗時立即結束 |
| CONTINUE | 即使失敗也能玩到歌曲結束。紀錄仍為所選血條 |
| HARD->GROOVE | 在 HARD 等血條下失敗時，切換為 NORMAL 繼續遊玩 |
| BEST CLEAR | 同時計算所有血條，記錄已過關血條中最高的一種 |
| SELECT UNDER | 同時計算所選血條及以下的血條，記錄已過關血條中最高的一種 |

例如在 BEST CLEAR 下，即使中途無法滿足 EX-HARD 的條件，只要以 HARD 或 NORMAL 過關，該紀錄仍會保留。
可以用「GAS 最低血條」決定最低記錄到哪一種血條。

## 排列（RANDOM 等）

改變落到各按鍵上的音符排列。同一譜面也能以不同排列練習。

| 排列 | 內容 |
| --- | --- |
| OFF | 依譜面原樣落下 |
| MIRROR | 左右翻轉 |
| RANDOM | 每次遊玩隨機交換軌道排列 |
| R-RANDOM | 保持軌道順序，整體橫向平移 |
| S-RANDOM | 將每個音符隨機分配到軌道 |
| SPIRAL | 讓軌道排列逐漸像旋轉一樣變化 |
| H-RANDOM | 與 S-RANDOM 相同，但避免同一軌道在短時間內連續出現音符 |
| ALL-SCR | 盡可能將音符集中到轉盤 |
| RANDOM-EX / S-RANDOM-EX | 連同轉盤一起交換 |
| F-RANDOM | 將按鍵分為左半與右半，分別在各自範圍內交換排列。7 鍵時中間的按鍵不動 |
| MF-RANDOM | 在 F-RANDOM 的排列基礎上再左右翻轉 |

S-RANDOM 等逐個分配音符的排列，可能使譜面與原本形狀差異很大。

## 流速

音符落下的速度。加快後音符間距變大、更容易看清，但反應時間會變短。
遊玩中可以用 **← / →** 鍵，或 **按住 E1 + 按鍵** 變更。

### 綠色數字

表示音符從畫面上方出現到抵達判定線所需時間的數字。
數值為毫秒數的 0.6 倍，例如綠色數字 300 為 0.5 秒。數字越小，看起來越快。
即使 BPM 不同，只要綠色數字相同，看起來的速度就相同。

### 流速方式（HS 設定）

| 方式 | 內容 |
| --- | --- |
| NORMAL | 從 20 個段數中選擇。每個段數對應固定的綠色數字 |
| CLASSIC | 直接指定倍率。與 LR2 與 beatoraja 的一般流速相同 |
| FLOATING | 指定綠色數字後，依歌曲的 BPM 自動決定倍率 |
| NORMAL+FLOATING | 遊玩中可以在 NORMAL 與 FLOATING 之間切換 |
| CLASSIC+FLOATING | 遊玩中可以在 CLASSIC 與 FLOATING 之間切換（初始設定） |
| LR2 | 與 CLASSIC 一樣直接指定倍率（倍率與 CLASSIC 共用）。使用 HS-FIX 時，倍率表示 BPM 150 時的速度（與 LR2 相同） |

在可切換的方式中，遊玩時 **同時按 E1 與 E2** 即可切換。
使用 FLOATING 時，**按住 E2 + 按鍵或轉盤** 可變更綠色數字。

如果不想每首歌都重新調整速度，FLOATING 會很方便。

### HS-FIX

歌曲中途 BPM 變化時，選擇以哪個 BPM 為基準決定速度。
例如設為「最大 BPM」時，會以歌曲中最快的部分為準決定速度。

## 軌道遮罩

遮住軌道的一部分，調整音符可見的範圍。
可用於讓快速的音符更容易看清，或讓可見位置與視線高度一致。

| 類型 | 內容 |
| --- | --- |
| SUDDEN+ | 遮住軌道上方 |
| HIDDEN+ | 遮住軌道下方（判定線附近） |
| LIFT | 將判定線往上抬高 |

要使用的遮罩需在 設定 → **遊玩** 的「顯示」中依按鍵數分別啟用。
遊玩中用 **↑ / ↓** 鍵或 **按住 E1 + 轉盤** 調整遮擋量。
**連按兩次 E1** 可以顯示或隱藏 SUDDEN+。

開啟「軌道遮罩變更時依目前 BPM 自動調整 HS」後，移動遮罩時會調整流速，使綠色數字維持不變。

## LN 模式

選擇長按音符（長條音符）的判定方式。

| 類型 | 內容 |
| --- | --- |
| LN | 只判定按下的時機，不判定放開的時機 |
| CN | 同時判定按下與放開的時機 |
| HCN | 與 CN 一樣兩者都判定，按住期間血條也會增減 |

帶有「AUTO」的設定中，譜面指定了類型時依譜面，未指定時依所選類型遊玩。
帶有「FORCE」的設定中，不論譜面如何指定，都依所選類型遊玩。

也可以在選曲畫面按 **3** 鍵切換。成績依 LN 模式分別儲存。

## 規則

一併切換判定範圍、血條與分數計算方式。成績依規則分別儲存。

| 規則 | 內容 |
| --- | --- |
| beatoraja | 與 beatoraja 相同的規則（初始設定） |
| LR2oraja | 接近 LR2 的規則。與 LR2oraja Endless Dream 的行為相同 |
| DX MODE | 與 LR2oraja Endless Dream 的 DX MODE 相同的規則 |

查看從 LR2 或 beatoraja 匯入的成績時，請切換為匯入時的規則。

## 輔助

放寬判定、提前顯示 BPM 變化等輔助遊玩的功能。
在選曲畫面按住 **E2** 時顯示的畫面中設定。

輔助功能生效的遊玩中，即使過關也會記為 ASSIST，且不儲存分數、不送出到 IR。
不過，顯示可判定範圍（JUDGE AREA）、標記追加音符（MARK NOTE）等僅改變顯示的功能不會影響紀錄。
此外，像在 BPM 不變的譜面上使用 BPM GUIDE 這樣沒有生效的輔助功能，也不會影響紀錄。

## 目標

選擇遊玩中與自己分數比較的對象。
可以從 AAA 等評級目標值、IR 高分、對手的分數等中選擇。

## 遊玩類型

| 類型 | 內容 |
| --- | --- |
| NORMAL | 一般遊玩 |
| PRACTICE | 指定區間與速度進行練習。不儲存成績 |
| AUTOPLAY | 自動演奏。不儲存成績 |
| AUTOPLAY BATTLE | 在對戰畫面中自動演奏。不儲存成績 |
| G-BATTLE | 以已儲存的重播或 IR 成績為對手進行對戰 |

## 不儲存成績的情況

以下遊玩不會儲存成績、過關紀錄與重播，也不會送出到 IR：

- 自動演奏、重播播放、練習
- 轉換了按鍵數的遊玩（如以 9 鍵玩 7 鍵譜面）

輔助功能生效的遊玩只儲存 ASSIST 過關紀錄。
