# 基本操作

本頁介紹選曲畫面、遊玩畫面與結算畫面的主要操作。
按鍵以初始指派為準。指派可以在 設定 → **按鍵設定** 中變更。

表中的 KEY1～KEY7 是從左數起的 7 鍵按鍵編號，E1～E4 是輔助按鈕。
初始指派中，KEY1～KEY7 為 **Z S X D C F V**，E1～E4 為 **Q W E R**。

## 所有畫面通用的操作

| 按鍵 | 操作 |
| --- | --- |
| F1 | 開啟或關閉 BMZ 選單（設定與工具） |
| F12 | 儲存螢幕截圖 |

## 選曲畫面

### 選擇歌曲

| 按鍵 | 操作 |
| --- | --- |
| ↑ / ↓、轉盤 | 移動游標 |
| PageUp / PageDown | 逐頁移動 |
| Enter、→、KEY1・KEY3・KEY5・KEY7 | 決定（開啟資料夾、開始歌曲） |
| ←、KEY2・KEY4・KEY6 | 關閉資料夾 |
| / | 搜尋歌曲 |
| Esc | 開啟 BMZ 選單時關閉選單，在資料夾中時關閉資料夾 |
| Esc（在最上層長按） | 結束 BMZ Player |

也可以用滑鼠操作。捲動滾輪移動游標，點擊選取中的列即可決定，按右鍵關閉資料夾。

### 變更列表顯示

| 按鍵 | 操作 |
| --- | --- |
| 0 | 依難度篩選 |
| 1 | 依按鍵數篩選（7K、14K、9K 等） |
| 2 | 變更排序方式 |
| 3 | 切換 LN 模式 |
| F8 / F9 | 將歌曲或譜面加入 / 移出最愛 |
| F5 | 重新讀取所選資料夾（在難度表中則重新取得難度表） |

### 變更選項

按住 **E1** 時會顯示選項畫面。按住的同時按下按鍵即可變更設定。

| 按鍵 | 按住 E1 時 |
| --- | --- |
| KEY1 / KEY2 | 切換排列（RANDOM 等） |
| KEY3 / KEY4 | 切換血條 |
| KEY5 | 切換 HS-FIX |
| KEY6 | 切換 DP 選項 |
| KEY7 | 切換遊玩類型（一般、練習、自動演奏等） |
| 轉盤、↑ / ↓ | 切換目標（用來比較分數的對象） |

按住 **E2** 時顯示輔助選項，同時按住 **E1 與 E2** 時顯示其他詳細選項。
顯示與操作可能因面板而異。各選項的意義請參閱[遊玩選項](05-play-options.md)。

### 其他操作

| 按鍵 | 操作 |
| --- | --- |
| F3 | 開啟所選譜面檔案的位置 |
| F10 | 以自動演奏播放所選資料夾中的歌曲 |
| F11 | 在瀏覽器中開啟所選譜面的 IR 頁面 |
| 4 / 5 | 選擇 / 播放已儲存的重播 |
| 6 | 開啟按鍵設定 |
| 9 | 開啟歌曲隨附的文字檔 |

## 遊玩畫面

| 按鍵 | 操作 |
| --- | --- |
| ← / → | 降低 / 提高流速 |
| ↑ / ↓ | 移動軌道遮罩（SUDDEN+ 等） |
| 按住 E2 + ↑ / ↓ | 小幅移動軌道遮罩 |
| 滑鼠滾輪 | 移動軌道遮罩（按住 E2 時小幅移動） |
| 按住 E1 + 按鍵 | 變更流速 |
| 按住 E1 + 轉盤 | 移動軌道遮罩 |
| 按住 E2 + 按鍵或轉盤 | 變更綠色數字（可使用 FLOATING 時） |
| 連按兩次 E1 | 顯示 / 隱藏 SUDDEN+ |
| 同時按 E1 與 E2 | 切換流速方式（FLOATING 等） |
| 3 / 9 | 以 1 毫秒為單位調整顯示時機 |
| 0 | 開啟 / 關閉自動判定調整 |
| Esc | 結束遊玩 |
| 長按 E1 與 E2 | 結束遊玩 |

中途失敗（血條歸零而結束）時，在演出過程中按 **E1** 可用新的排列、按 **E2** 可用相同排列立即重試。

流速與綠色數字請參閱[遊玩選項](05-play-options.md)，顯示時機請參閱[判定時機與延遲調整](06-timing.md)。

### 自動演奏、重播播放中

按住上排數字鍵 **1 / 2 / 3 / 4** 時，播放速度會變為 25% / 50% / 200% / 300%。放開後恢復原速。

## 結算畫面

| 按鍵 | 操作 |
| --- | --- |
| Enter、Esc、KEY1～KEY4 | 返回選曲畫面 |
| R | 以相同排列再玩一次 |
| 按住 KEY7 等待 | 以相同排列再玩一次 |
| 按住 KEY5 等待 | 以新的排列再玩一次 |
| KEY6 | 切換血條圖表的顯示 |
| 1 / 2 / 3 / 4 | 將重播儲存到槽位 1～4 |
| F11 | 在瀏覽器中開啟所玩譜面的 IR 頁面 |

在支援的面板中，可以用 **E2** 切換 IR 排名與圖表的顯示。

## 課程

在第2首或之後的歌曲開始前結束遊玩，會僅彙整已完成的歌曲並顯示FAILED課程結算。未開始歌曲的遊玩次數不會增加。在第1首開始前結束則返回選曲畫面。
歌曲之間的結算畫面中，R、KEY5和KEY7也用於進入下一首。從最終課程結算重試會從第1首重新開始。如果無法確認譜面而導致重試失敗，會保留原結算並顯示錯誤。
課程中無法在失敗演出期間快速重試。

## 練習

在選曲畫面將遊玩類型設為練習並決定歌曲後，會開啟練習用的設定畫面。
可以指定要練習的區間、血條、播放速度（50～200%）等，反覆練習同一區間。
練習的成績不會儲存。

| 按鍵 | 操作 |
| --- | --- |
| ↑ / ↓ | 選擇項目 |
| ← / → | 變更數值 |
| Enter | 開始區間遊玩 |
| Esc | 返回選曲畫面 |
