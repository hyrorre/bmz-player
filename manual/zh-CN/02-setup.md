# 初始设置

本页介绍从下载 BMZ Player 到游玩第一首歌曲的步骤。
请从上到下依次进行。已经设置好的项目可以跳过。

## 1. 下载 BMZ Player

从 [GitHub Releases](https://github.com/hyrorre/bmz-player/releases) 下载适合所用操作系统的文件。

| 操作系统 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `...-windows-x64-setup.exe` | 安装程序。不确定时请选择此项 |
| Windows | `...-windows-x64-portable.zip` | 解压即可使用的版本。设置和成绩保存在解压后文件夹的 `data` 中 |
| macOS（Apple 芯片） | `...-macos-arm64.app.zip` | 适用于 M1 及更新的 Mac |
| macOS（Intel） | `...-macos-x64.app.zip` | 适用于 Intel 处理器的 Mac |
| Linux | `...-linux-x64.tar.gz` | 解压后运行 `./bmz-player` |
| Linux | `...-linux-x64.flatpak` | Flatpak 版 |

`sources`、`SHA256SUMS` 等文件仅在游玩时不需要。

### 运行环境

- **Windows**：Windows 10 及以上
- **macOS**：macOS 10.13 及以上
- **Linux**：相当于 Ubuntu 22.04 及以上的 x86_64 环境。需要支持 Vulkan 的显卡驱动。

### macOS 提示“无法打开”时

BMZ Player 未经过 Apple 公证，首次打开时可能出现警告。
请将解压得到的 `.app` 移动到“应用程序”等文件夹后，
按照 [Apple 的说明](https://support.apple.com/zh-cn/102445)打开。

## 2. 启动并确认画面

启动 BMZ Player 后会显示选曲画面。
其中已附带 1 首用于确认运行的示例歌曲，可以选择并试玩。

- 用 **↑ / ↓** 移动光标，**Enter** 决定，**←** 关闭文件夹。
- 7 键时，按键为 **Z S X D C F V**，转盘为 **左 Shift / 左 Ctrl**。
- 要退出时，请在选曲画面的最上层长按 **Esc**。在文件夹中时，每按一次 Esc 关闭一层文件夹。

设置可以在按 **F1** 打开的“BMZ 菜单”中更改。
从左侧列表选择项目，右侧会显示对应的设置。
设置更改后会自动保存，无需按保存按钮。

## 3. 登记歌曲文件夹

确定存放 BMS 的文件夹，并登记到 BMZ Player。

1. 在电脑的任意位置创建存放 BMS 的文件夹（例如 `D:\BMS`）。
2. 将下载的歌曲放入该文件夹。每首歌曲放在一个文件夹中。也可以按类型等分成多层。
3. 在 设置 → **曲库** → **歌曲文件夹（BMS）** 中按“选择文件夹…”，选择刚才创建的文件夹并添加。

添加的文件夹会自动读取，歌曲会显示在选曲画面中。
之后增加歌曲时，请在选曲画面选择该文件夹并按 **F5**，
或者按 设置 → 曲库 →“重新扫描曲库”。

### 获取歌曲的途径

- **BMS 搜索网站**：可以按曲名或作者名查找发布页面。
- **BMS 活动**：可以从 BMS OF FIGHTERS（BOF）等活动的会场页面一次下载参赛作品。
- **难度表**：也可以通过下一步介绍的难度表，查找想玩的难度的歌曲。

有些歌曲还会另外发布称为“差分”的追加谱面。
将差分放入原歌曲的文件夹后即可选择。

## 4. 使用难度表

难度表是玩家们将 BMS 谱面按难度排列的列表。
BMZ Player 已预先登记了常用的难度表。
打开选曲画面中的“难度表”文件夹，歌曲会按表中的等级排列。

如需使用其他难度表，请在 设置 → **难度表** 中输入难度表的 URL 并添加。

难度表中也会显示尚未拥有的谱面。
选择尚未拥有的谱面并决定后，会在浏览器中打开该谱面的获取页面。
将获取的歌曲放入歌曲文件夹并重新扫描后即可游玩。

## 5. 设置按键和控制器

初始分配如下：

| 操作 | 键盘 |
| --- | --- |
| 7 键的按键 | Z S X D C F V |
| 7 键的转盘 | 左 Shift（上）/ 左 Ctrl（下） |
| 14 键 2P 侧的按键 | M K , L . ; / |
| 14 键 2P 侧的转盘 | 右 Shift / 右 Ctrl |
| 9 键（PMS） | Z S X D C F V G B |
| E1 / E2 / E3 / E4 | Q / W / E / R |

E1～E4 是相当于 beatoraja 中 START / SELECT 的辅助按钮，用于更改选项等。

要更改分配，请打开 设置 → **按键配置**。

1. 在“对象”中选择要更改的按键数（如 7K）或画面。
2. 在“输入槽位”中选择键盘或控制器。
3. 按下要更改的操作右侧的按钮，再按下要分配的按键或按钮。

按 Esc 取消，按 Delete 或 Backspace 解除分配。
控制器没有反应时，请在 设置 → **输入设备** 中确认是否已连接。

## 6. 确认声音

没有声音或声音中断时，请在 设置 → **音频** 中确认输出位置。

1. 在“输出设备”中选择所用的扬声器或耳机。
2. 按“应用”。音频设置在按“应用”之前不会生效。

声音听起来有延迟时，减小“缓冲区大小”可能会有所改善。
过小会导致声音断断续续，请在不断音的范围内调整。

## 7. 调整判定时机

觉得音符、声音和操作的时机不一致时，请进行调整。
在游玩中按 **0** 键会开启自动判定调整，游玩几首歌后偏差会得到修正。
详情请参阅[判定时机与延迟调整](06-timing.md)。

## 8. 选择皮肤

BMZ Player 附带以下皮肤：

- **m-select**：选曲、决定、结算画面，以及游玩画面（antique、brand-new）
- **Rm-skin**：4 键到 9 键的游玩画面
- **Luxe Flat**：选曲、决定、结算画面

在 设置 → **皮肤** 中选择“目标画面”（选曲、7K 游玩画面等），再选择要使用的皮肤即可更改。
各皮肤提供的选项也可以在同一画面中更改。

### 添加其他皮肤

1. 按 设置 → 皮肤 →“打开附加皮肤文件夹”。
2. 将获取的皮肤整个文件夹放入打开的文件夹中。ZIP 请先解压再放入。
3. 按“刷新皮肤列表”，再为每个画面选择添加的皮肤。

BMZ Player 可以读取 beatoraja 用的皮肤（JSON、Lua）和 LR2 用的皮肤（CSV）。

## 9. 参加网络排名（IR）

参加 IR 后，可以将成绩登记到在线排名，与其他玩家比较。是否参加由你决定。

1. 在 [BMZ IR](https://bmz-player.hyrorre.workers.dev/zh-CN) 中通过“注册”创建账号。
2. 在 BMZ Player 的 设置 → **IR** 中，在 BMZ IR 一栏输入邮箱和密码，按“登录”。

登录后，之后游玩的成绩会自动提交。
BMZ Player 也支持 rianIR 和 BMS-IR，可以在同一画面登录。

### 批量发送与获取过去的成绩

在 设置 → **IR** 的“成绩批量操作”中，可以进行以下操作。

- “批量发送本地成绩”：把保存在这台电脑上的成绩一次性发送到主 IR。想把从 LR2 或 beatoraja 导入的成绩登记到 IR 时使用。
- “从 IR 获取成绩”：把保存在 IR 上的个人成绩导入这台电脑。想让在其他电脑上游玩的成绩保持一致时使用。

按下按钮会打开确认窗口。批量发送时会显示要发送的成绩数量和所需时间的大致参考。确认内容后按“开始”即可开始。

- 成绩较多时，可能需要几分钟到几十分钟以上。进度显示在同一画面，关闭设置窗口后处理仍会继续。
- 可以随时按“中断”停止。再次运行时会从中断处继续。
- 运行期间无法切换配置文件。
- 批量操作只能用于主 IR。批量发送本地成绩仅限 BMZ IR，获取成绩可用于 rianIR 以外的 IR。未登录时无法按下按钮。

完成后会通知结果。

### 查看并重新发送发送失败的成绩

批量操作下方是“IR 发送队列”，列出等待发送、发送中和发送失败的成绩，一开始只显示发送失败的成绩。可以用“显示”切换筛选条件，用“刷新”更新到最新状态。

- 每一行显示类型、谱面、状态、尝试次数、下次重试时间和最后的错误。
- 按失败行的“重新发送”，会立即重新发送该条成绩。
- 按“全部重新发送失败项”，确认后会依次重新发送发送失败的成绩。

发送失败的成绩也会隔一段时间自动重试。网络问题解决后想不等待直接重新发送时，请使用这些按钮。其他处理正在发送的成绩，会在该处理结束后发送。

设置到此完成。操作方法请参阅[基本操作](04-controls.md)。
