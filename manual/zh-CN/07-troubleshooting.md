# 常见问题

本页列出常见的症状和处理方法。如果仍无法解决，请按本页最后的方法反馈。

## 启动与显示

### 无法启动或立即退出

- **Windows**：请将显卡驱动更新到最新版本。较旧的 Windows 可能需要 Vulkan 驱动。
- **macOS**：提示“无法打开”时，请参阅[初始设置](02-setup.md)中的“macOS 提示‘无法打开’时”。
- **Linux**：需要支持 Vulkan 的显卡驱动。tar.gz 版请从解压后文件夹中的 `./bmz-player` 启动。

### 画面卡顿、动作不流畅

请在 设置 → **视频** 中将“帧延迟”设为“稳定”，或将“目标 FPS”设为显示器的刷新率。
关闭其他应用也可能有所改善。

### 皮肤不显示或显示错乱

请在 设置 → **皮肤** 中确认该皮肤是否显示了读取错误。
如果皮肤缺少部分文件夹（字体或图片），将无法正确显示。
请将皮肤整个文件夹按发布时的结构放置。

## 歌曲与难度表

### 歌曲不显示

- 请在 设置 → **曲库** 中确认已登记存放歌曲的文件夹。
- 添加歌曲后，请在选曲画面按 **F5**，或按“重新扫描曲库”。
- 请确认每首歌曲都放在一个文件夹中。谱面文件（.bms 等）和音频文件需要在同一文件夹中。
- 请确认选曲画面中没有开启 **0**（难度）或 **1**（按键数）的筛选。

### 难度表中没有歌曲或难度表没有更新

在选曲画面选择难度表文件夹并按 **F5**，即可重新获取难度表。
即使难度表中列出了谱面，没有该谱面也无法游玩。选择尚未拥有的谱面并决定后，会在浏览器中打开获取页面。

## 声音

### 没有声音

1. 在 设置 → **音频** 的“输出设备”中确认已选择所用设备。
2. 按“刷新设备列表”后重新选择，再按“应用”。
3. 在同一画面的“音量”中确认主音量等没有设为 0。

插拔设备后没有声音时，按“应用”也可能恢复。

### 声音中断或有杂音

请增大 设置 → **音频** 中的“缓冲区大小”。

### 声音听起来有延迟

请参阅[判定时机与延迟调整](06-timing.md)。

## 输入

### 键盘或控制器没有反应

- 请在 设置 → **输入设备** 中确认控制器显示为已连接。
- 请在 设置 → **按键配置** 中确认所玩按键数（如 7K）的分配。不同按键数的分配是分开的。
- 分配旁边显示警告图标时，表示与其他操作分配了相同的按键。

### 转盘反应不灵敏或转动过头

请在 设置 → **输入设备** 中调整“模拟转盘”和“模拟输入灵敏度”。

## 成绩与 IR

### 成绩没有保存

自动演奏、回放播放、练习以及转换了按键数的游玩不保存成绩。
辅助功能生效时只保存 ASSIST 通关记录。

### 看不到导入的成绩或以前的成绩

成绩按规则和 LN 模式的组合分别保存。
请将 设置 → **游玩** 的“规则”和“LN 模式”改回取得该成绩时的设置。

### 成绩没有提交到 IR

- 请在 设置 → **IR** 中确认显示为已登录。
- 未联网期间的成绩会在恢复联网后自动提交。
- 发送失败的成绩可在 设置 → **IR** →“打开发送队列”中查看，并用“重新发送”再次发送。

## 日志与数据的位置

按 **F1** 打开 BMZ 菜单，在“常规”的“打开目录”中用按钮可以打开各文件夹。

| 按钮 | 内容 |
| --- | --- |
| data_dir | 设置、成绩、回放、添加的皮肤 |
| logs_dir | 运行记录（日志） |
| cache_dir | 临时文件。删除后会在需要时重新生成 |
| resource_dir | BMZ Player 附带的文件。更新时会被覆盖 |

备份 data_dir 可以保护设置和成绩。
请在退出 BMZ Player 后再进行备份。

## 反馈问题

请在 [GitHub Issues](https://github.com/hyrorre/bmz-player/issues) 反馈。
提供以下信息有助于查明原因：

- 所用操作系统和 BMZ Player 的版本
- 做了什么操作时发生了什么
- logs_dir 中的日志文件
- 如有需要，附上截图（按 **F12** 保存）
