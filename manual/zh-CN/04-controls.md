# 基本操作

本页介绍选曲画面、游玩画面和结算画面的主要操作。
按键以初始分配为准。分配可以在 设置 → **按键配置** 中更改。

表中的 KEY1～KEY7 是从左数起的 7 键按键编号，E1～E4 是辅助按钮。
初始分配中，KEY1～KEY7 为 **Z S X D C F V**，E1～E4 为 **Q W E R**。

## 所有画面通用的操作

| 按键 | 操作 |
| --- | --- |
| F1 | 打开或关闭 BMZ 菜单（设置从这里打开） |
| F12 | 保存截图 |

## 选曲画面

### 选择歌曲

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓、转盘 | 移动光标 |
| PageUp / PageDown | 按页移动 |
| Enter、→、KEY1・KEY3・KEY5・KEY7 | 决定（打开文件夹、开始歌曲） |
| ←、KEY2・KEY4・KEY6 | 关闭文件夹 |
| / | 搜索歌曲 |
| Esc（长按） | 退出 BMZ Player |

也可以用鼠标操作。滚动滚轮移动光标，点击选中的行即可决定，右键关闭文件夹。

### 更改列表显示

| 按键 | 操作 |
| --- | --- |
| 0 | 按难度筛选 |
| 1 | 按按键数筛选（7K、14K、9K 等） |
| 2 | 更改排序方式 |
| 3 | 切换 LN 模式 |
| F8 / F9 | 将歌曲或谱面加入 / 移出收藏 |
| F5 | 重新读取所选文件夹（在难度表中则重新获取难度表） |

### 更改选项

按住 **E1** 时会显示选项面板。按住的同时按下按键即可更改设置。

| 按键 | 按住 E1 时 |
| --- | --- |
| KEY1 / KEY2 | 切换排列（RANDOM 等） |
| KEY3 / KEY4 | 切换血条 |
| KEY5 | 切换 HS-FIX |
| KEY6 | 切换 DP 选项 |
| KEY7 | 切换游玩类型（普通、练习、自动演奏等） |
| 转盘、↑ / ↓ | 切换目标（用来比较分数的对象） |

按住 **E2** 时显示辅助选项，同时按住 **E1 和 E2** 时显示其他详细选项。
显示和操作可能因皮肤而异。各选项的含义请参阅[游玩选项](05-play-options.md)。

### 其他操作

| 按键 | 操作 |
| --- | --- |
| F3 | 打开所选谱面文件的位置 |
| F10 | 以自动演奏播放所选文件夹中的歌曲 |
| F11 | 在浏览器中打开所选谱面的 IR 页面 |
| 4 / 5 | 选择 / 播放已保存的回放 |
| 6 | 打开按键配置 |
| 9 | 打开歌曲附带的文本文件 |

## 游玩画面

| 按键 | 操作 |
| --- | --- |
| ← / → | 降低 / 提高流速 |
| ↑ / ↓ | 移动轨道遮罩（SUDDEN+ 等） |
| 按住 E2 + ↑ / ↓ | 小幅移动轨道遮罩 |
| 鼠标滚轮 | 移动轨道遮罩（按住 E2 时小幅移动） |
| 按住 E1 + 按键 | 更改流速 |
| 按住 E1 + 转盘 | 移动轨道遮罩 |
| 按住 E2 + 按键或转盘 | 更改绿色数字（可使用 FLOATING 时） |
| 连按两次 E1 | 显示 / 隐藏 SUDDEN+ |
| 同时按 E1 和 E2 | 切换流速方式（FLOATING 等） |
| 3 / 9 | 以 1 毫秒为单位调整显示时机 |
| 0 | 开启 / 关闭自动判定调整 |
| Esc | 退出游玩 |
| 长按 E1 和 E2 | 退出游玩 |

中途失败（血条归零而结束）时，在演出过程中按 **E1** 可用新的排列、按 **E2** 可用相同排列立即重试。

流速和绿色数字请参阅[游玩选项](05-play-options.md)，显示时机请参阅[判定时机与延迟调整](06-timing.md)。

### 自动演奏、回放播放中

按住上排数字键 **1 / 2 / 3 / 4** 时，播放速度变为 25% / 50% / 200% / 300%。松开后恢复原速。

## 结算画面

| 按键 | 操作 |
| --- | --- |
| Enter、Esc、KEY1～KEY4 | 返回选曲画面 |
| R | 以相同排列再玩一次 |
| 按住 KEY7 等待 | 以相同排列再玩一次 |
| 按住 KEY5 等待 | 以新的排列再玩一次 |
| KEY6 | 切换血条图表的显示 |
| 1 / 2 / 3 / 4 | 将回放保存到槽位 1～4 |
| F11 | 在浏览器中打开所玩谱面的 IR 页面 |

在支持的皮肤中，可以用 **E2** 切换 IR 排名和图表的显示。

## 练习

在选曲画面将游玩类型设为练习并决定歌曲后，会打开练习用的设置画面。
可以指定要练习的区间、血条、播放速度（50～200%）等，反复练习同一区间。
练习的成绩不会保存。

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 选择项目 |
| ← / → | 更改数值 |
| Enter | 开始区间游玩 |
| Esc | 返回选曲画面 |
