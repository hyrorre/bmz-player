# 游玩选项

本页介绍改变游玩难度和显示方式的选项。
选项可以在选曲画面按 **E1** 等显示的选项面板中更改，也可以在 设置 → **游玩** 中更改。

不确定时，直接使用初始设置开始游玩也没有问题。

## 血条

血条是表示游玩状态的计量条。判定良好时增加，失误时减少。
不同类型的血条，增减方式和通关条件各不相同。

| 血条 | 特点 |
| --- | --- |
| ASSIST EASY | 最不容易减少的血条。通关也会被视为比 EASY 低的记录 |
| EASY | 比 NORMAL 更不容易减少的血条 |
| NORMAL | 标准的血条 |
| HARD | 从满值开始，归零时立即结束（失败） |
| EX-HARD | 比 HARD 更容易减少的血条 |
| HAZARD | 连击中断即失败 |

ASSIST EASY、EASY、NORMAL 在歌曲结束时血条达到通关线以上即为通关。
HARD、EX-HARD、HAZARD 只要中途不失败、玩到最后即为通关。

初次游玩建议从 NORMAL 开始，难以通关的歌曲建议使用 EASY 或 ASSIST EASY。

### 血条自动切换（GAS）

失败时切换到其他血条继续游玩的功能。初始为 OFF。

| 方式 | 内容 |
| --- | --- |
| OFF | 不切换。在 HARD 等血条下失败时立即结束 |
| CONTINUE | 即使失败也能玩到歌曲结束。记录仍为所选血条 |
| HARD->GROOVE | 在 HARD 等血条下失败时，切换为 NORMAL 继续游玩 |
| BEST CLEAR | 同时计算所有血条，记录已通关血条中最高的一种 |
| SELECT UNDER | 同时计算所选血条及以下的血条，记录已通关血条中最高的一种 |

例如在 BEST CLEAR 下，即使中途无法满足 EX-HARD 的条件，只要以 HARD 或 NORMAL 通关，该记录仍会保留。
可以用“GAS 最低血条”决定最低记录到哪一种血条。

## 排列（RANDOM 等）

改变落到各按键上的音符排列。同一谱面也能以不同排列练习。

| 排列 | 内容 |
| --- | --- |
| OFF | 按谱面原样落下 |
| MIRROR | 左右翻转 |
| RANDOM | 每次游玩随机交换轨道排列 |
| R-RANDOM | 保持轨道顺序，整体横向平移 |
| S-RANDOM | 将每个音符随机分配到轨道 |
| SPIRAL | 让轨道排列逐渐像旋转一样变化 |
| H-RANDOM | 与 S-RANDOM 相同，但避免同一轨道在短时间内连续出现音符 |
| ALL-SCR | 尽可能多地将音符集中到转盘 |
| RANDOM-EX / S-RANDOM-EX | 连同转盘一起交换 |
| F-RANDOM | 将按键分为左半和右半，分别在各自范围内交换排列。7 键时中间的按键不动 |
| MF-RANDOM | 在 F-RANDOM 的排列基础上再左右翻转 |

S-RANDOM 等逐个分配音符的排列，可能使谱面与原本形状差异很大。

## 流速

音符落下的速度。加快后音符间距变大、更容易看清，但反应时间会变短。
游玩中可以用 **← / →** 键，或 **按住 E1 + 按键** 更改。

### 绿色数字

表示音符从画面上方出现到抵达判定线所需时间的数字。
数值为毫秒数的 0.6 倍，例如绿色数字 300 为 0.5 秒。数字越小，看起来越快。
即使 BPM 不同，只要绿色数字相同，看起来的速度就相同。

### 流速方式（HS 设置）

| 方式 | 内容 |
| --- | --- |
| NORMAL | 从 20 个档位中选择。每个档位对应固定的绿色数字 |
| CLASSIC | 直接指定倍率。与 LR2 和 beatoraja 的普通流速相同 |
| FLOATING | 指定绿色数字后，根据歌曲的 BPM 自动决定倍率 |
| NORMAL+FLOATING | 游玩中可以在 NORMAL 和 FLOATING 之间切换 |
| CLASSIC+FLOATING | 游玩中可以在 CLASSIC 和 FLOATING 之间切换（初始设置） |
| LR2 | 与 CLASSIC 一样直接指定倍率（倍率与 CLASSIC 共用）。使用 HS-FIX 时，倍率表示 BPM 150 时的速度（与 LR2 相同） |

在可切换的方式中，游玩时 **同时按 E1 和 E2** 即可切换。
使用 FLOATING 时，**按住 E2 + 按键或转盘** 可更改绿色数字。

如果不想每首歌都重新调整速度，FLOATING 会很方便。

### HS-FIX

歌曲中途 BPM 变化时，选择以哪个 BPM 为基准决定速度。
例如设为“最大 BPM”时，会以歌曲中最快的部分为准决定速度。

## 轨道遮罩

遮住轨道的一部分，调整音符可见的范围。
可用于让快速的音符更容易看清，或让可见位置与视线高度一致。

| 类型 | 内容 |
| --- | --- |
| SUDDEN+ | 遮住轨道上方 |
| HIDDEN+ | 遮住轨道下方（判定线附近） |
| LIFT | 将判定线向上抬高 |

要使用的遮罩需在 设置 → **游玩** 的“显示”中按按键数分别启用。
游玩中用 **↑ / ↓** 键或 **按住 E1 + 转盘** 调整遮挡量。
**连按两次 E1** 可以显示或隐藏 SUDDEN+。

开启“轨道遮罩变化时按当前 BPM 自动调整 HS”后，移动遮罩时会调整流速，使绿色数字保持不变。

## LN 模式

选择长按音符（长条音符）的判定方式。

| 类型 | 内容 |
| --- | --- |
| LN | 只判定按下的时机，不判定松开的时机 |
| CN | 同时判定按下和松开的时机 |
| HCN | 与 CN 一样两者都判定，按住期间血条也会增减 |

带有“AUTO”的设置中，谱面指定了类型时按谱面，未指定时按所选类型游玩。
带有“FORCE”的设置中，无论谱面如何指定，都按所选类型游玩。

也可以在选曲画面按 **3** 键切换。成绩按 LN 模式分别保存。

## 规则

一并切换判定范围、血条和分数计算方式。成绩按规则分别保存。

| 规则 | 内容 |
| --- | --- |
| beatoraja | 与 beatoraja 相同的规则（初始设置） |
| LR2oraja | 接近 LR2 的规则。与 LR2oraja Endless Dream 的行为相同 |
| DX MODE | 与 LR2oraja Endless Dream 的 DX MODE 相同的规则 |

查看从 LR2 或 beatoraja 导入的成绩时，请切换为导入时的规则。

## 辅助

放宽判定、提前显示 BPM 变化等辅助游玩的功能。
在选曲画面按住 **E2** 时显示的面板中设置。

辅助功能生效的游玩中，即使通关也会记为 ASSIST，且不保存分数、不提交到 IR。
不过，显示可判定范围（JUDGE AREA）、标记追加音符（MARK NOTE）等仅改变显示的功能不会影响记录。
此外，像在 BPM 不变的谱面上使用 BPM GUIDE 这样没有生效的辅助功能，也不会影响记录。

## 目标

选择游玩中与自己分数比较的对象。
可以从 AAA 等评级目标值、IR 高分、对手的分数等中选择。

## 游玩类型

| 类型 | 内容 |
| --- | --- |
| NORMAL | 普通游玩 |
| PRACTICE | 指定区间和速度进行练习。不保存成绩 |
| AUTOPLAY | 自动演奏。不保存成绩 |
| AUTOPLAY BATTLE | 在对战画面中自动演奏。不保存成绩 |
| G-BATTLE | 以已保存的回放或 IR 成绩为对手进行对战 |

## 不保存成绩的情况

以下游玩不会保存成绩、通关记录和回放，也不会提交到 IR：

- 自动演奏、回放播放、练习
- 转换了按键数的游玩（如以 9 键玩 7 键谱面）

辅助功能生效的游玩只保存 ASSIST 通关记录。
