# 从 LR2 或 beatoraja 迁移

本页面向用过 LR2 或 beatoraja 的玩家，介绍如何将歌曲、成绩和皮肤迁移到 BMZ Player。
BMZ Player 不会更改原软件的文件，因此迁移后仍可继续使用 LR2 或 beatoraja。

## 1. 登记歌曲文件夹

首先，将在 LR2 或 beatoraja 中使用的 BMS 文件夹也登记到 BMZ Player。
请在 设置 → **曲库** → **歌曲文件夹（BMS）** 中添加相同的文件夹。
无需复制歌曲文件。

**导入成绩前，请等待歌曲读取完成。**
LR2 的成绩会与 BMZ Player 已读取的谱面进行比对后导入，
因此尚未读取的谱面的成绩不会被导入。

## 2. 导入成绩

在 设置 → **数据导入** →“导入成绩”中导入。

1. 按“选择文件…”，选择原软件的成绩文件。

   | 原软件 | 要选择的文件 |
   | --- | --- |
   | LR2 | `LR2files/Database/Score/<玩家名>.db` |
   | beatoraja | `player/<玩家名>/score.db` |
   | LR2oraja | 与 beatoraja 相同位置的 `score.db` |

2. 在右侧栏中选择原软件的类型。
3. 在“输入设备”中选择这些成绩是用键盘还是控制器取得的。
4. 按“导入”。

会显示导入的条数和无法导入的条数。

想把导入的成绩也登记到 IR 时，请先按[参加网络排名（IR）](02-setup.md)登录，再使用 设置 → **IR** 中的“批量发送本地成绩”。

### 看不到导入的成绩时

BMZ Player 会按规则（判定和血条的机制）分别保存成绩。
导入的成绩会按原软件保存到以下规则：

| 原软件 | 保存的规则 |
| --- | --- |
| beatoraja | beatoraja |
| LR2、LR2oraja | LR2oraja |
| LR2oraja（DX Mode） | DX MODE |

选曲画面中看不到成绩时，请确认 设置 → **游玩** 的“规则”是否为导入时的规则。
关于规则，请参阅[游玩选项](05-play-options.md)。

## 3. 导入回放（beatoraja）

也可以导入 beatoraja 的回放。
在 设置 → **数据导入** 中将上方的切换改为“导入回放”，
然后指定 beatoraja 的 `player/<玩家名>` 文件夹、`replay` 文件夹或单个 `.brd` 文件进行导入。

## 4. 迁移皮肤

在 beatoraja 中使用的皮肤可以直接在 BMZ Player 中使用。

1. 按 设置 → **皮肤** →“打开附加皮肤文件夹”。
2. 从 beatoraja 的 `skin` 文件夹中整个复制所用的皮肤文件夹。
   如果皮肤使用了其他文件夹中的字体或图片，也请一并复制。
3. 按“刷新皮肤列表”，再在左侧选择画面，在右侧选择皮肤。

皮肤选项不会被迁移，请根据需要重新设置。

## 5. 重新检查设置

按键分配、流速和判定时机不会被迁移。
请参阅[初始设置](02-setup.md)中的“设置按键和控制器”以及[判定时机与延迟调整](06-timing.md)进行设置。

### 与 LR2、beatoraja 的主要区别

- 设置集中在按 **F1** 打开的设置窗口中。没有启动器。
- 流速有 5 种方式。想以与 LR2 或 beatoraja 相同的感觉游玩时，请参阅[游玩选项](05-play-options.md)了解如何选择。
- 可以选择将长条音符作为 LN、CN 还是 HCN 游玩。成绩按 LN 类型分别保存。
