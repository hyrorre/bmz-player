# 困ったとき

よくある症状と対処方法です。解決しない場合は、ページの最後にある方法で報告してください。

## 起動・表示

### 起動しない、すぐに終了する

- **Windows**：グラフィックドライバーを最新にしてください。古い Windows では Vulkan ドライバーが必要な場合があります。
- **macOS**：「開けません」と表示される場合は、[初期セットアップ](02-setup.md)の「macOS で『開けません』と表示されたとき」を参照してください。
- **Linux**：Vulkan に対応したグラフィックドライバーが必要です。tar.gz 版は、展開したフォルダの `./bmz-player` から起動してください。

### 画面がカクつく、動きがなめらかでない

設定 → **映像** で「フレーム遅延」を「安定」にするか、「目標 FPS」をモニターのリフレッシュレートに合わせてください。
ほかのアプリを閉じると改善することもあります。

### スキンが表示されない、崩れる

設定 → **スキン** で、そのスキンに読み込みエラーが表示されていないか確認してください。
スキンの一部のフォルダ（フォントや画像）が足りないと、正しく表示されません。
スキンはフォルダごと、配布されたままの構成で置いてください。

## 曲・難易度表

### 曲が表示されない

- 設定 → **ライブラリ** で、曲を入れたフォルダが登録されているか確認してください。
- 曲を追加したあとは、選曲画面で **F5** を押すか、「ライブラリを再スキャン」を押してください。
- 1 曲を 1 フォルダとして置いているか確認してください。譜面ファイル（.bms など）と音声ファイルが同じフォルダに必要です。
- 選曲画面で **0**（難易度）や **1**（鍵盤数）の絞り込みが有効になっていないか確認してください。

### 難易度表に曲がない、表が更新されない

選曲画面で難易度表のフォルダを選んで **F5** を押すと、表を取得し直します。
難易度表に載っていても、譜面を持っていなければ遊べません。持っていない譜面を選んで決定すると、入手先がブラウザで開きます。

## 音

### 音が出ない

1. 設定 → **音声** の「出力デバイス」で、使っている機器が選ばれているか確認します。
2. 「デバイス一覧を更新」を押してから選び直し、「適用」を押します。
3. 同じ画面の「音量」で、マスター音量などが 0 になっていないか確認します。

機器を抜き差ししたあとに音が出なくなった場合も、「適用」を押すと直ることがあります。

### 音が途切れる、プツプツする

設定 → **音声** の「バッファサイズ」を大きくしてください。

### 音が遅れて聞こえる

[判定タイミングと遅延の調整](06-timing.md)を参照してください。

## 入力

### キーボードやコントローラーが反応しない

- 設定 → **入力デバイス** で、コントローラーが接続済みと表示されているか確認してください。
- 設定 → **キーコンフィグ** で、遊んでいる鍵盤数（7K など）の割り当てを確認してください。鍵盤数ごとに割り当てが分かれています。
- 割り当ての横に警告アイコンが出ている場合は、別の操作と同じキーが割り当てられています。

### スクラッチが反応しにくい、回しすぎる

設定 → **入力デバイス** で「アナログスクラッチ」と「アナログ感度」を調整してください。

## スコア・IR

### スコアが保存されない

オートプレイ・リプレイの再生・プラクティス・鍵盤数を変換したプレイのスコアは保存されません。
アシストの効果が出た場合は、ASSIST のクリア記録だけが保存されます。

### 取り込んだスコアや以前のスコアが表示されない

スコアは、ルールと LN モードの組み合わせごとに分けて保存されています。
設定 → **プレイ** の「ルール」と「LN モード」を、そのスコアを出したときの設定に戻してください。

### IR にスコアが送信されない

- 設定 → **IR** で、ログイン済みと表示されているか確認してください。
- インターネットに接続していない間のスコアは、接続が戻ったあとに自動で送信されます。
- 送信に失敗したスコアは、設定 → **IR** →「送信キューを開く」で確認し、「再送信」で送り直せます。

## ログとデータの場所

**F1** で BMZ メニューを開き、「一般」の「ディレクトリを開く」にあるボタンからフォルダを開けます。

| ボタン | 中身 |
| --- | --- |
| data_dir | 設定、スコア、リプレイ、追加したスキン |
| logs_dir | 動作記録（ログ） |
| cache_dir | 一時的なファイル。削除しても必要に応じて作り直されます |
| resource_dir | BMZ Player に同梱されているファイル。更新で上書きされます |

data_dir をバックアップしておくと、設定とスコアを守れます。
バックアップは BMZ Player を終了してから行ってください。

## 不具合を報告する

[GitHub の Issues](https://github.com/hyrorre/bmz-player/issues) から報告してください。
次の情報があると、原因を調べやすくなります。

- 使っている OS と BMZ Player のバージョン
- 何をしたときに、何が起きたか
- logs_dir にあるログファイル
- 必要ならスクリーンショット（**F12** で保存できます）
