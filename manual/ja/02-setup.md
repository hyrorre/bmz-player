# 初期セットアップ

BMZ Player を入手してから、最初の 1 曲を遊ぶまでの手順です。
上から順に進めてください。すでに設定済みの項目は飛ばして構いません。

## 1. BMZ Player を入手する

[GitHub Releases](https://github.com/hyrorre/bmz-player/releases) から、使っている OS に合ったファイルをダウンロードします。

| OS | ファイル | 説明 |
| --- | --- | --- |
| Windows | `...-windows-x64-setup.exe` | インストーラーです。迷ったらこちらを選んでください |
| Windows | `...-windows-x64-portable.zip` | 展開するだけで使える版です。設定やスコアは展開したフォルダの `data` に保存されます |
| macOS（Apple シリコン） | `...-macos-arm64.app.zip` | M1 以降の Mac 用です |
| macOS（Intel） | `...-macos-x64.app.zip` | Intel 製 CPU の Mac 用です |
| Linux | `...-linux-x64.tar.gz` | 展開して `./bmz-player` を実行します |
| Linux | `...-linux-x64.flatpak` | Flatpak 版です |

`sources` や `SHA256SUMS` などのファイルは、遊ぶだけなら必要ありません。

### 動作環境

- **Windows**：Windows 10 以降
- **macOS**：macOS 10.13 以降
- **Linux**：Ubuntu 22.04 相当以降の x86_64 環境。Vulkan に対応したグラフィックドライバーが必要です。

### macOS で「開けません」と表示されたとき

BMZ Player は Apple の公証を受けていないため、初めて開くときに警告が出ることがあります。
ZIP を展開した `.app` を「アプリケーション」フォルダなどへ移動してから、
[Apple の案内](https://support.apple.com/ja-jp/102445)に従って開いてください。

## 2. 起動して画面を確認する

BMZ Player を起動すると、選曲画面が表示されます。
最初から動作確認用のサンプル曲が 1 曲入っているので、選んで遊んでみてください。

- カーソルの移動は **↑ / ↓**、決定は **Enter**、フォルダを閉じるのは **←** です。
- 7 鍵の場合、鍵盤は **Z S X D C F V**、スクラッチは **左 Shift / 左 Ctrl** です。
- 終了するときは、選曲画面で **Esc** を長押しします。

設定は **F1** キーで開く「BMZ メニュー」から変更します。
左の一覧から項目を選ぶと、右側にその設定が表示されます。
設定は変更すると自動で保存されるので、保存ボタンを押す必要はありません。

## 3. 曲フォルダを登録する

BMS を入れておくフォルダを決めて、BMZ Player に登録します。

1. パソコンの好きな場所に、BMS を入れるフォルダを作ります（例：`D:\BMS`）。
2. 入手した曲をそのフォルダに入れます。1 曲を 1 フォルダとして置きます。ジャンル別などに何階層かまとめても構いません。
3. 設定 → **ライブラリ** → **曲フォルダ (BMS)** で「フォルダを選択…」を押し、作ったフォルダを選んで追加します。

追加したフォルダは自動で読み込まれ、選曲画面に曲が表示されます。
あとから曲を増やしたときは、選曲画面でそのフォルダを選んで **F5** を押すか、
設定 → ライブラリ →「ライブラリを再スキャン」を押してください。

### 曲の入手先

- **BMS 検索サイト**：曲名や作者名から配布ページを探せます。
- **BMS イベント**：BMS OF FIGHTERS（BOF）などのイベントの会場ページから、参加作品をまとめて入手できます。
- **難易度表**：次の手順で説明する難易度表から、遊びたい難しさの曲を探すこともできます。

曲によっては、本体とは別に「差分」と呼ばれる追加譜面が配布されています。
差分は、元の曲のフォルダに入れると選べるようになります。

## 4. 難易度表を使う

難易度表は、有志が BMS の譜面を難しさ順に並べた一覧です。
BMZ Player には、よく使われている難易度表が最初から登録されています。
選曲画面の「難易度表」フォルダを開くと、表のレベルごとに曲が並びます。

ほかの難易度表を使いたいときは、設定 → **難易度表** で表の URL を入力して追加します。

難易度表の中には、まだ持っていない譜面も表示されます。
持っていない譜面を選んで決定すると、その譜面の入手先がブラウザで開きます。
入手した曲を曲フォルダへ入れて再スキャンすると、遊べるようになります。

## 5. キーやコントローラーを設定する

最初の割り当ては次のとおりです。

| 操作 | キーボード |
| --- | --- |
| 7 鍵の鍵盤 | Z S X D C F V |
| 7 鍵のスクラッチ | 左 Shift（上）／左 Ctrl（下） |
| 14 鍵の 2P 側の鍵盤 | M K , L . ; / |
| 14 鍵の 2P 側のスクラッチ | 右 Shift ／右 Ctrl |
| 9 ボタン（PMS） | Z S X D C F V G B |
| E1 / E2 / E3 / E4 | Q / W / E / R |

E1〜E4 は、beatoraja の START / SELECT にあたる補助ボタンです。オプションの変更などに使います。

割り当てを変えるには、設定 → **キーコンフィグ** を開きます。

1. 「対象」で、変更したい鍵盤数（7K など）や画面を選びます。
2. 「入力スロット」で、キーボードかコントローラーかを選びます。
3. 変更したい操作の右にあるボタンを押してから、割り当てたいキーやボタンを押します。

Esc で取り消し、Delete または Backspace で割り当てを外せます。
コントローラーが反応しない場合は、設定 → **入力デバイス** で接続されているかを確認してください。

## 6. 音を確認する

音が出ない、または音が途切れるときは、設定 → **音声** で出力先を確認します。

1. 「出力デバイス」で、使っているスピーカーやヘッドホンを選びます。
2. 「適用」を押します。音声の設定は「適用」を押すまで反映されません。

音が遅れて聞こえる場合は、「バッファサイズ」を小さくすると改善することがあります。
小さくしすぎると音がプツプツ途切れるので、途切れない範囲で調整してください。

## 7. 判定タイミングを合わせる

ノーツと音、操作のタイミングがずれていると感じたら調整します。
プレイ中に **0** キーを押すと自動判定調整が ON になり、数曲遊ぶうちにずれが補正されます。
詳しくは[判定タイミングと遅延の調整](06-timing.md)を参照してください。

## 8. スキンを選ぶ

BMZ Player には、次のスキンが同梱されています。

- **m-select**：選曲・決定・リザルト画面と、プレイ画面（antique、brand-new）
- **Rm-skin**：4 鍵〜9 ボタンのプレイ画面
- **Luxe Flat**：選曲・決定・リザルト画面

スキンは、設定 → **スキン** で「対象画面」（選曲、7K のプレイ画面など）を選び、使うスキンを選択して変更します。
スキンごとに用意されたオプションも、同じ画面で変更できます。

### ほかのスキンを追加する

1. 設定 → スキン →「追加スキンのフォルダーを開く」を押します。
2. 開いたフォルダに、入手したスキンをフォルダごと置きます。ZIP は展開してから置いてください。
3. 「スキン一覧を更新」を押し、画面ごとに追加したスキンを選びます。

BMZ Player は beatoraja 用のスキン（JSON・Lua）と LR2 用のスキン（CSV）を読み込めます。

## 9. インターネットランキング（IR）に参加する

IR に参加すると、スコアをオンラインのランキングに登録して、ほかのプレイヤーと比べられます。参加は任意です。

1. [BMZ IR](https://bmz-player.hyrorre.workers.dev/) の「登録」からアカウントを作ります。
2. BMZ Player の設定 → **IR** で、BMZ IR の欄にメールアドレスとパスワードを入力し、「ログイン」を押します。

ログインすると、以後のプレイのスコアは自動で送信されます。
BMZ Player は rianIR と BMS-IR にも対応しており、同じ画面からログインできます。

### 過去のスコアをまとめて送る・取得する

設定 → **IR** の「スコアの一括操作」では、次の操作ができます。

- 「ローカルスコアを一括送信」: この PC に保存されているスコアを、Primary IR へまとめて送ります。LR2 や beatoraja から取り込んだスコアを IR に載せたいときに使います。
- 「IRからスコアを取得」: IR に保存されている自分のスコアを、この PC に取り込みます。別の PC でプレイしたスコアをそろえたいときに使います。

ボタンを押すと確認画面が開きます。一括送信では、送るスコアの件数と、かかる時間の目安が表示されます。内容を確認して「開始」を押すと始まります。

- 件数が多いと、数分から数十分以上かかります。進み具合は同じ画面に表示され、設定ウィンドウを閉じても処理は続きます。
- 「中断」でいつでも止められます。もう一度実行すると、続きから進みます。
- 実行中はプロファイルを切り替えられません。
- 一括操作は Primary IR にだけ使えます。ローカルスコアの一括送信は BMZ IR のみ、スコアの取得は rianIR 以外で使えます。ログインしていないときは、ボタンを押せません。

終わると、結果が通知されます。

### 送信に失敗したスコアを確認して再送する

一括操作の下に「IR送信キュー」があります。送信待ち・送信中・失敗したスコアの一覧で、初めは失敗したスコアだけが表示されます。「表示」で絞り込みを変え、「更新」で最新の状態にできます。

- 各行には、種類、譜面、状態、試行回数、次の再試行の時刻、最後のエラーが表示されます。
- 失敗した行の「再送信」を押すと、そのスコアだけをすぐに送り直します。
- 「失敗分を一括再送信」を押すと、確認画面のあと、失敗したスコアを順に送り直します。

失敗したスコアは、時間をおいて自動でも再試行されます。通信の不調が直ったあとに、待たずに送り直したいときに使ってください。別の処理が送信中のスコアは、その処理が終わってから送られます。

以上でセットアップは完了です。操作方法は[基本操作](04-controls.md)を参照してください。
