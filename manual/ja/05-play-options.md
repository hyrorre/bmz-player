# プレイオプション

プレイの難しさや見え方を変えるオプションの説明です。
オプションは、選曲画面で **E1** などを押して表示するオプションパネル、または設定 → **プレイ** で変更できます。

迷ったときは、最初の設定のまま遊び始めて構いません。

## ゲージ

ゲージは、プレイ中の調子を表すメーターです。判定がよいと増え、ミスすると減ります。
種類によって、増え方・減り方とクリアの条件が変わります。

| ゲージ | 特徴 |
| --- | --- |
| ASSIST EASY | 最も減りにくいゲージです。クリアしても、EASY より下の記録として扱われます |
| EASY | NORMAL より減りにくいゲージです |
| NORMAL | 標準のゲージです |
| HARD | 満タンから始まり、0 になるとその場で終了（閉店）します |
| EX-HARD | HARD よりさらに減りやすいゲージです |
| HAZARD | コンボが途切れると閉店します |

ASSIST EASY・EASY・NORMAL は、曲の最後にゲージがクリアのライン以上ならクリアです。
HARD・EX-HARD・HAZARD は、最後まで閉店せずに遊び切ればクリアです。

初めての方は NORMAL から始め、クリアが難しい曲では EASY や ASSIST EASY を使うことをおすすめします。

### ゲージオートシフト（GAS）

閉店したときに、ほかのゲージに切り替えて遊び続ける機能です。最初は OFF になっています。

| 方式 | 内容 |
| --- | --- |
| OFF | 切り替えません。HARD などで閉店すると、その場で終了します |
| CONTINUE | 閉店しても、曲の最後まで遊べます。記録は選んだゲージのままです |
| HARD->GROOVE | HARD などで閉店したら、NORMAL に切り替えて遊び続けます |
| BEST CLEAR | すべてのゲージを同時に計算し、クリアできた中で最も上のゲージを記録します |
| SELECT UNDER | 選んだゲージから下のゲージを同時に計算し、クリアできた中で最も上のゲージを記録します |

たとえば BEST CLEAR では、途中で EX-HARD の条件を満たせなくなっても、HARD や NORMAL でクリアしていればその記録が残ります。
「GAS 下限ゲージ」で、どこまで下のゲージを記録の対象にするかを決められます。

## 配置（RANDOM など）

鍵盤に降ってくるノーツの並びを入れ替えます。同じ譜面でも違う配置で練習できます。

| 配置 | 内容 |
| --- | --- |
| OFF | 譜面のとおりに降ります |
| MIRROR | 左右を反転します |
| RANDOM | レーンの並びをプレイごとにランダムに入れ替えます |
| R-RANDOM | レーンの並びを、順番を保ったまま横にずらします |
| S-RANDOM | ノーツ 1 つずつをランダムなレーンに振り分けます |
| SPIRAL | レーンの並びを、少しずつ回転するように変えていきます |
| H-RANDOM | S-RANDOM と同じですが、同じレーンに短い間隔でノーツが続かないようにします |
| ALL-SCR | できるだけ多くのノーツをスクラッチに集めます |
| RANDOM-EX / S-RANDOM-EX | スクラッチも含めて入れ替えます |
| F-RANDOM | 鍵盤を左半分と右半分に分け、それぞれの中で並びを入れ替えます。7 鍵では中央の鍵盤は動きません |
| MF-RANDOM | F-RANDOM の配置を、さらに左右反転します |

S-RANDOM などノーツを個別に振り分ける配置では、譜面が本来の形と大きく変わることがあります。

## ハイスピード

ノーツが降ってくる速さです。速くするとノーツの間隔が広がって見やすくなりますが、反応する時間は短くなります。
プレイ中に **← / →** キー、または **E1 を押しながら鍵盤** で変えられます。

### 緑数字

ノーツが画面の上に現れてから判定ラインに届くまでの時間を表す数字です。
値はミリ秒の 0.6 倍で、たとえば緑数字 300 は 0.5 秒です。数字が小さいほど速く見えます。
BPM が違う曲でも、緑数字が同じなら同じ速さに見えます。

### ハイスピードの方式（HS設定）

| 方式 | 内容 |
| --- | --- |
| NORMAL | 20 段階から選びます。段階ごとに緑数字が決まっています |
| CLASSIC | 倍率を直接指定します。LR2 や beatoraja の通常のハイスピードと同じ考え方です |
| FLOATING | 緑数字を指定し、曲の BPM に合わせて倍率を自動で決めます |
| NORMAL+FLOATING | NORMAL と FLOATING をプレイ中に切り替えられます |
| CLASSIC+FLOATING | CLASSIC と FLOATING をプレイ中に切り替えられます（最初の設定） |
| LR2 | CLASSIC と同じく倍率を直接指定します（倍率は CLASSIC と共通）。HS-FIX を使うときは、倍率を BPM 150 での速さとして扱います（LR2 と同じ） |

切り替えられる方式では、プレイ中に **E1 と E2 を同時に押す** と切り替わります。
FLOATING のときは、**E2 を押しながら鍵盤やスクラッチ** で緑数字を変えます。

曲ごとに速さを合わせ直すのが面倒な場合は、FLOATING を使うと便利です。

### HS-FIX

曲の途中で BPM が変わるとき、どの BPM を基準に速さを決めるかを選びます。
たとえば「最大 BPM」にすると、曲の中で最も速い部分に合わせて速さを決めます。

## レーンカバー

レーンの一部を隠して、ノーツが見える範囲を調整します。
速いノーツを見やすくしたり、見える位置を目の高さに合わせたりするのに使います。

| 種類 | 内容 |
| --- | --- |
| SUDDEN+ | レーンの上側を隠します |
| HIDDEN+ | レーンの下側（判定ライン付近）を隠します |
| LIFT | 判定ラインを上に持ち上げます |

使うカバーは、設定 → **プレイ** の「表示」で鍵盤数ごとに有効にします。
プレイ中は **↑ / ↓** キー、または **E1 を押しながらスクラッチ** で量を変えます。
↑ / ↓ は 1 回押すとレーンの 1% 動き、押し続けると連続して動きます。**E2 を押しながら** だと 0.1% ずつ細かく動かせます。マウスホイールでも動かせ、1 目盛りでレーンの 0.5%（E2 を押しながらだと 0.1%）動きます。動く量と、押し続けてから動き始めるまでの時間は、設定 → **入力** で変えられます。
有効にしたカバーの量が 0 のときは、プレイ開始時に 150（レーンの 15%）にします。
**E1 を 2 回押す** と SUDDEN+ を表示したり隠したりできます。

「レーンカバー変更時に現在BPMへHSを自動調整」を ON にすると、カバーを動かしても緑数字が変わらないようにハイスピードを調整します。

## LN モード

長押しするノーツ（ロングノート）の判定方法を選びます。

| 種類 | 内容 |
| --- | --- |
| LN | 押し始めのタイミングだけを判定します。離すタイミングは問われません |
| CN | 押し始めと離すタイミングの両方を判定します |
| HCN | CN と同じく両方を判定し、押している間もゲージが増減します |

「AUTO」の付いた設定では、譜面が種類を指定していればそれに従い、指定していなければ選んだ種類で遊びます。
「FORCE」の付いた設定では、譜面の指定に関係なく選んだ種類で遊びます。

選曲画面で **3** キーを押しても切り替えられます。スコアは LN モードごとに分けて保存されます。

## ルール

判定の幅、ゲージ、スコアの計算方法をまとめて切り替えます。スコアはルールごとに分けて保存されます。

| ルール | 内容 |
| --- | --- |
| beatoraja | beatoraja と同じルールです（最初の設定） |
| LR2oraja | LR2 に近いルールです。LR2oraja Endless Dream と同じ動作をします |
| DX MODE | LR2oraja Endless Dream の DX MODE と同じルールです |

LR2 や beatoraja から取り込んだスコアを見るときは、取り込んだときのルールに合わせてください。

## アシスト

判定を広げる、BPM の変化を事前に表示するなど、プレイを手助けする機能です。
選曲画面で **E2** を押している間に表示されるパネルで設定します。

アシストの効果が出たプレイでは、クリアしても ASSIST の記録になり、スコアの保存と IR への送信は行われません。
ただし、判定される範囲の表示（JUDGE AREA）や追加ノーツの目印（MARK NOTE）など、表示だけを変える機能は記録に影響しません。
また、BPM が変わらない譜面での BPM GUIDE のように、効果が出なかったアシストも記録に影響しません。

## ターゲット

プレイ中に、自分のスコアと比べる相手を選びます。
AAA などのランクの目標値、IR の上位スコア、ライバルのスコアなどから選べます。

## プレイの種類

| 種類 | 内容 |
| --- | --- |
| NORMAL | 通常のプレイです |
| PRACTICE | 区間や速度を指定して練習します。スコアは保存されません |
| AUTOPLAY | 自動で演奏します。スコアは保存されません |
| AUTOPLAY BATTLE | 対戦用の画面で自動演奏します。スコアは保存されません |
| G-BATTLE | 保存したリプレイや IR のスコアを相手にして対戦します |

## スコアが保存されない場合

次のプレイでは、スコア・クリア記録・リプレイを保存せず、IR にも送信しません。

- オートプレイ、リプレイの再生、プラクティス
- 鍵盤数を変換したプレイ（7 鍵を 9 ボタンで遊ぶなど）

アシストの効果が出たプレイでは、ASSIST のクリア記録だけを保存します。
