# 基本操作

選曲画面・プレイ画面・リザルト画面のおもな操作です。
キーは最初の割り当てで書いています。割り当ては設定 → **キーコンフィグ** で変更できます。

表の「KEY1」〜「KEY7」は 7 鍵の鍵盤を左から数えた番号、「E1」〜「E4」は補助ボタンです。
最初の割り当てでは、KEY1〜KEY7 が **Z S X D C F V**、E1〜E4 が **Q W E R** です。

## どの画面でも使える操作

| キー | 操作 |
| --- | --- |
| F1 | BMZ メニュー（設定とツール）を開く・閉じる |
| F12 | スクリーンショットを保存する |

## 選曲画面

### 曲を選ぶ

| キー | 操作 |
| --- | --- |
| ↑ / ↓、スクラッチ | カーソルを動かす |
| PageUp / PageDown | 1 ページずつ動かす |
| Enter、→、KEY1・KEY3・KEY5・KEY7 | 決定する（フォルダを開く、曲を始める） |
| ←、KEY2・KEY4・KEY6 | フォルダを閉じる |
| / | 曲を検索する |
| Esc | BMZ メニューを開いていれば閉じる。フォルダの中ならフォルダを閉じる |
| Esc（いちばん上の階層で長押し） | BMZ Player を終了する |

マウスでも操作できます。ホイールでカーソルを動かし、選択中の行をクリックすると決定、右クリックでフォルダを閉じます。

### 一覧の表示を変える

| キー | 操作 |
| --- | --- |
| 0 | 難易度で絞り込む |
| 1 | 鍵盤数で絞り込む（7K、14K、9K など） |
| 2 | 並び順を変える |
| 3 | LN モードを切り替える |
| F8 / F9 | お気に入りの曲・譜面に登録する／外す |
| F5 | 選んでいるフォルダを読み込み直す（難易度表では表を取得し直す） |

### オプションを変える

**E1** を押している間、オプションパネルが表示されます。押したまま鍵盤を押して設定を変えます。

| 鍵盤 | E1 を押しながら |
| --- | --- |
| KEY1 / KEY2 | 配置（RANDOM など）を切り替える |
| KEY3 / KEY4 | ゲージを切り替える |
| KEY5 | HS-FIX を切り替える |
| KEY6 | DP オプションを切り替える |
| KEY7 | プレイの種類（通常、プラクティス、オートプレイなど）を切り替える |
| スクラッチ、↑ / ↓ | ターゲット（スコアの比較相手）を切り替える |

**E2** を押している間はアシスト、**E1 と E2** を同時に押している間はそのほかの詳細オプションが表示されます。
表示や操作はスキンによって異なる場合があります。各オプションの意味は[プレイオプション](05-play-options.md)を参照してください。

### そのほかの操作

| キー | 操作 |
| --- | --- |
| F3 | 選んでいる譜面のファイルの場所を開く |
| F10 | 選んでいるフォルダの曲をオートプレイで流す |
| F11 | 選んでいる譜面の IR ページをブラウザで開く |
| 4 / 5 | 保存したリプレイを選ぶ／再生する |
| 6 | キーコンフィグを開く |
| 9 | 曲に付属するテキストファイルを開く |

## プレイ画面

| キー | 操作 |
| --- | --- |
| ← / → | ハイスピードを下げる／上げる |
| ↑ / ↓ | レーンカバー（SUDDEN+ など）を動かす |
| E2 を押しながら ↑ / ↓ | レーンカバーを少しずつ動かす |
| マウスホイール | レーンカバーを動かす（E2 を押しながらだと少しずつ） |
| E1 を押しながら鍵盤 | ハイスピードを変える |
| E1 を押しながらスクラッチ | レーンカバーを動かす |
| E2 を押しながら鍵盤・スクラッチ | 緑数字を変える（FLOATING が使えるとき） |
| E1 を 2 回押す | SUDDEN+ を表示する／隠す |
| E1 と E2 を同時押し | ハイスピードの方式（FLOATING など）を切り替える |
| 3 / 9 | 表示タイミングを 1 ms ずつずらす |
| 0 | 自動判定調整を ON / OFF にする |
| Esc | プレイをやめる |
| E1 と E2 を長押し | プレイをやめる |

途中で閉店（ゲージが 0 になって終了）したときは、演出中に **E1** を押すと別の配置で、**E2** を押すと同じ配置ですぐにやり直せます。

ハイスピードと緑数字については[プレイオプション](05-play-options.md)、表示タイミングについては[判定タイミングと遅延の調整](06-timing.md)を参照してください。

### オートプレイ・リプレイ再生中

上段の数字キー **1 / 2 / 3 / 4** を押している間、再生速度が 25% / 50% / 200% / 300% になります。離すと元の速度に戻ります。

## リザルト画面

| キー | 操作 |
| --- | --- |
| Enter、Esc、KEY1〜KEY4 | 選曲画面に戻る |
| R | 同じ配置でもう一度遊ぶ |
| KEY7 を押したまま待つ | 同じ配置でもう一度遊ぶ |
| KEY5 を押したまま待つ | 別の配置でもう一度遊ぶ |
| KEY6 | ゲージのグラフの表示を切り替える |
| 1 / 2 / 3 / 4 | リプレイをスロット 1〜4 に保存する |
| F11 | プレイした譜面の IR ページをブラウザで開く |

対応しているスキンでは、**E2** で IR ランキングとグラフの表示を切り替えられます。

## コース

コースでは、2曲目以降の開始前にプレイをやめると、完了済みの曲を集計したFAILEDのコースリザルトを表示します。未開始曲のプレイ回数は増えません。1曲目の開始前なら選曲画面へ戻ります。
曲間リザルトではRやKEY5・KEY7も次の曲へ進む操作になります。コース最終リザルトのリトライは1曲目からやり直します。譜面を確認できずリトライに失敗した場合は、元のリザルトとエラーを表示します。
閉店演出中のクイックリトライはコースでは使えません。

## プラクティス

選曲画面でプレイの種類をプラクティスにして曲を決定すると、練習用の設定画面が開きます。
練習する区間・ゲージ・再生速度（50〜200%）などを指定して、同じ区間を繰り返し練習できます。
プラクティスのスコアは保存されません。

| キー | 操作 |
| --- | --- |
| ↑ / ↓ | 項目を選ぶ |
| ← / → | 値を変える |
| Enter | 区間プレイを始める |
| Esc | 選曲画面に戻る |
