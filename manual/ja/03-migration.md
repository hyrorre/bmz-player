# LR2・beatoraja から移行する

LR2 や beatoraja を使っていた方向けに、曲・スコア・スキンを BMZ Player へ引き継ぐ手順を説明します。
元のソフトのファイルは変更しないので、移行後も LR2 や beatoraja をそのまま使えます。

## 1. 曲フォルダを登録する

最初に、LR2 や beatoraja で使っていた BMS のフォルダを BMZ Player にも登録します。
設定 → **ライブラリ** → **曲フォルダ (BMS)** で、同じフォルダを追加してください。
曲ファイルをコピーする必要はありません。

**スコアを取り込む前に、曲の読み込みが終わるまで待ってください。**
LR2 のスコアは、BMZ Player が読み込んだ譜面と照合して取り込むため、
読み込まれていない譜面のスコアは取り込まれません。

## 2. スコアを取り込む

設定 → **データ移行** →「スコアインポート」で取り込みます。

1. 「ファイルを選択…」を押し、元のソフトのスコアファイルを選びます。

   | 元のソフト | 選ぶファイル |
   | --- | --- |
   | LR2 | `LR2files/Database/Score/<プレイヤー名>.db` |
   | beatoraja | `player/<プレイヤー名>/score.db` |
   | LR2oraja | beatoraja と同じ場所の `score.db` |

2. その右の欄で、元のソフトの種類を選びます。
3. 「入力デバイス」で、そのスコアをキーボードとコントローラーのどちらで出したかを選びます。
4. 「インポート」を押します。

取り込んだ件数と、取り込めなかった件数が表示されます。

取り込んだスコアを IR にも載せたいときは、[IR に参加する](02-setup.md)のあとで、設定 → **IR** の「ローカルスコアを一括送信」を使います。

### 取り込んだスコアが見つからないとき

BMZ Player では、ルール（判定やゲージの仕組み）ごとにスコアを分けて保存しています。
取り込んだスコアは、元のソフトに合わせて次のルールで保存されます。

| 元のソフト | 保存されるルール |
| --- | --- |
| beatoraja | beatoraja |
| LR2、LR2oraja | LR2oraja |
| LR2oraja（DX Mode） | DX MODE |

選曲画面にスコアが表示されないときは、設定 → **プレイ** の「ルール」が取り込んだときのルールになっているか確認してください。
ルールについては[プレイオプション](05-play-options.md)を参照してください。

## 3. リプレイを取り込む（beatoraja）

beatoraja のリプレイも取り込めます。
設定 → **データ移行** で上部の切り替えを「リプレイ取り込み」にし、
beatoraja の `player/<プレイヤー名>` フォルダ、`replay` フォルダ、または `.brd` ファイルを 1 つ指定して取り込みます。

## 4. スキンを移す

beatoraja で使っていたスキンは、BMZ Player でもそのまま使えます。

1. 設定 → **スキン** →「追加スキンのフォルダーを開く」を押します。
2. beatoraja の `skin` フォルダから、使っていたスキンをフォルダごとコピーします。
   スキンが別のフォルダのフォントや画像を使っている場合は、それもコピーしてください。
3. 「スキン一覧を更新」を押し、左で画面を選んでから右でスキンを選びます。

スキンのオプションは引き継がれないので、必要に応じて設定し直してください。

## 5. 設定を見直す

キーの割り当て・ハイスピード・判定タイミングは引き継がれません。
[初期セットアップ](02-setup.md)の「キーやコントローラーを設定する」と[判定タイミングと遅延の調整](06-timing.md)を参考に設定してください。

### LR2・beatoraja との主な違い

- 設定は **F1** キーで開く設定ウィンドウにまとまっています。ランチャーはありません。
- ハイスピードの方式が 5 種類あります。LR2 や beatoraja と同じ感覚で遊びたい場合の選び方は[プレイオプション](05-play-options.md)を参照してください。
- ロングノートを LN・CN・HCN のどれとして遊ぶかを選べます。LN の種類ごとにスコアが分けて保存されます。
