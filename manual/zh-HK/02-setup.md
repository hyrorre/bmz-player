# 初始設定

本頁介紹從下載 BMZ Player 到遊玩第一首歌曲的步驟。
請從上到下依序進行。已經設定好的項目可以略過。

## 1. 下載 BMZ Player

從 [GitHub Releases](https://github.com/hyrorre/bmz-player/releases) 下載適合所用作業系統的檔案。

| 作業系統 | 檔案 | 說明 |
| --- | --- | --- |
| Windows | `...-windows-x64-setup.exe` | 安裝程式。不確定時請選擇此項 |
| Windows | `...-windows-x64-portable.zip` | 解壓縮即可使用的版本。設定與成績儲存在解壓縮後資料夾的 `data` 中 |
| macOS（Apple 晶片） | `...-macos-arm64.app.zip` | 適用於 M1 及更新的 Mac |
| macOS（Intel） | `...-macos-x64.app.zip` | 適用於 Intel 處理器的 Mac |
| Linux | `...-linux-x64.tar.gz` | 解壓縮後執行 `./bmz-player` |
| Linux | `...-linux-x64.flatpak` | Flatpak 版 |

`sources`、`SHA256SUMS` 等檔案在單純遊玩時不需要。

### 執行環境

- **Windows**：Windows 10 以上
- **macOS**：macOS 10.13 以上
- **Linux**：相當於 Ubuntu 22.04 以上的 x86_64 環境。需要支援 Vulkan 的顯示卡驅動程式。

### macOS 顯示「無法開啟」時

BMZ Player 未經過 Apple 公證，首次開啟時可能出現警告。
請將解壓縮得到的 `.app` 移到「應用程式」等資料夾後，
依照 [Apple 的說明](https://support.apple.com/zh-hk/102445)開啟。

## 2. 啟動並確認畫面

啟動 BMZ Player 後會顯示選曲畫面。
其中已隨附 1 首用於確認運作的範例歌曲，可以選擇並試玩。

- 用 **↑ / ↓** 移動游標，**Enter** 決定，**←** 關閉資料夾。
- 7 鍵時，按鍵為 **Z S X D C F V**，轉盤為 **左 Shift / 左 Ctrl**。
- 要結束時，請在選曲畫面的最上層長按 **Esc**。在資料夾中時，每按一次 Esc 關閉一層資料夾。

設定可以在按 **F1** 開啟的「BMZ 選單」中變更。
從左側清單選擇項目，右側會顯示對應的設定。
設定變更後會自動儲存，不需要按儲存按鈕。

## 3. 登錄歌曲資料夾

決定存放 BMS 的資料夾，並登錄到 BMZ Player。

1. 在電腦的任意位置建立存放 BMS 的資料夾（例如 `D:\BMS`）。
2. 將下載的歌曲放入該資料夾。每首歌曲放在一個資料夾中。也可以依類型等分成多層。
3. 在 設定 → **曲庫** → **歌曲資料夾（BMS）** 中按「選擇資料夾…」，選擇剛才建立的資料夾並新增。

新增的資料夾會自動讀取，歌曲會顯示在選曲畫面中。
之後增加歌曲時，請在選曲畫面選擇該資料夾並按 **F5**，
或按 設定 → 曲庫 →「重新掃描曲庫」。

### 取得歌曲的途徑

- **BMS 搜尋網站**：可以依曲名或作者名尋找發布頁面。
- **BMS 活動**：可以從 BMS OF FIGHTERS（BOF）等活動的會場頁面一次下載參賽作品。
- **難度表**：也可以透過下一步介紹的難度表，尋找想玩的難度的歌曲。

有些歌曲還會另外發布稱為「差分」的追加譜面。
將差分放入原歌曲的資料夾後即可選擇。

## 4. 使用難度表

難度表是玩家們將 BMS 譜面依難度排列的列表。
BMZ Player 已預先登錄常用的難度表。
開啟選曲畫面中的「難度表」資料夾，歌曲會依表中的等級排列。

如需使用其他難度表，請在 設定 → **難度表** 中輸入難度表的 URL 並新增。

難度表中也會顯示尚未擁有的譜面。
選擇尚未擁有的譜面並決定後，會在瀏覽器中開啟該譜面的取得頁面。
將取得的歌曲放入歌曲資料夾並重新掃描後即可遊玩。

## 5. 設定按鍵與控制器

初始指派如下：

| 操作 | 鍵盤 |
| --- | --- |
| 7 鍵的按鍵 | Z S X D C F V |
| 7 鍵的轉盤 | 左 Shift（上）/ 左 Ctrl（下） |
| 14 鍵 2P 側的按鍵 | M K , L . ; / |
| 14 鍵 2P 側的轉盤 | 右 Shift / 右 Ctrl |
| 9 鍵（PMS） | Z S X D C F V G B |
| E1 / E2 / E3 / E4 | Q / W / E / R |

E1～E4 是相當於 beatoraja 中 START / SELECT 的輔助按鈕，用於變更選項等。

要變更指派，請開啟 設定 → **按鍵設定**。

1. 在「對象」中選擇要變更的按鍵數（如 7K）或畫面。
2. 在「輸入欄位」中選擇鍵盤或控制器。
3. 按下要變更的操作右側的按鈕，再按下要指派的按鍵或按鈕。

按 Esc 取消，按 Delete 或 Backspace 解除指派。
控制器沒有反應時，請在 設定 → **輸入裝置** 中確認是否已連線。

## 6. 確認聲音

沒有聲音或聲音中斷時，請在 設定 → **音訊** 中確認輸出位置。

1. 在「輸出裝置」中選擇所用的喇叭或耳機。
2. 按「套用」。音訊設定在按「套用」之前不會生效。

聲音聽起來有延遲時，減少「緩衝區大小」可能會有所改善。
過小會導致聲音斷斷續續，請在不斷音的範圍內調整。

## 7. 調整判定時機

覺得音符、聲音與操作的時機不一致時，請進行調整。
在遊玩中按 **0** 鍵會開啟自動判定調整，遊玩幾首歌後偏差會得到修正。
詳情請參閱[判定時機與延遲調整](06-timing.md)。

## 8. 選擇介面

BMZ Player 隨附以下介面：

- **m-select**：選曲、決定、結算畫面，以及遊玩畫面（antique、brand-new）
- **Rm-skin**：4 鍵到 9 鍵的遊玩畫面
- **Luxe Flat**：選曲、決定、結算畫面

在 設定 → **外觀** 中選擇「目標畫面」（選曲、7K 遊玩畫面等），再選擇要使用的介面即可變更。
各介面提供的選項也可以在同一畫面中變更。

### 加入其他介面

1. 按 設定 → 外觀 →「開啟額外介面資料夾」。
2. 將取得的介面整個資料夾放入開啟的資料夾中。ZIP 請先解壓縮再放入。
3. 按「重新整理介面清單」，再為每個畫面選擇加入的介面。

BMZ Player 可以讀取 beatoraja 用的介面（JSON、Lua）與 LR2 用的介面（CSV）。

## 9. 參加網絡排名（IR）

參加 IR 後，可以將成績登錄到線上排名，與其他玩家比較。是否參加由你決定。

1. 在 [BMZ IR](https://bmz-player.hyrorre.workers.dev/zh-HK) 中透過「註冊」建立帳號。
2. 在 BMZ Player 的 設定 → **IR** 中，在 BMZ IR 一欄輸入電郵與密碼，按「登入」。

登入後，之後遊玩的成績會自動送出。
BMZ Player 也支援 rianIR 與 BMS-IR，可以在同一畫面登入。

### 批次傳送與取得過去的成績

在 設定 → **IR** 的「成績批次操作」中，可以進行以下操作。

- 「批次傳送本機成績」：把儲存在這台電腦上的成績一次傳送到主要 IR。想把從 LR2 或 beatoraja 匯入的成績登錄到 IR 時使用。
- 「從 IR 取得成績」：把儲存在 IR 上的個人成績匯入這台電腦。想讓在其他電腦上遊玩的成績保持一致時使用。

按下按鈕會開啟確認視窗。批次傳送時會顯示要傳送的成績數量和所需時間的大致參考。確認內容後按「開始」即可開始。

- 成績較多時，可能需要幾分鐘到幾十分鐘以上。進度顯示在同一畫面，關閉設定視窗後處理仍會繼續。
- 可以隨時按「中斷」停止。再次執行時會從中斷處繼續。
- 執行期間無法切換設定檔。
- 批次操作只能用於主要 IR。批次傳送本機成績僅限 BMZ IR，取得成績可用於 rianIR 以外的 IR。未登入時無法按下按鈕。

完成後會通知結果。

### 查看並重新傳送傳送失敗的成績

批次操作下方是「IR 傳送佇列」，列出等待傳送、傳送中和傳送失敗的成績，一開始只顯示傳送失敗的成績。可以用「顯示」切換篩選條件，用「重新載入」更新到最新狀態。

- 每一列顯示類型、譜面、狀態、嘗試次數、下次重試時間和最後的錯誤。
- 按失敗列的「重新傳送」，會立即重新傳送該筆成績。
- 按「全部重新傳送失敗項目」，確認後會依序重新傳送傳送失敗的成績。

傳送失敗的成績也會隔一段時間自動重試。網路問題解決後想不等待直接重新傳送時，請使用這些按鈕。其他處理正在傳送的成績，會在該處理結束後傳送。

設定到此完成。操作方式請參閱[基本操作](04-controls.md)。
