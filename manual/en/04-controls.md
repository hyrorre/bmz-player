# Basic controls

This page lists the main controls on the song select, play, and result screens.
Keys are shown with their default bindings. You can change them in Settings → **Key Config**.

In the tables, KEY1 to KEY7 are the 7-key keys counted from the left, and E1 to E4 are the extra buttons.
By default, KEY1 to KEY7 are **Z S X D C F V**, and E1 to E4 are **Q W E R**.

## On any screen

| Key | Action |
| --- | --- |
| F1 | Open or close the BMZ Menu (settings and tools) |
| F12 | Save a screenshot |

## Song select

### Choose a song

| Key | Action |
| --- | --- |
| Up / Down, turntable | Move the cursor |
| PageUp / PageDown | Move one page |
| Enter, Right, KEY1 / KEY3 / KEY5 / KEY7 | Confirm (open a folder or start a song) |
| Left, KEY2 / KEY4 / KEY6 | Close the folder |
| / | Search for songs |
| Esc (hold) | Quit BMZ Player |

You can also use the mouse. Scroll the wheel to move the cursor, click the selected row to confirm, and right-click to close the folder.

### Change the list

| Key | Action |
| --- | --- |
| 0 | Filter by difficulty |
| 1 | Filter by key mode (7K, 14K, 9K, and so on) |
| 2 | Change the sort order |
| 3 | Change the LN mode |
| F8 / F9 | Add or remove the song or chart from favorites |
| F5 | Reload the selected folder (in a difficulty table, fetch the table again) |

### Change options

While you hold **E1**, the option panel is shown. Keep holding it and press keys to change settings.

| Key | While holding E1 |
| --- | --- |
| KEY1 / KEY2 | Change the arrangement (RANDOM and so on) |
| KEY3 / KEY4 | Change the gauge |
| KEY5 | Change HS-FIX |
| KEY6 | Change the DP option |
| KEY7 | Change the play type (normal, practice, autoplay, and so on) |
| Turntable, Up / Down | Change the target (the score you compare against) |

Hold **E2** for assist options, or hold **E1 and E2** together for other detailed options.
The display and controls may differ depending on the skin. See [Play options](05-play-options.md) for what each option means.

### Other actions

| Key | Action |
| --- | --- |
| F3 | Open the location of the selected chart file |
| F10 | Autoplay the songs in the selected folder |
| F11 | Open the selected chart's IR page in your browser |
| 4 / 5 | Choose / play a saved replay |
| 6 | Open Key Config |
| 9 | Open the text file included with the song |

## Play screen

| Key | Action |
| --- | --- |
| Left / Right | Lower / raise hi-speed |
| Up / Down | Move the lane cover (SUDDEN+ and so on) |
| Hold E2 + Up / Down | Move the lane cover in small steps |
| Mouse wheel | Move the lane cover (in small steps while holding E2) |
| Hold E1 + keys | Change hi-speed |
| Hold E1 + turntable | Move the lane cover |
| Hold E2 + keys or turntable | Change the green number (when FLOATING is available) |
| Press E1 twice | Show or hide SUDDEN+ |
| Press E1 and E2 together | Switch the hi-speed mode (such as FLOATING) |
| 3 / 9 | Shift the visual timing by 1 ms |
| 0 | Turn automatic timing adjustment on or off |
| Esc | Quit the song |
| Hold E1 and E2 | Quit the song |

If you fail partway through (the gauge reaches 0), press **E1** during the failure animation to retry right away with a new arrangement, or **E2** to retry with the same arrangement.

See [Play options](05-play-options.md) for hi-speed and the green number, and [Timing and latency](06-timing.md) for visual timing.

### During autoplay or replay

While you hold **1 / 2 / 3 / 4** on the number row, playback speed becomes 25% / 50% / 200% / 300%. Release the key to return to normal speed.

## Result screen

| Key | Action |
| --- | --- |
| Enter, Esc, KEY1 to KEY4 | Return to song select |
| R | Play again with the same arrangement |
| Keep holding KEY7 | Play again with the same arrangement |
| Keep holding KEY5 | Play again with a new arrangement |
| KEY6 | Change the gauge graph display |
| 1 / 2 / 3 / 4 | Save the replay to slot 1 to 4 |
| F11 | Open the played chart's IR page in your browser |

With supported skins, **E2** switches between the IR ranking and the graph.

## Practice

Set the play type to practice on the song select screen and confirm a song to open the practice settings.
You can choose a section, gauge, playback speed (50 to 200%), and more, then practice the same section repeatedly.
Practice scores are not saved.

| Key | Action |
| --- | --- |
| Up / Down | Select an item |
| Left / Right | Change the value |
| Enter | Start the section |
| Esc | Return to song select |
