# 문제 해결

자주 있는 증상과 대처 방법입니다. 해결되지 않으면 이 페이지 마지막의 방법으로 알려 주세요.

## 실행·표시

### 실행되지 않거나 바로 종료된다

- **Windows**: 그래픽 드라이버를 최신으로 하세요. 오래된 Windows에서는 Vulkan 드라이버가 필요할 수 있습니다.
- **macOS**: '열 수 없습니다'라고 표시되면 [초기 설정](02-setup.md)의 'macOS에서 '열 수 없습니다'라고 표시될 때'를 참고하세요.
- **Linux**: Vulkan을 지원하는 그래픽 드라이버가 필요합니다. tar.gz 버전은 압축을 푼 폴더의 `./bmz-player`로 실행하세요.

### 화면이 끊기거나 움직임이 매끄럽지 않다

설정 → **영상**에서 '프레임 지연'을 '안정'으로 하거나, '목표 FPS'를 모니터의 주사율에 맞추세요.
다른 앱을 닫으면 나아지기도 합니다.

### 스킨이 표시되지 않거나 깨진다

설정 → **스킨**에서 그 스킨에 읽기 오류가 표시되지 않았는지 확인하세요.
스킨의 일부 폴더(글꼴이나 이미지)가 빠져 있으면 제대로 표시되지 않습니다.
스킨은 폴더째로, 배포된 구성 그대로 두세요.

## 곡·난이도표

### 곡이 표시되지 않는다

- 설정 → **라이브러리**에서 곡을 넣은 폴더가 등록되어 있는지 확인하세요.
- 곡을 추가한 뒤에는 선곡 화면에서 **F5**를 누르거나 '라이브러리 다시 스캔'을 누르세요.
- 1곡을 1폴더로 두었는지 확인하세요. 채보 파일(.bms 등)과 음성 파일이 같은 폴더에 있어야 합니다.
- 선곡 화면에서 **0**(난이도)이나 **1**(건반 수) 거르기가 켜져 있지 않은지 확인하세요.

### 난이도표에 곡이 없거나 표가 갱신되지 않는다

선곡 화면에서 난이도표 폴더를 고르고 **F5**를 누르면 표를 다시 가져옵니다.
난이도표에 실려 있어도 채보를 갖고 있지 않으면 플레이할 수 없습니다. 갖고 있지 않은 채보를 골라 결정하면 구하는 곳이 브라우저로 열립니다.

## 소리

### 소리가 나지 않는다

1. 설정 → **오디오**의 '출력 장치'에서 사용하는 기기가 선택되어 있는지 확인합니다.
2. '장치 목록 새로 고침'을 누른 뒤 다시 고르고 '적용'을 누릅니다.
3. 같은 화면의 '음량'에서 마스터 음량 등이 0이 아닌지 확인합니다.

기기를 뺐다 꽂은 뒤 소리가 나지 않을 때도 '적용'을 누르면 나아질 수 있습니다.

### 소리가 끊기거나 뚝뚝거린다

설정 → **오디오**의 '버퍼 크기'를 크게 하세요.

### 소리가 늦게 들린다

[판정 타이밍과 지연 조정](06-timing.md)을 참고하세요.

## 입력

### 키보드나 컨트롤러가 반응하지 않는다

- 설정 → **입력 장치**에서 컨트롤러가 연결됨으로 표시되는지 확인하세요.
- 설정 → **키 구성**에서 플레이하는 건반 수(7K 등)의 할당을 확인하세요. 건반 수마다 할당이 나뉘어 있습니다.
- 할당 옆에 경고 아이콘이 나오면 다른 조작과 같은 키가 할당되어 있습니다.

### 스크래치가 잘 반응하지 않거나 너무 많이 돈다

설정 → **입력 장치**에서 '아날로그 스크래치'와 '아날로그 감도'를 조정하세요.

## 점수·IR

### 점수가 저장되지 않는다

오토 플레이·리플레이 재생·프랙티스·건반 수를 변환한 플레이의 점수는 저장되지 않습니다.
어시스트의 효과가 난 경우에는 ASSIST 클리어 기록만 저장됩니다.

### 가져온 점수나 예전 점수가 보이지 않는다

점수는 규칙과 LN 모드의 조합마다 따로 저장됩니다.
설정 → **플레이**의 '규칙'과 'LN 모드'를 그 점수를 냈을 때의 설정으로 되돌리세요.

### IR에 점수가 전송되지 않는다

- 설정 → **IR**에서 로그인 상태로 표시되는지 확인하세요.
- 인터넷에 연결되지 않았던 동안의 점수는 연결이 돌아오면 자동으로 전송됩니다.
- 전송에 실패한 점수는 설정 → **IR** → '전송 대기열 열기'에서 확인하고 '다시 전송'으로 다시 보낼 수 있습니다.

## 로그와 데이터 위치

**F1**로 BMZ 메뉴를 열고 '일반'의 '디렉터리 열기'에 있는 버튼으로 폴더를 열 수 있습니다.

| 버튼 | 내용 |
| --- | --- |
| data_dir | 설정, 점수, 리플레이, 추가한 스킨 |
| logs_dir | 동작 기록(로그) |
| cache_dir | 임시 파일. 지워도 필요할 때 다시 만들어집니다 |
| resource_dir | BMZ Player에 함께 들어 있는 파일. 업데이트하면 덮어쓰입니다 |

data_dir를 백업해 두면 설정과 점수를 지킬 수 있습니다.
백업은 BMZ Player를 종료한 뒤에 하세요.

- 필요하면 스크린숏(**F12**로 저장할 수 있습니다)
