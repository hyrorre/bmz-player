# 초기 설정

BMZ Player를 내려받은 뒤 첫 곡을 플레이하기까지의 순서입니다.
위에서부터 차례로 진행하세요. 이미 설정한 항목은 건너뛰어도 됩니다.

## 1. BMZ Player 내려받기

[GitHub Releases](https://github.com/hyrorre/bmz-player/releases)에서 사용하는 OS에 맞는 파일을 내려받습니다.

| OS | 파일 | 설명 |
| --- | --- | --- |
| Windows | `...-windows-x64-setup.exe` | 설치 프로그램입니다. 잘 모르겠다면 이것을 고르세요 |
| Windows | `...-windows-x64-portable.zip` | 압축만 풀면 사용할 수 있는 버전입니다. 설정과 점수는 압축을 푼 폴더의 `data`에 저장됩니다 |
| macOS (Apple 실리콘) | `...-macos-arm64.app.zip` | M1 이후의 Mac용입니다 |
| macOS (Intel) | `...-macos-x64.app.zip` | Intel CPU를 사용하는 Mac용입니다 |
| Linux | `...-linux-x64.tar.gz` | 압축을 풀고 `./bmz-player`를 실행합니다 |
| Linux | `...-linux-x64.flatpak` | Flatpak 버전입니다 |

`sources`나 `SHA256SUMS` 같은 파일은 플레이만 한다면 필요하지 않습니다.

### 동작 환경

- **Windows**: Windows 10 이상
- **macOS**: macOS 10.13 이상
- **Linux**: Ubuntu 22.04 수준 이상의 x86_64 환경. Vulkan을 지원하는 그래픽 드라이버가 필요합니다.

### macOS에서 '열 수 없습니다'라고 표시될 때

BMZ Player는 Apple의 공증을 받지 않았기 때문에 처음 열 때 경고가 나올 수 있습니다.
ZIP을 풀어 나온 `.app`을 '응용 프로그램' 폴더 등으로 옮긴 뒤,
[Apple의 안내](https://support.apple.com/ko-kr/102445)에 따라 여세요.

## 2. 실행해서 화면 확인하기

BMZ Player를 실행하면 선곡 화면이 표시됩니다.
처음부터 동작 확인용 샘플 곡이 1곡 들어 있으니 골라서 플레이해 보세요.

- 커서 이동은 **↑ / ↓**, 결정은 **Enter**, 폴더 닫기는 **←**입니다.
- 7키의 경우 건반은 **Z S X D C F V**, 스크래치는 **왼쪽 Shift / 왼쪽 Ctrl**입니다.
- 종료하려면 선곡 화면의 최상위 계층에서 **Esc**를 길게 누릅니다. 폴더 안에서는 Esc를 누를 때마다 폴더를 닫습니다.

설정은 **F1** 키로 여는 'BMZ 메뉴'에서 바꿉니다.
왼쪽 목록에서 항목을 고르면 오른쪽에 해당 설정이 표시됩니다.
설정은 바꾸면 자동으로 저장되므로 저장 버튼을 누를 필요가 없습니다.

## 3. 곡 폴더 등록하기

BMS를 넣어 둘 폴더를 정해서 BMZ Player에 등록합니다.

1. 컴퓨터의 원하는 위치에 BMS를 넣을 폴더를 만듭니다(예: `D:\BMS`).
2. 내려받은 곡을 그 폴더에 넣습니다. 1곡을 1폴더로 둡니다. 장르별 등으로 몇 단계로 묶어도 됩니다.
3. 설정 → **라이브러리** → **곡 폴더 (BMS)**에서 '폴더 선택…'을 누르고, 만든 폴더를 골라 추가합니다.

추가한 폴더는 자동으로 읽어 들여 선곡 화면에 곡이 표시됩니다.
나중에 곡을 늘렸을 때는 선곡 화면에서 그 폴더를 고르고 **F5**를 누르거나,
설정 → 라이브러리 → '라이브러리 다시 스캔'을 누르세요.

### 곡을 구하는 곳

- **BMS 검색 사이트**: 곡 제목이나 작자 이름으로 배포 페이지를 찾을 수 있습니다.
- **BMS 이벤트**: BMS OF FIGHTERS(BOF) 등 이벤트 회장 페이지에서 참가 작품을 한꺼번에 받을 수 있습니다.
- **난이도표**: 다음 단계에서 설명하는 난이도표에서 원하는 난이도의 곡을 찾을 수도 있습니다.

곡에 따라서는 본체와 별도로 '차분'이라는 추가 채보가 배포되기도 합니다.
차분은 원래 곡의 폴더에 넣으면 고를 수 있게 됩니다.

## 4. 난이도표 사용하기

난이도표는 사용자들이 BMS 채보를 난이도 순으로 정리한 목록입니다.
BMZ Player에는 자주 쓰이는 난이도표가 처음부터 등록되어 있습니다.
선곡 화면의 '난이도표' 폴더를 열면 표의 레벨별로 곡이 늘어섭니다.

다른 난이도표를 쓰고 싶다면 설정 → **난이도표**에서 표의 URL을 입력해 추가합니다.

난이도표에는 아직 갖고 있지 않은 채보도 표시됩니다.
갖고 있지 않은 채보를 골라 결정하면 그 채보를 구하는 곳이 브라우저로 열립니다.
구한 곡을 곡 폴더에 넣고 다시 스캔하면 플레이할 수 있습니다.

## 5. 키와 컨트롤러 설정하기

처음 할당은 다음과 같습니다.

| 조작 | 키보드 |
| --- | --- |
| 7키 건반 | Z S X D C F V |
| 7키 스크래치 | 왼쪽 Shift(위) / 왼쪽 Ctrl(아래) |
| 14키 2P 쪽 건반 | M K , L . ; / |
| 14키 2P 쪽 스크래치 | 오른쪽 Shift / 오른쪽 Ctrl |
| 9버튼(PMS) | Z S X D C F V G B |
| E1 / E2 / E3 / E4 | Q / W / E / R |

E1~E4는 beatoraja의 START / SELECT에 해당하는 보조 버튼입니다. 옵션 변경 등에 사용합니다.

할당을 바꾸려면 설정 → **키 구성**을 엽니다.

1. '대상'에서 바꾸고 싶은 건반 수(7K 등)나 화면을 고릅니다.
2. '입력 슬롯'에서 키보드인지 컨트롤러인지 고릅니다.
3. 바꾸고 싶은 조작 오른쪽의 버튼을 누른 다음, 할당할 키나 버튼을 누릅니다.

Esc로 취소하고, Delete 또는 Backspace로 할당을 해제할 수 있습니다.
컨트롤러가 반응하지 않으면 설정 → **입력 장치**에서 연결되어 있는지 확인하세요.

## 6. 소리 확인하기

소리가 나지 않거나 끊길 때는 설정 → **오디오**에서 출력 대상을 확인합니다.

1. '출력 장치'에서 사용하는 스피커나 헤드폰을 고릅니다.
2. '적용'을 누릅니다. 오디오 설정은 '적용'을 누르기 전까지 반영되지 않습니다.

소리가 늦게 들리면 '버퍼 크기'를 작게 하면 나아질 수 있습니다.
너무 작게 하면 소리가 뚝뚝 끊기므로, 끊기지 않는 범위에서 조정하세요.

## 7. 판정 타이밍 맞추기

노트와 소리, 조작의 타이밍이 어긋난다고 느껴지면 조정합니다.
플레이 중에 **0** 키를 누르면 자동 판정 조정이 켜지고, 몇 곡 플레이하는 동안 어긋남이 보정됩니다.
자세한 내용은 [판정 타이밍과 지연 조정](06-timing.md)을 참고하세요.

## 8. 스킨 고르기

BMZ Player에는 다음 스킨이 함께 들어 있습니다.

- **m-select**: 선곡·결정·결과 화면과 플레이 화면(antique, brand-new)
- **Rm-skin**: 4키~9버튼 플레이 화면
- **Luxe Flat**: 선곡·결정·결과 화면

스킨은 설정 → **스킨**에서 '대상 화면'(선곡, 7K 플레이 화면 등)을 고르고 사용할 스킨을 선택해 바꿉니다.
스킨마다 준비된 옵션도 같은 화면에서 바꿀 수 있습니다.

### 다른 스킨 추가하기

1. 설정 → 스킨 → '추가 스킨 폴더 열기'를 누릅니다.
2. 열린 폴더에 구한 스킨을 폴더째로 둡니다. ZIP은 압축을 푼 뒤에 두세요.
3. '스킨 목록 새로고침'을 누르고, 화면마다 추가한 스킨을 고릅니다.

BMZ Player는 beatoraja용 스킨(JSON·Lua)과 LR2용 스킨(CSV)을 읽어 들일 수 있습니다.

## 9. 인터넷 랭킹(IR)에 참가하기

IR에 참가하면 점수를 온라인 랭킹에 등록해 다른 플레이어와 비교할 수 있습니다. 참가는 선택 사항입니다.

1. [BMZ IR](https://bmz-player.hyrorre.workers.dev/ko)의 '가입'에서 계정을 만듭니다.
2. BMZ Player의 설정 → **IR**에서 BMZ IR 항목에 이메일과 비밀번호를 입력하고 '로그인'을 누릅니다.

로그인하면 이후 플레이의 점수가 자동으로 전송됩니다.
BMZ Player는 rianIR과 BMS-IR도 지원하며, 같은 화면에서 로그인할 수 있습니다.

### 이전 점수를 한꺼번에 보내기·가져오기

설정 → **IR**의 '점수 일괄 작업'에서 다음 작업을 할 수 있습니다.

- '로컬 점수 일괄 전송': 이 PC에 저장된 점수를 기본 IR로 한꺼번에 보냅니다. LR2나 beatoraja에서 가져온 점수를 IR에 올리고 싶을 때 사용합니다.
- 'IR에서 점수 가져오기': IR에 저장된 내 점수를 이 PC로 가져옵니다. 다른 PC에서 플레이한 점수를 맞추고 싶을 때 사용합니다.

버튼을 누르면 확인 창이 열립니다. 일괄 전송에서는 보낼 점수의 개수와 걸리는 시간의 대략적인 기준이 표시됩니다. 내용을 확인하고 '시작'을 누르면 시작됩니다.

- 점수가 많으면 몇 분에서 수십 분 이상 걸립니다. 진행 상황은 같은 화면에 표시되며, 설정 창을 닫아도 작업은 계속됩니다.
- '중단'으로 언제든 멈출 수 있습니다. 다시 실행하면 이어서 진행합니다.
- 실행 중에는 프로필을 전환할 수 없습니다.
- 일괄 작업은 기본 IR에서만 사용할 수 있습니다. 로컬 점수 일괄 전송은 BMZ IR만, 점수 가져오기는 rianIR을 제외한 IR에서 사용할 수 있습니다. 로그인하지 않았을 때는 버튼을 누를 수 없습니다.

끝나면 결과가 알림으로 표시됩니다.

### 전송에 실패한 점수 확인하고 다시 보내기

일괄 작업 아래에 'IR 전송 대기열'이 있습니다. 전송 대기 중, 전송 중, 실패한 점수의 목록이며, 처음에는 실패한 점수만 표시됩니다. '표시'로 필터를 바꾸고 '새로고침'으로 최신 상태로 갱신할 수 있습니다.

- 각 행에는 종류, 채보, 상태, 시도 횟수, 다음 재시도 시각, 마지막 오류가 표시됩니다.
- 실패한 행의 '다시 전송'을 누르면 그 점수만 바로 다시 보냅니다.
- '실패한 항목 모두 다시 전송'을 누르면 확인 창이 나온 뒤 실패한 점수를 차례로 다시 보냅니다.

실패한 점수는 시간이 지나면 자동으로도 재시도됩니다. 통신 문제가 해결된 뒤 기다리지 않고 바로 다시 보내고 싶을 때 사용하세요. 다른 작업이 전송 중인 점수는 그 작업이 끝난 뒤에 전송됩니다.

이것으로 설정이 끝났습니다. 조작 방법은 [기본 조작](04-controls.md)을 참고하세요.
