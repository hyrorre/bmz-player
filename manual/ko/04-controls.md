# 기본 조작

선곡 화면·플레이 화면·결과 화면의 주요 조작입니다.
키는 처음 할당을 기준으로 적었습니다. 할당은 설정 → **키 구성**에서 바꿀 수 있습니다.

표의 KEY1~KEY7은 7키 건반을 왼쪽부터 센 번호이고, E1~E4는 보조 버튼입니다.
처음 할당에서는 KEY1~KEY7이 **Z S X D C F V**, E1~E4가 **Q W E R**입니다.

## 어느 화면에서나 쓸 수 있는 조작

| 키 | 조작 |
| --- | --- |
| F1 | BMZ 메뉴 열기·닫기(설정은 여기서 엽니다) |
| F12 | 스크린숏 저장 |

## 선곡 화면

### 곡 고르기

| 키 | 조작 |
| --- | --- |
| ↑ / ↓, 스크래치 | 커서 이동 |
| PageUp / PageDown | 한 페이지씩 이동 |
| Enter, →, KEY1·KEY3·KEY5·KEY7 | 결정(폴더 열기, 곡 시작) |
| ←, KEY2·KEY4·KEY6 | 폴더 닫기 |
| / | 곡 검색 |
| Esc(길게 누르기) | BMZ Player 종료 |

마우스로도 조작할 수 있습니다. 휠로 커서를 움직이고, 선택 중인 행을 클릭하면 결정, 오른쪽 클릭으로 폴더를 닫습니다.

### 목록 표시 바꾸기

| 키 | 조작 |
| --- | --- |
| 0 | 난이도로 거르기 |
| 1 | 건반 수로 거르기(7K, 14K, 9K 등) |
| 2 | 정렬 순서 바꾸기 |
| 3 | LN 모드 전환 |
| F8 / F9 | 즐겨찾는 곡·채보에 등록 / 해제 |
| F5 | 선택한 폴더를 다시 읽어 들이기(난이도표에서는 표를 다시 가져오기) |

### 옵션 바꾸기

**E1**을 누르고 있는 동안 옵션 패널이 표시됩니다. 누른 채로 건반을 눌러 설정을 바꿉니다.

| 건반 | E1을 누른 채로 |
| --- | --- |
| KEY1 / KEY2 | 배치(RANDOM 등) 전환 |
| KEY3 / KEY4 | 게이지 전환 |
| KEY5 | HS-FIX 전환 |
| KEY6 | DP 옵션 전환 |
| KEY7 | 플레이 종류(일반, 프랙티스, 오토 플레이 등) 전환 |
| 스크래치, ↑ / ↓ | 타깃(점수 비교 상대) 전환 |

**E2**를 누르고 있는 동안에는 어시스트, **E1과 E2**를 함께 누르고 있는 동안에는 그 밖의 상세 옵션이 표시됩니다.
표시와 조작은 스킨에 따라 다를 수 있습니다. 각 옵션의 의미는 [플레이 옵션](05-play-options.md)을 참고하세요.

### 그 밖의 조작

| 키 | 조작 |
| --- | --- |
| F3 | 선택한 채보 파일의 위치 열기 |
| F10 | 선택한 폴더의 곡을 오토 플레이로 재생 |
| F11 | 선택한 채보의 IR 페이지를 브라우저로 열기 |
| 4 / 5 | 저장한 리플레이 고르기 / 재생 |
| 6 | 키 구성 열기 |
| 9 | 곡에 딸린 텍스트 파일 열기 |

## 플레이 화면

| 키 | 조작 |
| --- | --- |
| ← / → | 하이스피드 내리기 / 올리기 |
| ↑ / ↓ | 레인 커버(SUDDEN+ 등) 움직이기 |
| E2를 누른 채 ↑ / ↓ | 레인 커버를 조금씩 움직이기 |
| 마우스 휠 | 레인 커버 움직이기(E2를 누른 채면 조금씩) |
| E1을 누른 채 건반 | 하이스피드 바꾸기 |
| E1을 누른 채 스크래치 | 레인 커버 움직이기 |
| E2를 누른 채 건반·스크래치 | 녹색 숫자 바꾸기(FLOATING을 쓸 수 있을 때) |
| E1 두 번 누르기 | SUDDEN+ 보이기 / 숨기기 |
| E1과 E2 동시에 누르기 | 하이스피드 방식(FLOATING 등) 전환 |
| 3 / 9 | 표시 타이밍을 1ms씩 옮기기 |
| 0 | 자동 판정 조정 ON / OFF |
| Esc | 플레이 그만두기 |
| E1과 E2 길게 누르기 | 플레이 그만두기 |

도중에 폐점(게이지가 0이 되어 종료)했을 때는 연출 중에 **E1**을 누르면 다른 배치로, **E2**를 누르면 같은 배치로 바로 다시 할 수 있습니다.

하이스피드와 녹색 숫자는 [플레이 옵션](05-play-options.md), 표시 타이밍은 [판정 타이밍과 지연 조정](06-timing.md)을 참고하세요.

### 오토 플레이·리플레이 재생 중

위쪽 숫자 키 **1 / 2 / 3 / 4**를 누르고 있는 동안 재생 속도가 25% / 50% / 200% / 300%가 됩니다. 떼면 원래 속도로 돌아갑니다.

## 결과 화면

| 키 | 조작 |
| --- | --- |
| Enter, Esc, KEY1~KEY4 | 선곡 화면으로 돌아가기 |
| R | 같은 배치로 다시 플레이 |
| KEY7을 누른 채 기다리기 | 같은 배치로 다시 플레이 |
| KEY5를 누른 채 기다리기 | 다른 배치로 다시 플레이 |
| KEY6 | 게이지 그래프 표시 전환 |
| 1 / 2 / 3 / 4 | 리플레이를 슬롯 1~4에 저장 |
| F11 | 플레이한 채보의 IR 페이지를 브라우저로 열기 |

지원하는 스킨에서는 **E2**로 IR 랭킹과 그래프 표시를 전환할 수 있습니다.

## 프랙티스

선곡 화면에서 플레이 종류를 프랙티스로 하고 곡을 결정하면 연습용 설정 화면이 열립니다.
연습할 구간·게이지·재생 속도(50~200%) 등을 지정해 같은 구간을 반복해서 연습할 수 있습니다.
프랙티스의 점수는 저장되지 않습니다.

| 키 | 조작 |
| --- | --- |
| ↑ / ↓ | 항목 고르기 |
| ← / → | 값 바꾸기 |
| Enter | 구간 플레이 시작 |
| Esc | 선곡 화면으로 돌아가기 |
