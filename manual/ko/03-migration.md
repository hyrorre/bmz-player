# LR2·beatoraja에서 옮겨 오기

LR2나 beatoraja를 쓰던 분을 위해 곡·점수·스킨을 BMZ Player로 옮기는 방법을 설명합니다.
원래 소프트웨어의 파일은 바꾸지 않으므로 옮긴 뒤에도 LR2나 beatoraja를 그대로 쓸 수 있습니다.

## 1. 곡 폴더 등록하기

먼저 LR2나 beatoraja에서 쓰던 BMS 폴더를 BMZ Player에도 등록합니다.
설정 → **라이브러리** → **곡 폴더 (BMS)**에서 같은 폴더를 추가하세요.
곡 파일을 복사할 필요는 없습니다.

**점수를 가져오기 전에 곡을 다 읽어 들일 때까지 기다리세요.**
LR2 점수는 BMZ Player가 읽어 들인 채보와 대조해서 가져오므로,
읽어 들이지 않은 채보의 점수는 가져오지 않습니다.

## 2. 점수 가져오기

설정 → **데이터 가져오기** → '점수 가져오기'에서 가져옵니다.

1. '파일 선택…'을 누르고 원래 소프트웨어의 점수 파일을 고릅니다.

   | 원래 소프트웨어 | 고를 파일 |
   | --- | --- |
   | LR2 | `LR2files/Database/Score/<플레이어 이름>.db` |
   | beatoraja | `player/<플레이어 이름>/score.db` |
   | LR2oraja | beatoraja와 같은 위치의 `score.db` |

2. 오른쪽 칸에서 원래 소프트웨어의 종류를 고릅니다.
3. '입력 장치'에서 그 점수를 키보드와 컨트롤러 중 무엇으로 냈는지 고릅니다.
4. '가져오기'를 누릅니다.

가져온 건수와 가져오지 못한 건수가 표시됩니다.

가져온 점수를 IR에도 올리고 싶다면 [인터넷 랭킹(IR)에 참가하기](02-setup.md)에서 로그인한 뒤, 설정 → **IR**의 '로컬 점수 일괄 전송'을 사용하세요.

### 가져온 점수가 보이지 않을 때

BMZ Player는 규칙(판정과 게이지의 구조)마다 점수를 따로 저장합니다.
가져온 점수는 원래 소프트웨어에 맞춰 다음 규칙으로 저장됩니다.

| 원래 소프트웨어 | 저장되는 규칙 |
| --- | --- |
| beatoraja | beatoraja |
| LR2, LR2oraja | LR2oraja |
| LR2oraja (DX Mode) | DX MODE |

선곡 화면에 점수가 보이지 않으면 설정 → **플레이**의 '규칙'이 가져올 때의 규칙으로 되어 있는지 확인하세요.
규칙에 대해서는 [플레이 옵션](05-play-options.md)을 참고하세요.

## 3. 리플레이 가져오기(beatoraja)

beatoraja의 리플레이도 가져올 수 있습니다.
설정 → **데이터 가져오기**에서 위쪽의 전환을 '리플레이 가져오기'로 하고,
beatoraja의 `player/<플레이어 이름>` 폴더, `replay` 폴더 또는 `.brd` 파일 하나를 지정해 가져옵니다.

## 4. 스킨 옮기기

beatoraja에서 쓰던 스킨은 BMZ Player에서도 그대로 쓸 수 있습니다.

1. 설정 → **스킨** → '추가 스킨 폴더 열기'를 누릅니다.
2. beatoraja의 `skin` 폴더에서 쓰던 스킨을 폴더째로 복사합니다.
   스킨이 다른 폴더의 글꼴이나 이미지를 쓴다면 그것도 복사하세요.
3. '스킨 목록 새로고침'을 누르고 왼쪽에서 화면, 오른쪽에서 스킨을 고릅니다.

스킨 옵션은 옮겨지지 않으므로 필요하면 다시 설정하세요.

## 5. 설정 다시 보기

키 할당·하이스피드·판정 타이밍은 옮겨지지 않습니다.
[초기 설정](02-setup.md)의 '키와 컨트롤러 설정하기'와 [판정 타이밍과 지연 조정](06-timing.md)을 참고해 설정하세요.

### LR2·beatoraja와의 주요 차이

- 설정은 **F1** 키로 여는 설정 창에 모여 있습니다. 런처는 없습니다.
- 하이스피드 방식이 5가지 있습니다. LR2나 beatoraja와 같은 감각으로 플레이하고 싶을 때의 선택 방법은 [플레이 옵션](05-play-options.md)을 참고하세요.
- 롱노트를 LN·CN·HCN 중 무엇으로 플레이할지 고를 수 있습니다. LN 종류마다 점수가 따로 저장됩니다.
