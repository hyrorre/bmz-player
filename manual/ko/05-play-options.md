# 플레이 옵션

플레이의 난이도나 보이는 방식을 바꾸는 옵션의 설명입니다.
옵션은 선곡 화면에서 **E1** 등을 눌러 표시하는 옵션 패널이나, 설정 → **플레이**에서 바꿀 수 있습니다.

잘 모르겠다면 처음 설정 그대로 플레이를 시작해도 됩니다.

## 게이지

게이지는 플레이 중의 상태를 나타내는 미터입니다. 판정이 좋으면 오르고, 미스하면 내려갑니다.
종류에 따라 오르고 내리는 방식과 클리어 조건이 달라집니다.

| 게이지 | 특징 |
| --- | --- |
| ASSIST EASY | 가장 잘 줄지 않는 게이지입니다. 클리어해도 EASY보다 아래 기록으로 취급됩니다 |
| EASY | NORMAL보다 잘 줄지 않는 게이지입니다 |
| NORMAL | 표준 게이지입니다 |
| HARD | 가득 찬 상태에서 시작하며, 0이 되면 그 자리에서 종료(폐점)합니다 |
| EX-HARD | HARD보다 더 잘 줄어드는 게이지입니다 |
| HAZARD | 콤보가 끊기면 폐점합니다 |

ASSIST EASY·EASY·NORMAL은 곡이 끝날 때 게이지가 클리어 선 이상이면 클리어입니다.
HARD·EX-HARD·HAZARD는 폐점하지 않고 끝까지 플레이하면 클리어입니다.

처음이라면 NORMAL부터 시작하고, 클리어가 어려운 곡에서는 EASY나 ASSIST EASY를 쓰기를 추천합니다.

### 게이지 오토 시프트(GAS)

폐점했을 때 다른 게이지로 바꿔 계속 플레이하는 기능입니다. 처음에는 OFF로 되어 있습니다.

| 방식 | 내용 |
| --- | --- |
| OFF | 바꾸지 않습니다. HARD 등에서 폐점하면 그 자리에서 종료합니다 |
| CONTINUE | 폐점해도 곡 끝까지 플레이할 수 있습니다. 기록은 고른 게이지 그대로입니다 |
| HARD->GROOVE | HARD 등에서 폐점하면 NORMAL로 바꿔 계속 플레이합니다 |
| BEST CLEAR | 모든 게이지를 동시에 계산하고, 클리어한 것 중 가장 높은 게이지를 기록합니다 |
| SELECT UNDER | 고른 게이지와 그 아래 게이지를 동시에 계산하고, 클리어한 것 중 가장 높은 게이지를 기록합니다 |

예를 들어 BEST CLEAR에서는 도중에 EX-HARD 조건을 만족하지 못하게 되어도 HARD나 NORMAL로 클리어했다면 그 기록이 남습니다.
'GAS 최소 게이지'로 어디까지 아래 게이지를 기록 대상으로 할지 정할 수 있습니다.

## 배치(RANDOM 등)

건반에 떨어지는 노트의 배치를 바꿉니다. 같은 채보라도 다른 배치로 연습할 수 있습니다.

| 배치 | 내용 |
| --- | --- |
| OFF | 채보대로 떨어집니다 |
| MIRROR | 좌우를 뒤집습니다 |
| RANDOM | 레인 배치를 플레이마다 무작위로 바꿉니다 |
| R-RANDOM | 레인 순서를 유지한 채 옆으로 밉니다 |
| S-RANDOM | 노트 하나하나를 무작위 레인에 나눕니다 |
| SPIRAL | 레인 배치를 조금씩 회전하듯이 바꿔 갑니다 |
| H-RANDOM | S-RANDOM과 같지만, 같은 레인에 짧은 간격으로 노트가 이어지지 않게 합니다 |
| ALL-SCR | 가능한 한 많은 노트를 스크래치로 모읍니다 |
| RANDOM-EX / S-RANDOM-EX | 스크래치까지 포함해 바꿉니다 |
| F-RANDOM | 건반을 왼쪽 절반과 오른쪽 절반으로 나누어 각각 안에서 배치를 바꿉니다. 7키에서는 가운데 건반은 움직이지 않습니다 |
| MF-RANDOM | F-RANDOM 배치를 다시 좌우로 뒤집습니다 |

S-RANDOM처럼 노트를 하나씩 나누는 배치에서는 채보가 원래 모양과 크게 달라질 수 있습니다.

## 하이스피드

노트가 떨어지는 속도입니다. 빠르게 하면 노트 간격이 넓어져 보기 쉬워지지만, 반응할 시간은 짧아집니다.
플레이 중에 **← / →** 키나 **E1을 누른 채 건반**으로 바꿀 수 있습니다.

### 녹색 숫자

노트가 화면 위에 나타나서 판정선에 닿기까지의 시간을 나타내는 숫자입니다.
값은 밀리초의 0.6배로, 예를 들어 녹색 숫자 300은 0.5초입니다. 숫자가 작을수록 빠르게 보입니다.
BPM이 다른 곡이라도 녹색 숫자가 같으면 같은 속도로 보입니다.

### 하이스피드 방식(HS 설정)

| 방식 | 내용 |
| --- | --- |
| NORMAL | 20단계 중에서 고릅니다. 단계마다 녹색 숫자가 정해져 있습니다 |
| CLASSIC | 배율을 직접 지정합니다. LR2나 beatoraja의 일반 하이스피드와 같은 방식입니다 |
| FLOATING | 녹색 숫자를 지정하면 곡의 BPM에 맞춰 배율을 자동으로 정합니다 |
| NORMAL+FLOATING | NORMAL과 FLOATING을 플레이 중에 전환할 수 있습니다 |
| CLASSIC+FLOATING | CLASSIC과 FLOATING을 플레이 중에 전환할 수 있습니다(처음 설정) |
| LR2 | CLASSIC처럼 배율을 직접 지정합니다(배율은 CLASSIC과 공통). HS-FIX를 사용할 때는 배율을 BPM 150에서의 속도로 취급합니다(LR2와 같음) |

전환할 수 있는 방식에서는 플레이 중에 **E1과 E2를 동시에 누르면** 전환됩니다.
FLOATING일 때는 **E2를 누른 채 건반이나 스크래치**로 녹색 숫자를 바꿉니다.

곡마다 속도를 다시 맞추기가 번거롭다면 FLOATING이 편리합니다.

### HS-FIX

곡 도중에 BPM이 바뀔 때 어느 BPM을 기준으로 속도를 정할지 고릅니다.
예를 들어 '최대 BPM'으로 하면 곡에서 가장 빠른 부분에 맞춰 속도를 정합니다.

## 레인 커버

레인의 일부를 가려 노트가 보이는 범위를 조정합니다.
빠른 노트를 보기 쉽게 하거나, 보이는 위치를 눈높이에 맞추는 데 씁니다.

| 종류 | 내용 |
| --- | --- |
| SUDDEN+ | 레인 위쪽을 가립니다 |
| HIDDEN+ | 레인 아래쪽(판정선 근처)을 가립니다 |
| LIFT | 판정선을 위로 올립니다 |

사용할 커버는 설정 → **플레이**의 '표시'에서 건반 수마다 켭니다.
플레이 중에는 **↑ / ↓** 키나 **E1을 누른 채 스크래치**로 양을 바꿉니다.
**E1을 두 번 누르면** SUDDEN+를 보이거나 숨길 수 있습니다.

'레인 커버 변경 시 현재 BPM에 맞춰 HS 자동 조정'을 켜면 커버를 움직여도 녹색 숫자가 바뀌지 않도록 하이스피드를 조정합니다.

## LN 모드

길게 누르는 노트(롱노트)의 판정 방법을 고릅니다.

| 종류 | 내용 |
| --- | --- |
| LN | 누르기 시작한 타이밍만 판정합니다. 떼는 타이밍은 따지지 않습니다 |
| CN | 누르기 시작한 타이밍과 떼는 타이밍을 모두 판정합니다 |
| HCN | CN과 같이 둘 다 판정하며, 누르고 있는 동안에도 게이지가 오르내립니다 |

'AUTO'가 붙은 설정에서는 채보가 종류를 지정했다면 그것을 따르고, 지정하지 않았다면 고른 종류로 플레이합니다.
'FORCE'가 붙은 설정에서는 채보의 지정과 관계없이 고른 종류로 플레이합니다.

선곡 화면에서 **3** 키를 눌러도 전환할 수 있습니다. 점수는 LN 모드마다 따로 저장됩니다.

## 규칙

판정 폭, 게이지, 점수 계산 방식을 한꺼번에 바꿉니다. 점수는 규칙마다 따로 저장됩니다.

| 규칙 | 내용 |
| --- | --- |
| beatoraja | beatoraja와 같은 규칙입니다(처음 설정) |
| LR2oraja | LR2에 가까운 규칙입니다. LR2oraja Endless Dream과 같은 동작을 합니다 |
| DX MODE | LR2oraja Endless Dream의 DX MODE와 같은 규칙입니다 |

LR2나 beatoraja에서 가져온 점수를 볼 때는 가져올 때의 규칙에 맞추세요.

## 어시스트

판정을 넓히거나 BPM 변화를 미리 표시하는 등 플레이를 돕는 기능입니다.
선곡 화면에서 **E2**를 누르고 있는 동안 표시되는 패널에서 설정합니다.

어시스트의 효과가 난 플레이에서는 클리어해도 ASSIST 기록이 되며, 점수 저장과 IR 전송은 하지 않습니다.
다만 판정 범위 표시(JUDGE AREA)나 추가 노트 표시(MARK NOTE)처럼 표시만 바꾸는 기능은 기록에 영향을 주지 않습니다.
또한 BPM이 바뀌지 않는 채보에서의 BPM GUIDE처럼 효과가 나지 않은 어시스트도 기록에 영향을 주지 않습니다.

## 타깃

플레이 중에 내 점수와 비교할 상대를 고릅니다.
AAA 같은 랭크 목표값, IR 상위 점수, 라이벌 점수 등에서 고를 수 있습니다.

## 플레이 종류

| 종류 | 내용 |
| --- | --- |
| NORMAL | 일반 플레이입니다 |
| PRACTICE | 구간과 속도를 지정해 연습합니다. 점수는 저장되지 않습니다 |
| AUTOPLAY | 자동으로 연주합니다. 점수는 저장되지 않습니다 |
| AUTOPLAY BATTLE | 대전용 화면에서 자동으로 연주합니다. 점수는 저장되지 않습니다 |
| G-BATTLE | 저장한 리플레이나 IR 점수를 상대로 대전합니다 |

## 점수가 저장되지 않는 경우

다음 플레이에서는 점수·클리어 기록·리플레이를 저장하지 않으며, IR에도 전송하지 않습니다.

- 오토 플레이, 리플레이 재생, 프랙티스
- 건반 수를 변환한 플레이(7키를 9버튼으로 플레이하는 등)

어시스트의 효과가 난 플레이에서는 ASSIST 클리어 기록만 저장합니다.
