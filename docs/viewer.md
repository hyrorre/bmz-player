# BMS作成ツール向けビューワー

BMZ Playerは、BMSE / iBMSC系のuBMplay互換コマンドラインを使って、編集中の譜面を
常駐ビューワーとして再生できます。BMS Maker 3、woseq、BmsONEからも同じ入口を
利用できます。

## コマンドライン

```text
bmz-player.exe -P -N12 "C:\path\to\_temp.bms"
bmz-player.exe -P -B --profile playtest -N12 "C:\path\to\_temp.bms"
bmz-player.exe -S
```

- `-P` / `--viewer-play`: 指定譜面を外部ビューワーモードで開きます。
- `-B` / `--battle`: Viewerの5K/7K譜面を`AUTOPLAY BATTLE`で開き、profileの
  `battle5` / `battle7` skinを使います。専用skinが未設定なら同じkey modeの
  `play5` / `play7`へフォールバックします。
- `--profile <ID>`: `data/config.toml`の`active_profile`を変更せず、このViewer
  プロセスだけで指定profileを使います。存在しないprofileはエラーにします。
- `-N<N>` / `-N <N>` / `--start-measure <N>`: 元譜面の0始まりの小節番号から
  再生します。BMSの先頭ノーツ余白をBMZが追加した場合も、元譜面の小節番号を指定します。
- `-S` / `--viewer-stop`: 実行中の外部ビューワーへ停止要求を送り、このコマンド自身は
  直ちに終了します。常駐ビューワーは終了せず、現在の再生を止めて次の再生要求を待機します。
  ビューワーが起動していない場合も成功終了します。
- `--skip-decide`: 起動譜面でDecide画面を表示しません。
- `--skip-result`: 単曲プレイ後にResult画面を表示せず、アプリを終了します。

`-P`はオートプレイと`--skip-decide`をまとめて有効にします。Viewer起動ではSelectを
経由せず、最初の描画からPlay画面へ入ります。起動時間を短くするため、選曲リスト、
Select / Decide / Result skin、skin catalog、システムBGM / SEは初期化しません。
単曲の再生後はResult画面を表示せず、最後のPlay画面を保持したまま次の再生を待機します。
再生中に`-S`を受け取った場合も、現在のPlay画面を保持した同じ待機状態へ戻ります。
Viewerの再生中および再生終了後の待機中は、`Escape`、`E2+E3`、または`E1+E2`の
長押しで黒フェードアウト後にBMZ Playerを終了します。ViewerからSelect画面へは移動せず、
Viewer起動時に省略した選曲リスト、Select skin、skin catalog、システムBGM / SEも
初期化しません。再生だけを停止して次の命令を待機させる場合は、BMSエディタから`-S`を
送信します。
従来どおり単曲終了時にプロセスも終了させる場合は、`-P --skip-result`を指定します。編集中の
一時ファイルだけを一時ライブラリDBへ取り込むため、通常のライブラリDB、スコア、リプレイ、
IRには記録しません。新しい`-P`起動時に既存の外部ビューワーがあれば、同じプロセスへ
`Play { path, measure, battle }`を転送して現在の再生を差し替えます。`-B`の有無も
再生要求ごとに反映されるため、通常ViewerとBattle Viewerを同じ常駐プロセスで切り替えられます。
起動した側の短命プロセスは
転送完了後すぐ終了します。既存ビューワーがなければ、そのプロセスが常駐ビューワーになります。
`--profile`はプロセス単位の指定なので、既存Viewerがある場合はそのプロセスを終了し、指定profileで
新しいViewerを起動します。profile指定がない後続`-P`は、常駐Viewerが起動時に読み込んだprofileを
引き続き使用します。
常駐ビューワーが受け取る後続の`Play`は、Play skinの開始時計を継続し、ロード演出、
READYアニメーション、READY SEを再生しません。譜面と音声の再読込完了後、指定小節から
シークしたように再生を差し替えます。初回の`-P`起動では通常の開始・READY演出を表示します。

## Viewer操作

再生中は編集確認向けの専用キーマップを使用します。

| 入力 | 操作 |
| --- | --- |
| Left / Right | 前 / 次の1小節 |
| Shift+Left / Shift+Right | -3秒 / +3秒 |
| Up / Down | 次 / 前の1小節 |
| Shift+Up / Shift+Down | 4小節先 / 前 |
| Ctrl+Up / Ctrl+Down | ±5秒後の位置を含む小節の先頭 |
| マウスホイール | Up / Downと同じ（Shift / Ctrl修飾可） |
| Home | 0小節目 |
| Space | 一時停止 / 再開 |
| F5 | 現在小節から再読込（RANDOM配置を維持） |
| Shift+F5 | 現在小節から再読込してRANDOM配置を再抽選 |
| Escape | 黒フェードアウト後にBMZ Playerを終了 |

一時停止中は譜面時計、音声、動画BGA、Play skinの経過時間が同じ位置で停止します。
Spaceで再開すると、停止していた時間にかかわらず一時停止した位置から再生します。
停止中にシークまたはF5再読込しても、新しい位置で停止状態を維持します。
シーク時はロード済み音源を再利用し、シーク位置より前の判定・スコア・ゲージを初期状態へ
戻したうえで、開始時点より前のplayable notesをすべてPGREATとして計上します。途中からの
再生時点でEXスコア、ゲージ、コンボもそのPGREAT数を反映します。F5は編集中ファイルを
再importするため、譜面の保存後に使用してください。動画BGAはシーク先直前のキーフレームへ
直接seekしてから必要なフレームだけをデコードし、seekできない形式では先頭からのデコードへ
フォールバックします。

Viewer待機中もカーソルキー、Home、マウスホイール、F5でシークまたは再読込でき、その位置から
再生を再開します。Spaceは保持中の位置から再開します。待機中にEscapeを押すと、通常プレイで
READY前に退出するときと同じPlay skinのtimer 2（未定義時は黒フェード）を再生してBMZ
Playerを終了します。E1+E2長押しとE2+E3による退出も同じです。

`[PATH]`だけを指定した通常起動でも、未登録の`.bms` / `.bme` / `.bml` / `.pms` /
`.bmson`を1ファイルだけ通常のライブラリへ取り込んで開始できます。

## 停止通信

BMSエディタはBMZと直接通信する必要はありません。従来のuBMplay連携と同様に、停止時は
`bmz-player.exe -S`を別プロセスとして起動します。`-P`と`-S`の短命プロセスが、実行中
ビューワーへ長さ付きコマンドと受信ACKを使う次のローカルIPCで要求を中継します。

- Windows: 名前付きパイプ `\\.\pipe\bmz-player-viewer-v2`
- macOS / Linux: loopback TCP `127.0.0.1:39077`

受信側はプロセス終了まで接続待ちを繰り返し、`Play { path, measure, battle }`と`Stop`を処理します。
`Stop`は常駐プロセスを終了せず、現在の再生位置とPlay画面を保持して無音の待機状態へ戻します。
`path`は送信側で絶対パスへ解決するため、エディタと常駐ビューワーの作業ディレクトリが
異なっていても同じ一時ファイルを開けます。

## エディタ別設定

| エディタ | 再生設定 | 停止設定 | 備考 |
| --- | --- | --- | --- |
| BMSE / iBMSC | ビューワー実行ファイルに`bmz-player.exe`を指定 | 対応する停止操作が`-S`を起動 | uBMplay互換の`-P -N<小節> <一時BMS>`をそのまま受け付けます。 |
| BMS Maker 3 | ファイル名と開始小節の置換項目を使い、`-P -N<小節> "<ファイル名>"`になるよう設定 | 専用の停止引数欄がない版では、新しい`-P`で再生中譜面を差し替えます | 置換項目の表記は利用中のBMS Maker 3の設定画面に従います。 |
| woseq | ビューワー実行ファイルに`bmz-player`を指定 | なし | woseqが生成する`-P -N<小節> _temp.bms`をそのまま解釈します。 |
| BmsONE | 再生引数を`-P -N$(measure) "$(filename)"`に設定 | 停止引数を`-S`に設定 | 一時`.bmson`も直接読み込めます。 |

BMS Maker 3とwoseqはエディタ側に独立した停止コマンドがない構成でも、同一プロセスでの
再生差し替えは動作します。編集途中で明示的に止めたい場合は、ショートカットなどから
`bmz-player.exe -S`を実行してください。

## ドラッグ＆ドロップ

Select画面のBMZウィンドウへ対応譜面をドロップすると、その1ファイルを通常のライブラリへ
取り込み、通常プレイを開始します。通常起動ではSelect以外の画面へのドロップは受け付けません。

Viewerウィンドウへ対応譜面をドロップすると、その譜面をViewerモードで0小節目から再生します。
再生中、一時停止中、再生終了後の待機中でも切り替えられます。Battle ViewerではBattle設定を
維持します。通常のライブラリ、スコア、リプレイ、IRには記録しません。
