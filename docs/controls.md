# 操作方法

このドキュメントは現在の BMZ Player 実装に基づく操作一覧です。
キーコンフィグで変更できる操作は、デフォルト割り当てを前提に書いています。

## ランダム選曲

F1の設定 → 選曲、またはゲーム内の選曲設定で、次の項目を個別にON/OFFできます。
新しい条件付き項目は既定OFFです。

| 項目 | 抽選対象 |
| --- | --- |
| RANDOM SELECT | 条件なし |
| NO PLAY RANDOM SELECT | 保存スコアなし、またはプレイ回数0 |
| FAILED RANDOM SELECT | ベストランプがFAILED |
| NOT EASY RANDOM SELECT | EASY未満 |
| NOT CLEAR RANDOM SELECT | NORMAL未満 |
| NOT HARD RANDOM SELECT | HARD未満 |
| NOT EX-HARD RANDOM SELECT | EX-HARD未満 |
| NOT FULL COMBO RANDOM SELECT | FULL COMBO未満 |

「NOT ～」には未プレイも含まれます。判定には現在のプロファイル・LN設定・ルールモードの
選曲表示と同じ保存スコアを使います。現在の一覧でモード・難易度フィルターに残った所持譜面から
抽選し、決定するとプレイを開始します。サブフォルダ内は探索しません。
通常RANDOMは候補2曲以上、条件付き項目は1曲以上で表示します。
連続して同じ曲が選ばれる場合があります。

## 共通

| Key | 操作 |
| --- | --- |
| F1 | 詳細設定ウィンドウを開閉 |
| F12 | スクリーンショットを保存（左上に短時間メッセージ表示。撮影フレームには写らない） |

F1メニューの「設定」は、本体・プロファイル・スキン設定をまとめたウィンドウです。
左サイドメニューから一般／プロファイル／音声／映像／入力デバイス／キーコンフィグ／プレイ／選曲／スキン／
ライブラリ／難易度表／IR／連携・録画／データ移行を選びます。ライセンス表記は
サイドメニューの最下部に固定されています。幅が狭い場合は左メニューがカテゴリ選択の
プルダウンになります。連携・録画・データ移行の各ページは上部のプルダウンで内容を
切り替えます。プレイはプレイ・判定・表示・リプレイ、ライブラリは曲フォルダ・スキャン・
譜面取得をセクションに分けてまとめて表示します。曲フォルダは末尾のフォルダ名を表示し、
フルパスはホバー時のツールチップに表示します。難易度表は表名を表示し、URLはホバー時の
ツールチップに表示します。ページごとのスクロール位置を保持します。

一般はUI設定の下に更新・ログ設定を表示します。未実装のテーマ・終了確認は表示しません。
言語のラベルは英語以外では「言語 (Language)」のように英語を併記します。
新規プロファイルと `ui.language` が省略されたプロファイルは、OSの優先言語順から
最初の対応言語を選びます。対応言語がない場合は英語になります。保存済みの言語指定は
OSより優先し、選択後の言語コードを保存するため、OS言語の変更では上書きしません。

BMZメニューの並びは「設定」「コース作成」「Random Trainer」「デバッグ表示」です。

設定は変更が止まって約0.5秒後に自動保存し、設定を閉じるときも保存します。
最大FPSはドラッグ中には反映せず、マウスを離したときに反映します。
数値を直接入力した場合はEnterまたは入力欄からフォーカスを外したときに反映します。
保存失敗は下部に表示し、5秒間隔で再試行します。音声出力の「適用」は引き続き必要です。
プレイ終了・リトライ・アプリ終了時にも、本体設定とプロファイル設定の両方を保存します。
音声出力の適用など、その場で実行する操作は各ページのボタンから行います。
Decide / Play中は従来どおり項目ごとの変更制限があり、ページ移動・閲覧は可能です。
キー割り当ての入力待受は、別カテゴリ・別ページへの移動や設定ウィンドウを閉じる操作で解除されます。

スキンは「対象画面」で選曲・決定・各キーモード・BATTLE・リザルト・コースリザルトを
選び、その対象だけを編集します。選曲・決定・リザルト・コースリザルトは「共通画面」に
まとまっています。オプション／ファイル選択／位置・サイズはセクションに分けてすべて
表示し、検索欄で全セクションの項目名を絞り込めます。検索語は対象ごとに保持されます。
「デフォルトに戻す」は編集中の対象のオプション・素材・位置調整を初期値へ戻します。

F12 は既定割り当てです。選曲画面の `設定 → 入力 → キーコンフィグ → 共通` から変更できます。

通常プレイ中にF1メニューを表示しても、キーボード入力はプレイ側へ継続して渡されます。
eguiがプレイ入力を専有するのはPractice設定画面だけで、E1/E2 hold中はそこでもプレイ側操作を
優先します。Select / Decide / Resultでは、eguiが実際に消費した入力だけ各画面への伝播を止めます。

詳細設定の「入力デバイス」では、ゲームパッドbackendを`自動選択` / `gilrs`から選べます。
WindowsではHID reportをイベント駆動で受け取る`Raw Input`も選べます。`自動選択`は現在gilrsを使用し、
Raw Inputは明示選択時だけ有効になります。登録・初期化に失敗した場合はgilrsへフォールバックします。
旧設定の`GameInput`は読込時に`gilrs`へ移行されます。
backend変更は次回起動時、1P / 2Pのコントローラ割り当て変更は次回プレイ開始時から反映されます。
ゲーム内設定またはF1メニューの設定 → 入力 → 入力デバイスでは、`gamepad1` (1P) / `gamepad2` (2P)
ごとに `ANALOG SCRATCH`、アナログ感度、アナログ停止閾値を変更でき、稼働中の
ゲームパッドbackendへ即時反映されます。`ANALOG SCRATCH` がONの場合は軸の回転差分を
スクラッチ入力と回転量比例のメニュースクロールに使います。OFFの場合はbeatorajaと同様に、
軸値が `> 0.9` の端点を `AxisN+`、`< -0.9` の端点を `AxisN-` の通常ボタンとして扱い、
比例スクロールは行いません。未割り当てのSP用ゲームパッドは1P設定を使います。
旧 `Scratch Input Mode` 設定は使用しません。スクラッチ方向はキーコンフィグの
`Scratch Up` / `Scratch Down` 割り当てで指定し、既存profileの `scratch_mode` は読込時に
無視され、次回保存時に削除されます。
キーコンフィグの `KEYBOARD` と `KEYBOARD SUB` は独立したスロットとして保存されるため、
`KEYBOARD` を未割り当てにしたまま `KEYBOARD SUB` だけを使用することもできます。
F1メニューの設定 → キーコンフィグでは、共通／選曲／プレイ／リザルトと
4K / 5K / 6K / 7K / 8K / 9K / 10K / 14Kの割り当てを変更できます。対象と入力スロットを
選び、現在値のボタンを押してからキーまたはコントローラを入力します。Escapeで待受を
キャンセルし、Delete / Backspaceまたは「解除」で割り当てを削除します。「デフォルトに戻す」は
表示中のカテゴリと入力スロットの行だけを初期値へ戻し、他カテゴリ・他キーモードは変更しません。
Decide / Play中は変更できません。
共通 E1〜E4 と同じキーを選曲／プレイ／リザルトへ割り当てた場合は、共通 E1〜E4を優先して
処理します。プレイ中にキーモード別の鍵盤・スクラッチと共通またはプレイ操作が重なった場合は、
キーモード別設定を優先します。競合する行には警告アイコンを表示し、割り当て自体は保持します。
旧UI action の `Enter` (`SelectEnter`) と `OptionBga` は非推奨で、profile に残っていても
入力動作には使用しません。選曲の決定はキーモード別の鍵盤割り当て、BGA切替はKEY1の
割り当てを使用します。
F1メニューの設定 → プレイでは、beatoraja互換の7アシストと
SCROLL / LONGNOTE / MINE / EXTRA NOTEモディファイアを設定できます。
「プレイ」では判定ごとのGUIDE SEと未処理ノートの判定ライン滞留、
「表示」ではノーツ表示時間、CONSTANT、
CONSTANTフェード時間を設定できます。CONSTANTはPracticeでは無効です。
`RULE MODE` / `LN MODE` を変更すると、選曲一覧のスコア・リプレイ・フォルダ集計を
新しいスコア文脈で即時再読込し、変更前のプリロードとリトライ用cacheは破棄します。
譜面・プレビュー音量正規化とシステムBGM音量正規化は個別に切り替えられます。
システムBGM側は選曲BGMと決定BGMだけが対象で、システム効果音には適用しません。
どちらも実行中に切り替えられ、OFFにしても解析済みゲインを保持するため、再度ONにすると
同じゲインを即時適用します。

F1メニューの「Random Trainer」では、7K・1Pの通常`RANDOM`で使うレーン順を
ドラッグ＆ドロップまたは正規・鏡・左右シフトで固定できます。設定はアプリ実行中だけ保持され、
次の新規プレイまたは別配置リトライから反映されます。スクラッチは並べ替えません。
レーンボタンは白鍵を白、黒鍵を青で表示します。「Black/Whiteランダム」は白鍵同士・青鍵同士を
プレイごとに再抽選します。レーンを右クリックすると部分ランダム対象を切り替えられ、ピンク枠の
レーン番号だけが現在の位置群の中で再抽選されます。両方を有効にした場合はBlack/White、
部分ランダムの順に適用します。

F1メニューの「コース作成」は選曲画面で使用できます。ローカルコースの新規作成・
編集・削除、譜面検索からの課題曲追加と並べ替え、制約・トロフィー・IR送信可否の編集、
ファイルダイアログを使ったbeatoraja互換JSONの入出力を行えます。
コースと段位の区別はCLASS制約から決まり、トロフィー編集欄は既定で折り畳まれています。
24K / 48K譜面および24Kゲージ制約は編集候補に表示しません。

## 選曲画面

`.bms` / `.bme` / `.bml` / `.pms` / `.bmson`ファイルをBMZウィンドウへドラッグ＆
ドロップすると、その譜面をライブラリへ取り込んで通常プレイを開始します。
Select以外の画面へのドロップは受け付けません。外部BMSエディタのビューワー設定は
[`viewer.md`](viewer.md)を参照してください。

### 共通キー

| Key | 操作 |
| --- | --- |
| Up / Down | カーソル移動 |
| PageUp / PageDown | ページ移動 |
| Home / End | 先頭 / 末尾へ移動 |
| Enter / Space / Right | 決定、フォルダを開く、曲を開始 |
| Left | フォルダを閉じる |
| / | 検索モードを開始。E1/E2/E3/E4 hold 中は通常キー入力として扱う |
| F5 | フォルダ内の BMS 再スキャン / 難易度表の再取得 |
| F3 | 選択中譜面のフォルダを開く |
| E1+F3 | 選択中譜面の MD5 をクリップボードへコピー |
| E2+F3 | 選択中譜面の SHA256 をクリップボードへコピー |
| E3 | 対応スキンの通常選曲中に IR `RANKING` / `RIVAL` を切替 |
| Ctrl+F3 / Ctrl+Shift+F3 | MD5 / SHA256 をクリップボードへコピー（従来互換） |
| F10 | 選択中フォルダ内の譜面を Autoplay |
| F11 | 選択中譜面のプライマリIRページを開く |
| 0 / Numpad0 | 難易度フィルターを切替 |
| 1 / Numpad1 | キーモードフィルターを切替 |
| 2 / Numpad2 | ソートを切替 |
| 3 / Numpad3 | LNモードを切替 |
| 4 / Numpad4 | 選択中譜面・コースに存在するリプレイスロットを巡回 |
| 5 / Numpad5 | 現在選択中のリプレイスロットを再生 |
| 6 / Numpad6 | 現在のフォルダ階層を維持したまま `設定 → 入力 → キーコンフィグ` を開く |
| Tab | G-BATTLE相手選択を固定表示 / 閉じる |
| 7 / Numpad7 | rianIRの選択ライバルを `NONE → 登録順` で切替 |
| 8 / Numpad8 | 選択中譜面と同じフォルダ、または選択中コースの構成譜面を開く |
| 9 / Numpad9 | 選択中譜面と同じフォルダの `.txt` 曲テキストを開く |
| F8 | favorite song を登録 / 解除 |
| F9 | favorite chart を登録 / 解除 |
| マウスホイール | カーソル移動 |
| 選択中の行をクリック | 決定、フォルダを開く、曲を開始 |
| 未選択の行をクリック | その行へカーソル移動 |
| 右クリック | フォルダを閉じる |

F3 / F5 / F10 / F11 / 0〜9 は既定割り当てです。これらも
`設定 → 入力 → キーコンフィグ → 共通` から変更できます。

選曲の既定ショートカットは通常数字キー（0〜9）にまとめています。
対応するテンキー（Numpad0〜9）でも同じ操作を実行できます。

対応スキンの `KEY CONFIG` ボタンは、現在のフォルダ階層を維持したまま
`設定 → 入力 → キーコンフィグ` を開きます。キーコンフィグの一覧から戻ると、ボタンを押す直前のフォルダと
カーソル位置へ戻ります。

対応スキンのボタンから、スキン設定、曲テキスト、IRページ、フォルダ、譜面配布元URLを
開けます。`UPDATE FOLDER` はF5と同じ文脈依存更新です。HISPEED、表示時間、判定表示ずれ、
GUIDE SE、追加ノート／地雷／SCROLL／LNモディファイア、CONSTANTもスキンボタンから変更できます。

`SELECT INPUT` は設定フォルダの `INPUT` から `7K/14K` または `9K` を選べます。
デフォルトは `7K/14K` です。
設定フォルダ内では検索モードには入りません。
E1 / E2 / E1+E2 を hold している間は、選曲オプションパネルを表示します。
`selectIrScopeBinding = "active"` と `selectIrScopeToggle = "e3_press"` を宣言した
スキンでは、曲行を選択中かつオプションパネル・検索・設定編集を開いていないときに、E3で
`RANKING`（全体）と `RIVAL`（自分 + IRライバル）を切り替えます。Rival scope 非対応時は
何もしません。
`7`で選んだrianIRライバルに対象譜面のスコアがあれば、
そのEXスコアをプレイ時ターゲットとして自動使用します。未プレイ譜面ではbeatorajaと同じく、
通常のTARGET設定へフォールバックします。ライバル一覧はログイン済みのrianIRから起動時に
バックグラウンド同期します。`ir rivals` は手動再同期・確認用です。rianIRでのライバル追加・解除は
Webサイト側で行います。
`RANDOM SELECT` 行は設定フォルダの `選曲 > RANDOM SELECT` から表示を切り替えられます。
favorite 操作は invisible を使わず、登録済みなら解除、未登録なら登録します。

曲行を選択中、SESSION MODEに関係なく`KEY4`を120ms以上長押しすると、LR2と同様に
曲リストがG-BATTLE相手選択へ一時的に切り替わります。短押しはそのキーモードでの通常の
`KEY4`操作になり、長押し後にキーを離すと元の曲リストへ戻ります。`Tab`では固定表示でき、
もう一度`Tab`、戻る操作、`Escape`で閉じます。
相手を決定してもSESSION MODEは変更しません。`NORMAL`では通常5K / 7Kスキン、
`G-BATTLE`では5K / 7K BATTLEスキンのまま開始します。SESSION MODEで`G-BATTLE`を
選んで曲を直接決定した場合は、相手選択画面を開かず`BATTLE OFF`で開始します。

相手選択の先頭には`BATTLE OFF`（既定）、`MYBEST`、`REPLAY 1`〜`REPLAY 4`、
`RIVAL (名前)`が並び、その後にIRランキングが続きます。上下・ページ移動・スクラッチ・
マウスホイールで選び、決定するとG-BATTLEを開始します。ローカル項目とリプレイ公開対応IRは
フル入力リプレイを独立した相手判定へ使用します。リプレイが未検証、形式不一致、
譜面/LNポリシー不一致の場合は開始せず、選曲画面に理由を表示します。リプレイが未公開の
相手は配置を再現し、対戦相手側をAUTOPLAYで再生します。
旧BMZの5K/7Kリプレイに混入した2P表示レーンは相手再生時に除外し、微小な入力時刻の前後は
安定した時刻順へ補正します。Replay v3以前の配置seedも当時の方式で再現します。
`G-BATTLE`で`BATTLE OFF`を選んだ場合もSESSION MODEを維持し、相手側をAUTOPLAYにします。
`G-BATTLE`の2P側はリプレイの有無にかかわらず、1P側で確定した配置と同じ配置を表示します。

G-BATTLE相手を指定したプレイでは、`CHART REPLICATION`の`RIVALCHART`は相手の譜面
オプションとseedを自分側にも適用し、`RIVALOPTION`は相手の譜面オプションだけを適用して
自分側のseedを維持します。`NONE`では自分側の配置を変更しません。`7`で選択中のrianIR
ライバルとG-BATTLE相手が異なる場合は、そのプレイで明示したG-BATTLE相手を優先します。
G-BATTLE相手選択中も、人物表示に使うタイトル・サブタイトル・ジャンル・アーティスト以外の
譜面情報は選択元の楽曲を維持します。ただしIRランキング行のレベル欄にはランキング順位を
表示し、それ以外の固定行ではレベル欄を表示しません。G-BATTLEの開閉や相手カーソル移動では
現在の楽曲プレビュー再生を継続します。G-BATTLE開始時は画面を閉じるSEを鳴らさず、decide BGM
だけを再生します。

G-BATTLEは2K / 4K / 5K / 6K / 7K / 8K / 9K / 10K / 14Kで使用できます。
`AUTOPLAY BATTLE` / `G-BATTLE`では5K / 7Kだけバトルスキンを使い、
それ以外のキーモードは通常スキンを使います。

`COURSE` フォルダの `新規コース` を決定すると、LR2風のコース作成モードへ入ります。
通常どおり曲フォルダや難易度表、検索結果を移動し、所持譜面を決定すると課題曲へ追加します。
課題曲はキーモードを混在させて最大10譜面まで追加でき、同じ譜面の重複も可能です。
画面上のパネルでコース名、制約、トロフィー、IR送信可否の変更、曲順変更、個別削除、
直前の追加取り消し、保存、キャンセルを行えます。トロフィー編集欄は既定で折り畳まれ、
新規コースはトロフィーなしです。
キーボードの `Backspace` / `Delete` は直前の追加を取り消し、`Escape` は作成をキャンセルします。
戻る操作はフォルダ内では1階層戻り、ルートでは作成をキャンセルします。
保存したコースは `COURSE` フォルダへ追加されます。課題曲の検索やJSON入出力などの
詳細編集はF1メニューの「コース / 段位作成」を使用します。

`COURSE` フォルダの `RANDOM MIX` を決定すると、現在のキーモードから最大5譜面を抽選し、
同じ曲フォルダを重複させない一時コースとして開始します。設定フォルダの `選曲` では、
目標レベル、レベル上下限、BPM上下限、先頭曲を基準にしたBPM幅、曲数を変更できます。
曲数を `RANDOM` にすると2〜4曲を抽選します。

難易度表の未所持譜面を決定すると、詳細設定の「未所持譜面の取得」に従って
`IPFS > HTTP > ブラウザ` の順で利用可能な方法を選びます。IPFS / HTTP は既定で無効です。

## プレイ画面

### プラクティス設定

選曲画面で SESSION MODE を PRACTICE にして曲を決定するか、選曲スキンのPRACTICE操作、
または譜面PATHと`--practice`を指定すると、決定画面を経由して開きます。
コースではPRACTICEはNORMALとして扱います。
開始・終了位置、ゲージ種別/カテゴリ/初期値、判定ランク、TOTAL、50–200%の再生速度、
グラフ種別、1P/2P配置、DP FLIPを設定できます。設定値は譜面SHA-256単位で保存され、
区間プレイ後は決定画面を挟まず、ロード済みの譜面・音源・BGAを再利用して、
直前の判定グラフを表示する設定画面へ戻ります。設定ウィンドウはタイトルバーをドラッグして移動できます。
開始位置を変更すると背面の譜面プレビューも即座にその位置へ移動します。秒線とBPM/STOPガイドは
設定中だけ表示され、区間プレイ中には表示されません。

| 入力 | 操作 |
| --- | --- |
| Up / Down | 設定項目を移動 |
| Left / Right | 選択中の値を減らす / 増やす |
| Enter | 区間プレイを開始 |
| Escape / E1+E2 hold / E2+E3 | 設定を保存して選曲へ戻る |
| Scratch Up / Down | 設定項目・開始・戻るを移動 |
| KEY2 / KEY4 / KEY6 | 選択中の値を減らす |
| KEY1 / KEY3 / KEY5 / KEY7 | 選択中の値を増やす。開始・戻るを選択中はそのボタンを実行 |

入力は実際の譜面用キー割り当てを使い、DPでは1P/2Pのどちら側でも同じ規則です。
E1/E2単押しでは開始・退出しません。E1/E2 hold中は従来どおりプレイ側のHS・レーンカバー操作を
優先します。マウスでも各入力欄・選択肢・ボタンを直接操作できます。

### ゲームパッド (10K / 14K)

2 台のコントローラで 10K / 14K をプレイできます。

| 論理スロット | 既定の役割 | デフォルト binding |
| --- | --- | --- |
| `gamepad1` | 1P (Scratch + Key1–7) | 接続順の 1 台目 |
| `gamepad2` | 2P (Scratch2 + Key8–14) | 接続順の 2 台目 |

- 未割当時は **接続順フォールバック** (1 台目 = 1P、2 台目 = 2P) です。
- 1P / 2P の物理パッド割り当ては F1 → 本体設定 → **入力デバイス** から変更できます (接続一覧・自動割り当て・入れ替え)。
- キーコンフィグ (`設定 > 入力 > キーコンフィグ > 10K/14K`) の CONTROLLER スロットは、1P レーンが `gamepad1`、2P レーンが `gamepad2` として保存されます。
- 7K など単一パッドモードの CONTROLLER は `gamepad` ワイルドカード (どのパッドでも可) です。
- 割り当て変更は **次回プレイ開始から** 反映されます。

10K は 14K の binding を継承し、両側 5 鍵 + 両皿だけが有効です。

Viewer modeでは通常プレイのカーソルキー操作を使わず、編集確認向けの専用操作になります。

| Key | Viewer modeの操作 |
| --- | --- |
| Left / Right | 前 / 次の1小節へシーク |
| Shift+Left / Shift+Right | 現在位置から -3秒 / +3秒へシーク |
| Up / Down | 次 / 前の1小節へシーク |
| Shift+Up / Shift+Down | 4小節先 / 前へシーク |
| Ctrl+Up / Ctrl+Down | ±5秒後の位置を含む小節の先頭へシーク |
| マウスホイール | Up / Downと同じ。Shift / Ctrl修飾も使用可能 |
| Home | 0小節目へシーク |
| Space | 一時停止 / 再開 |
| F5 | 現在小節から譜面ファイルを再読込（RANDOM配置を維持） |
| Shift+F5 | 現在小節から譜面ファイルを再読込し、RANDOM配置を再抽選 |
| Escape | 黒フェードアウト後にBMZ Playerを終了 |

一時停止中は譜面時計、音声、動画BGA、Play skinの経過時間が同じ位置で停止し、
シークとF5再読込を行っても停止状態を維持します。
シークではロード済みのPCMと変換済み譜面を再利用し、シーク先より前の判定・スコア・
ゲージを初期状態へ戻したうえで、シーク先より前に判定時刻を迎えたplayable notesをすべて
PGREATとして計上します。このため、途中からの再生時点でEXスコア、ゲージ、コンボもその
PGREAT数を反映します。F5だけはエディタで保存した変更を反映するため譜面ファイルを
再importします。動画BGAはシーク先直前のキーフレームへ直接seekし、そこから必要な
フレームだけをデコードします。

再生終了後または停止命令後のViewer待機中も、カーソルキー、Home、マウスホイール、F5を
そのまま使用できます。シークまたはF5で指定位置から再生を再開し、Spaceは保持中の位置から
再開します。待機中にEscapeを押すと黒フェードアウト後にBMZ Playerを終了します。

Escape / E1+E2 hold / E2+E3 による中断は、実プレイ開始前（譜面・音源ロード中および READY 演出中）なら timer=2 の黒フェードアウトを開始し、リザルトを表示せず選曲へ戻ります。実プレイ開始後は FAILED 演出を開始し、通常の終了処理へ進みます。
Viewer modeではEscape / E1+E2 hold / E2+E3のいずれもBMZ Playerを終了するための
黒フェードアウトを開始します。再生終了後に最後のPlay画面を保持している待機中も、同じ
退出操作とフェードアウトを受け付けます。再生だけを停止して待機させる場合は、外部Viewerの
停止命令 (`-S`) を使用します。

SUDDEN+、LIFT、HIDDEN+の有効状態は、F1メニューのプロファイル設定「表示」と
選曲画面の `設定 → 表示` でキーモード別に変更できます。無効なカバーは表示・量変更の
対象になりません。LIFTとHIDDEN+を同時に有効にした場合、プレイ開始時の変更対象はLIFTで、
E1+E2の押下エッジごとにLIFT/HIDDEN+を切り替えます。押す順序は問いません。
この短押し切替とE1+E2長押しによる中断は共存します。
HIDDEN+を変更対象にした場合だけ増減方向がSUDDEN+/LIFTと逆になり、カーソルキーと
E1+ScratchのどちらでもUpでHIDDEN+量が増え、Downで減ります。

HS設定は `NORMAL` / `CLASSIC` / `FLOATING` / `NORMAL+FLOATING` /
`CLASSIC+FLOATING` の5種類です。`NORMAL` と `CLASSIC` ではFloatingと緑数字操作を
無効にし、`FLOATING` ではFloatingを固定します。末尾が `+FLOATING` の2設定だけ、
E1+E2で基準方式とFloatingを切り替えられます。Normalの段階表と切替時の変換規則は
`docs/hs.md`を参照してください。

SUDDEN+が無効または非表示で、LIFT/HIDDEN+も無効なため操作可能なカバーがない場合、
カバー操作はEndlessDream互換のHS操作になります。HS Auto AdjustがOFFならデジタル入力は
現在方式の速度操作、アナログスクラッチは1 tickあたり0.01でHS倍率を直接変更します。
HS Auto AdjustがONのFloatingでは、SUDDEN+とLIFTを0として現在BPMでHSを再計算します。
どちらの場合も無効なSUDDEN+/LIFT/HIDDEN+の量は変更・保存されません。

Practiceでは最終ノーツ処理後にE1 / E2 / Escapeで終了した場合もリザルトを表示せず、直前の判定グラフを反映してPractice設定画面へ戻ります。

E1/E2 hold 中の鍵盤方向は、譜面の KEY MODE ごとに次のとおりです。`Down` はハイスピードまたは緑数字を下げ、`Up` は上げます。10K/14K は 1P/2P の両側に同じ規則を適用します。

| KEY MODE | Down | Up |
| --- | --- | --- |
| 4K | KEY1 / KEY4 | KEY2 / KEY3 |
| 5K | KEY1 / KEY3 / KEY5 | KEY2 / KEY4 |
| 6K | KEY1 / KEY3 / KEY4 / KEY6 | KEY2 / KEY5 |
| 7K | KEY1 / KEY3 / KEY5 / KEY7 | KEY2 / KEY4 / KEY6 |
| 8K（既定） | KEY2 / KEY4 / KEY5 / KEY7 | KEY1 / KEY3 / KEY6 / KEY8 |
| 9K | KEY1 / KEY3 / KEY5 / KEY7 / KEY9 | KEY2 / KEY4 / KEY6 / KEY8 |
| 10K（1P/2P） | KEY1 / KEY3 / KEY5 | KEY2 / KEY4 |
| 14K（1P/2P） | KEY1 / KEY3 / KEY5 / KEY7 | KEY2 / KEY4 / KEY6 |

8K の各鍵盤の方向は、`設定 → 入力 → キーコンフィグ → 8K` で個別に `Down` / `Up` へ変更できます。
譜面レーンとして Scratch を持たない 4K / 6K / 8K / 9K でも、7K の Scratch 割り当てを使って E1/E2 hold 中のレーンカバー・緑数字操作ができます。この Scratch 入力はHS操作専用で、譜面の判定入力には追加されません。

コースの `NoSpeed` 制約中は、HS 1.0、SUDDEN/LIFT/HIDDEN 0 で開始し、HS MODE・ハイスピード・緑数字・レーンカバーに関する操作がすべて無効になります。制約中の一時的なレーン状態はプロファイルへ保存されません。
クイックリトライは単曲の通常プレイでのみ有効です。
Autoplay / Replayの速度操作自体は固定で、キーコンフィグの対象外です。再生中はプレイカテゴリ
のショートカットより上段1～4・テンキー1～4の速度変更を優先します。現在の KEY MODE の
レーン／スクラッチまたは共通 E1～E4に該当キーが割り当てられている場合は、その設定を優先して
速度変更には使いません。
複数の未割り当てキーを同時にholdした場合は、数字の小さいキーを優先します。

## リザルト画面

対応スキンでは、`GRAPH DATA` / `INTERNET RANKING` タブをマウスでクリックしてパネルを直接切り替えられます。
