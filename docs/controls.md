# 操作方法

各画面のキー操作と、操作に伴う動作をまとめた文書です。
BMZ メニュー（F1）の各設定の仕様は[設定画面](settings.md)、利用者向けの説明は[マニュアル](../manual/ja/04-controls.md)を参照してください。
キーコンフィグで変更できる操作は、既定の割り当てで書いています。

## キーの呼び方と既定の割り当て

- KEY1〜KEY7は鍵盤を左から数えた番号です。DPの2P側はKEY8〜KEY14、または2P KEY1〜2P KEY7と書きます。
- Scratch Up / Downはスクラッチの上下の回転です。
- E1〜E4は補助ボタンです。既定ではQ / W / E / Rに割り当てています。
- キーの組み合わせは次のように書きます。
  - E1+E2：同時に押す
  - E1 hold：押している間
  - E1 hold + KEY1：E1を押しながらKEY1を押す
  - E1+E2 長押し：同時に一定時間押し続ける

| モード | スクラッチ | 鍵盤 |
| --- | --- | --- |
| 7K | LShift / LControl | Z, S, X, D, C, F, V |
| 14K | LShift / LControl, RShift / RControl | Z, S, X, D, C, F, V, M, K, Comma, L, Period, Semicolon, Slash |
| 9K | - | Z, S, X, D, C, F, V, G, B |

### ゲームパッド（10K / 14K）

2台のコントローラーで10K / 14Kをプレイできます。

| 論理スロット | 既定の役割 | 既定の割り当て |
| --- | --- | --- |
| `gamepad1` | 1P（Scratch + KEY1〜KEY7） | 接続順の1台目 |
| `gamepad2` | 2P（Scratch2 + KEY8〜KEY14） | 接続順の2台目 |

- 割り当てていない場合は、接続順の1台目を1P、2台目を2Pとして使います。
- 1P / 2Pの物理パッドの割り当ては、「BMZ メニュー → 入力デバイス」で変更できます（接続一覧・自動割り当て・入れ替え）。
- キーコンフィグ（「選曲画面の 設定 → 入力 → キーコンフィグ → 10K/14K」）のCONTROLLERスロットは、1Pのレーンを`gamepad1`、2Pのレーンを`gamepad2`として保存します。
- 7Kなど1台で遊ぶモードのCONTROLLERは`gamepad`（どのパッドでも可）です。
- 割り当ての変更は、次にプレイを開始したときから反映します。
- 10Kは14Kの割り当てを引き継ぎ、両側の5鍵と両方のスクラッチだけを使います。

## すべての画面で使う操作

| キー | 操作 |
| --- | --- |
| F1 | BMZ メニュー（設定・ツール）を開く / 閉じる |
| Escape | BMZ メニューを表示中は閉じる（プレイ中・プラクティス設定中を除く）。文字入力中・プルダウン表示中は、そちらを先に閉じる |
| F12 | スクリーンショットを保存（左上に短時間メッセージを表示。撮影したフレームには写らない） |

F12は既定の割り当てで、「選曲画面の 設定 → 入力 → キーコンフィグ → 共通」から変更できます。
スクリーンショットのクリップボードへのコピーが有効な場合は、PNGを保存した後に画像もコピーします。
LinuxのWayland（Flatpakを含む）では、BMZのウィンドウにフォーカスがある状態でコピーしてください。

### BMZ メニューを表示中の入力

- 通常プレイ中にBMZ メニューを表示しても、キーボード入力はプレイ側へ渡し続けます。
- メニュー（egui）がプレイ入力を占有するのは、プラクティス設定画面だけです。プラクティス設定画面でも、E1 / E2 hold中はプレイ側の操作を優先します。
- 選曲画面・決定画面・リザルト画面では、メニューを表示中でも、メニューが実際に使ったキーボード・マウス入力だけを各画面へ渡しません。
- メニューへ送らないゲームパッド・アナログ入力は、メニューを表示しているだけでは止めません。
- プロファイルの切り替えなど、アプリ側の処理中に行う入力ロックは別に適用します。

- お気に入りの操作は、登録済みなら解除、未登録なら登録します。invisible状態は使いません。

### 鍵盤での操作（7K / 14K）

既定では、E1 / E2 / E1+E2をholdしている間、選曲オプションパネルを表示します。
E1 hold＝通常、E2 hold＝アシスト、E1+E2 hold＝詳細の3パネル方式です。
短く押して固定表示する操作はありません。

| キー | 通常 | E1 hold | E2 hold（アシスト） | E1+E2 hold |
| --- | --- | --- | --- | --- |
| KEY1 | 決定 / 開く / 曲開始 | 1P RANDOM次 | EXPAND JUDGE | BGA切り替え |
| KEY2 | 戻る / 閉じる | 1P RANDOM前 | SCROLL REMOVE | GAUGE AUTO SHIFT切り替え |
| KEY3 | 決定 / 開く / 曲開始 | GAUGE次 | JUDGE AREA | JUDGE AUTO ADJUST切り替え |
| KEY4 | 戻る / 閉じる（120ms長押しでG-BATTLEの相手選択） | GAUGE前 | LN REMOVE | GREEN NUMBER -1 |
| KEY5 | 決定 / 開く / 曲開始 | HS-FIX次 | MARK NOTE | VISUAL OFFSET -1ms |
| KEY6 | 戻る / 閉じる | DP OPTION次 | BPM GUIDE | GREEN NUMBER +1 |
| KEY7 | 決定 / 開く / 曲開始 | SESSION MODE次（NORMAL → PRACTICE → AUTOPLAY → AUTOPLAY BATTLE → G-BATTLE） | MINE REMOVE | VISUAL OFFSET +1ms |
| 2P KEY1 | 決定 / 開く / 曲開始 | 2P RANDOM次 | EXPAND JUDGE | BGA切り替え |
| 2P KEY2 | 戻る / 閉じる | 2P RANDOM前 | SCROLL REMOVE | GAUGE AUTO SHIFT切り替え |
| 2P KEY3 | 決定 / 開く / 曲開始 | GAUGE次 | JUDGE AREA | JUDGE AUTO ADJUST切り替え |
| 2P KEY4 | 戻る / 閉じる | GAUGE前 | LN REMOVE | GREEN NUMBER -1 |
| 2P KEY5 | 決定 / 開く / 曲開始 | HS-FIX次 | MARK NOTE | VISUAL OFFSET -1ms |
| 2P KEY6 | 戻る / 閉じる | DP OPTION次 | BPM GUIDE | GREEN NUMBER +1 |
| 2P KEY7 | 決定 / 開く / 曲開始 | SESSION MODE次 | MINE REMOVE | VISUAL OFFSET +1ms |
| Scratch Up | カーソル上 | TARGET前 | - | - |
| Scratch Down | カーソル下 | TARGET次 | - | - |
| Up / Down | カーソル移動 | TARGET前 / 次 | - | - |

- 選曲の決定には、キーモード別の鍵盤の割り当てを使います。BGAの切り替えはKEY1の割り当てを使います。
- 7K/14Kのキーボード操作で、7Kと14Kの2P側に同じキーを割り当てた場合は、7K側を優先します。
- アシストのevent・マウス操作・開閉timerも、3パネル方式の意味で扱います。
- ECFNの通常パネルには、F-RANDOM / MF-RANDOMを含む両サイド12種類の配置を表示します。上部のLNボタンには、FORCE系の設定時にバッジを表示します。これらは実験的な詳細オプションのON / OFFとは関係ありません。

#### 実験的な2パネル方式

「BMZ メニュー → 選曲 → 実験的な詳細オプション」は既定でOFFです。
ONにすると、`bmzDetailOptions: 1`と`bmzDetailOptionsNumbers: true`で対応を宣言したスキン（default、mz-select、Luxez-Flat、拡張済みのADFX02 / ECFN）では、通常 / 詳細の2パネルに切り替わります。
OFFの場合、対応していないスキン、スキンがない場合は、上の3パネル方式で操作します。
全21項目・スコープ・適用条件は[詳細プレイオプション](select-detail-options.md)を参照してください。

| 操作 | 動作 |
| --- | --- |
| 閉じた状態でE1を押す | 通常パネルをすぐ表示 |
| E1を200ms未満で離す | パネルを固定表示 |
| E1を200ms以上押してから離す | パネルを閉じる |
| 固定表示中にE1を押す | すぐ閉じる。そのときE1を離しても再び開かない |
| パネル表示中にE2を押す | 通常 / 詳細を切り替え。E2を離しても閉じない |
| 閉じた状態でE2だけを押す | パネルを開かない |
| 次にE1で開く | 通常パネルから開く。詳細パネルの項目カーソルはセッション中保持 |

詳細パネルでは次のように操作します。

- Scratch Up / Down、または独立したUI Left / Rightで前 / 次の項目を選びます。
- 選択式の項目では、各サイドの奇数鍵・UI Downで次の候補へ、偶数鍵・UI Upで前の候補へ進みます。
- 数値の項目では、奇数鍵・UI Upで増やし、偶数鍵・UI Downで減らします。
- 鍵盤とUIキーに同じキーを割り当てた場合は、鍵盤の操作を優先します。9Kでは独立した矢印キーかマウスを使えます。
- マウスホイールで項目を選び、選択式の候補をクリックすると直接設定できます。
- bool / enumは押した瞬間だけ変わります。数値は押し続けると400ms後から60ms間隔で繰り返し、最小 / 最大で止まります。
- 複数の方向を同時に押した場合は、最初に押した方向を優先します。項目を移動したりパネルを切り替えたりしたときは、押したままの値変更キーを押し直してください。

詳細パネルの表示と保存は次のとおりです。

- 項目は横並びの7列で循環し、選択した項目が中央へ移動するアニメーションを表示します。
- bool / enumはすべての選択肢を縦に表示し、数値は現在値を表示します。＋ / −ボタンはありません。
- 詳細パネルには、3パネル方式の詳細パネルにあるGAS方式、緑数字、BGA、判定表示自動調整、表示オフセット、判定アルゴリズムも含みます。
- 判定表示オフセットは、FASTが出るときは−方向、SLOWが出るときは＋方向へ調整してください。
- SUDDEN+ / HIDDEN+ / LIFTはそれぞれ独立していて、OFFにしても量を保持します。GASの下限はGASがOFFでも編集できます。
- キーモードが決まっていないときは7Kの設定を編集します。キーモードが決まった譜面では、キーモード変換後のモードを使います。
- 変更はすぐ反映し、詳細パネルを閉じるとき、または通常パネルへ切り替えるときに保存します。
- 通常パネルの設定と鍵盤の割り当ては、3パネル方式と同じです。

パネルの開閉と他の操作の関係は次のとおりです。

- フォーカスを失ったときや別のモーダルへ移ったときは、固定表示と入力を解除します。
- パネルを開閉・切り替えすると、途中のEscape長押しによる終了を取り消します。終了するには、パネルを閉じてからEscapeを改めて長押しします。
- 検索中やキーコンフィグ中のQ / Wは、文字入力・キーの割り当てへ渡し、オプションパネルの操作には使いません。

mz-select / Luxez-Flat / ECFNでは、通常パネルと詳細パネルの退出と登場のアニメーションを同時に再生します。
ECFNは既存のデザインに合わせた200msのフェード、ほかの2つは300msの横移動です。
退出中のパネルはクリックできません。詳細パネルからパネルなしへ閉じる300msの間は、背後の操作も受け付けません。

### 鍵盤での操作（9K）

「選曲画面の 設定 → INPUT」（`SELECT INPUT`）で`7K/14K`または`9K`を選べます。既定は`7K/14K`です。

| KEY2 | - | 1P RANDOM前 | SCROLL REMOVE | GAUGE AUTO SHIFT切り替え |
| KEY3 | 戻る / 閉じる | GAUGE次 | JUDGE AREA | JUDGE AUTO ADJUST切り替え |
| KEY4 | カーソル下（120ms長押しでG-BATTLEの相手選択） | GAUGE前 | LN REMOVE | GREEN NUMBER -1 |
| KEY5 | 決定 / 開く / 曲開始 | HS-FIX次 | MARK NOTE | VISUAL OFFSET -1ms |
| KEY6 | カーソル上 | DP OPTION次 | BPM GUIDE | GREEN NUMBER +1 |
| KEY7 | 決定 / 開く / 曲開始 | SESSION MODE次 | MINE REMOVE | VISUAL OFFSET +1ms |

9Kでは、プレイの鍵盤と既定のUI操作に同じキーを割り当てている場合、9K側の意味を優先します。

### LR2選曲スキン

LR2 CSVスキンでは、E1 holdで表示する基本オプションを次の配置にします。
2P側のKEY8〜KEY14も同じ並びで、KEY9は2Pの配置を変更します。

| キー | 操作 |
| --- | --- |
| KEY1 | 難易度フィルター |
| KEY2 | 配置（NORMAL / MIRROR / RANDOM / S-RANDOM / H-RANDOM / ALL-SCR） |
| KEY3 | キーフィルターが14KEYS / 10KEYSならDP FLIP、それ以外はBATTLE（OFF / D-BATTLE / SP-TO-DP / G-BATTLE） |
| KEY4 | ゲージ（NORMAL / HARD / DEATH / EASY） |
| KEY5 / KEY7 | ハイスピードを下げる / 上げる |
| KEY6 | ASSIST（OFF / AUTO SCRATCH） |

- E2 holdでスキンのパネル2、E1+E2 holdでパネル3を表示します。どちらもマウスで操作し、鍵盤では設定を変更しません。
- BMZのASSISTとDETAILの設定は、BMZ メニューで変更します。
- スキン内のスキン設定（SKIN SETTINGS）の上では、マウスホイールで一覧をスクロールします。クリックは曲バーへ渡しません。

スキンのパネルボタン（LR2 button 1〜6）は次のように動作します。

- クリックすると対応するパネルを固定表示し、同じボタンをもう一度クリックすると閉じます。
- パネル1の固定表示中も、鍵盤・ゲームパッドで設定を変更できます。
- E1 / E2の押下状態を変えると、hold操作に戻ります。
- 検索・設定画面・フォーカスの喪失・画面やプロファイルの切り替えでは、固定表示を解除します。

スキン内のオプションボタンは次のように動作します。

- 左クリックで操作し、BMZ メニューを開かずに、LR2の順で値を切り替えます。
- 増やすか減らすかはボタンの種類（＋のみ / −のみ / 左右半分）で決まります。難易度・キー・ソートのフィルターは常に次へ進みます。
- 現在値がEX-HARDやR-RANDOMなどのBMZ独自の値の場合は、次へ進むと先頭の値、前へ戻ると末尾の値へ移ります。
- BATTLEはSESSION MODE・DP OPTION・KEY CONVERSIONを書き換えます。D-BATTLEはDP OPTIONのBATTLE、SP-TO-DPはKEY CONVERSIONのSP TO DP、G-BATTLEはSESSION MODEのG-BATTLEです。
- BMZ独自の値や、FXなどBMZに同じ設定がない項目は、ボタンでは変更しません。これらはBMZ メニューから変更します。対応表は[スキン仕様](skin.md#lr2のselect--result)を参照してください。
- 画面下部の設定表示には、BMZの実際の値を表示します。

LR2のリザルトスキンでは、次のように進みます。

1. 決定の入力でグラフをスキップします。
2. スキンが指定した待ち時間の後、次の入力で更新演出を表示します（保存対象外の場合は省きます）。
3. その次の入力で選曲画面へ戻ります。

リトライの操作も、同じ演出の段階を経てから実行します。

### カーソルの移動

- 選曲バーは、移動途中の位置と速度を引き継いで、次の目標へ連続して移動します。
- キーの連打、マウスホイール、スクラッチにも同じ補間を使い、到着する前に減速して止まります。
- 方向を反転すると、短く減速してから戻ります。反転直後に元の方向へ進む量は最大で約1/4行です。
- 「BMZ メニュー → 選曲」の低速 / 高速スクロール時間は、最初の移動 / 長押し中の移動に使います。再入力時に行き過ぎを抑える必要がある場合は、設定より短い時間で到着します。
- 長押し中の次の入力は、設定時間の20ms前からつなげます（40ms未満の設定では設定時間の半分）。
- ページ移動は7行分を補間します。Home / End、スライダー、行の直接クリック、フォルダの切り替えは、移動の補間をリセットします。
- 決定する曲と詳細情報は、入力した直後の選択位置に従います。

### フォルダと一覧

- 空のフォルダを開こうとした場合は、現在の一覧とカーソルを保ったまま通知します。
- 一覧の更新で現在のフォルダが空になった場合は、項目のある最も近い親フォルダへ戻ります。詳しくは[空フォルダと一覧更新](select-folders.md#空フォルダと一覧更新)を参照してください。
- 対応スキンの`KEY CONFIG`ボタンは、現在のフォルダ階層を保ったまま「設定 → 入力 → キーコンフィグ」を開きます。キーコンフィグの一覧から戻ると、ボタンを押す直前のフォルダとカーソル位置へ戻ります。
- 対応スキンのボタンから、スキン設定、曲テキスト、IRページ、フォルダ、譜面の配布元URLを開けます。`UPDATE FOLDER`はF5と同じく、選択位置に応じた更新を行います。
- HISPEED、表示時間、判定表示のずれ、GUIDE SE、追加ノート / 地雷 / SCROLL / LNモディファイア、CONSTANTも、対応スキンのボタンから変更できます。

#### キーモードフィルター

- `ALL → 7K → 14K → 9K → 5K → 10K → 4K → 6K → 8K → ALL`の順で切り替えます。
- 同梱の選曲スキンのフィルターボタンも同じ状態を操作します。mz-select / Luxez-Flatは左右半分のクリックで前後へ、defaultはクリックで次へ切り替えます。
- 別途導入するECFNのBMZ拡張版も全9種類の名前を表示し、既存のボタンのクリックで次へ切り替えます。
- 選んだ値はプロファイルに保存します。
- 絞り込みには、登録した譜面の元のキー数を使います。BATTLEやキー数変換の後のキー数は使いません。
- 絞り込みで一覧がすべて消える場合は、行が残るまで次の値へ自動で進めます。フォルダ・コースなど譜面以外の行が残る場合は自動で進めず、コースの構成譜面の一覧は絞り込みません。

#### 難易度表のレベル表示

難易度表のレベルフォルダ内では、BMZの「レベル表示」設定をスキンのレベル欄にも適用します。

- 「難易度表」は現在の表のレベル、「譜面」は譜面本来のレベルを表示します。未所持などで譜面のレベルがない場合は、表のレベルを使います。
- 数値スプライトには、表のレベルが数字で始まる場合、その整数部分を表示します（`11+`→11、`12.5`→12）。
- `???`や`地力A`など数字で始まらない表のレベルは、LR2と同じく譜面本来のレベルを表示します。
- `SB-1`の`-1`のような負のレベルも、多くのスキンが負号を描けないため、譜面本来のレベルを表示します。
- 表名・所属する表の情報、表のレベルの文字列は保持します。

### F3と曲テキスト

- F3は、Windowsではエクスプローラー、macOSではFinderで譜面ファイルを選択した状態で表示します。
- LinuxではD-Busの`org.freedesktop.FileManager1.ShowItems`を使います。`dbus-send`がない場合、ファイルマネージャーが対応していない場合、応答が失敗した場合は、フォルダを開きます。
- 譜面ファイルが見つからない場合や、通常のフォルダ行を選択中の場合も、フォルダを開きます。
- ZIP / RAR / 7z内の譜面では、元の書庫ファイルを選択します。
- 曲テキストを開く操作（既定は9）は、書庫内の同じ曲フォルダの`.txt`をキャッシュへ展開して開きます。

### ファイルのドロップ

- `.bms` / `.bme` / `.bml` / `.pms` / `.bmson`ファイルを選曲画面へドラッグ＆ドロップすると、その譜面をライブラリへ取り込んで通常プレイを開始します。
- 通常の起動では、選曲画面以外へのドロップは受け付けません。
- Viewerのウィンドウへのドロップは、[BMS作成ツール向けビューワー](viewer.md#ドラッグドロップ)を参照してください。

### ランダム選曲

「BMZ メニュー → 選曲」、または「選曲画面の 設定 → 選曲 → RANDOM SELECT」で、次の項目を個別にON / OFFできます。
すべて既定でOFFです。

| 項目 | 抽選の対象 |
| --- | --- |
| RANDOM SELECT | 条件なし |
| NO PLAY RANDOM SELECT | 保存スコアがない、またはプレイ回数が0 |
| FAILED RANDOM SELECT | ベストランプがFAILED |
| NOT EASY RANDOM SELECT | EASY未満 |
| NOT CLEAR RANDOM SELECT | NORMAL未満 |
| NOT HARD RANDOM SELECT | HARD未満 |
| NOT EX-HARD RANDOM SELECT | EX-HARD未満 |
| NOT FULL COMBO RANDOM SELECT | FULL COMBO未満 |

- 「NOT 〜」には未プレイの譜面も含みます。
- 判定には、選曲画面の表示と同じ保存スコア（現在のプロファイル・LN設定・ルールモード）を使います。
- 現在の一覧で、モード・難易度フィルターに残った所持譜面から抽選し、決定するとプレイを開始します。サブフォルダ内は探しません。
- 通常のRANDOM SELECTは候補が2曲以上、条件付きの項目は1曲以上ある場合に表示します。
- 同じ曲が続けて選ばれる場合があります。

### IRとライバル

- 対応スキン（`selectIrScopeBinding = "active"`と`selectIrScopeToggle = "e3_press"`を宣言したスキン）では、E3で`RANKING`（全体）と`RIVAL`（自分 + IRライバル）を切り替えます。
- E3が働くのは、曲の行を選択中で、オプションパネル・検索・設定の編集を開いていないときです。Rival scopeに対応していない場合は何もしません。
- 7で選んだrianIRのライバルに対象譜面のスコアがあれば、そのEXスコアをプレイ時のターゲットとして使います。
- ライバルが未プレイの譜面では、beatorajaと同じく通常のTARGET設定を使います。
- ライバル一覧は、起動時にログイン済みのrianIRからバックグラウンドで同期します。`ir rivals`コマンドは手動での再同期・確認用です。
- rianIRでのライバルの追加・解除は、Webサイトで行います。

### G-BATTLE

曲の行を選択中にKEY4を120ms以上長押しすると、SESSION MODEに関係なく、LR2と同様に曲リストがG-BATTLEの相手選択へ一時的に切り替わります。

- 短く押した場合は、そのキーモードでの通常のKEY4の操作になります。
- 長押しした後にキーを離すと、元の曲リストへ戻ります。
- Tabで固定表示できます。もう一度Tab、戻る操作、Escapeで閉じます。

相手選択の一覧には、先頭に`BATTLE OFF`（既定）、`MYBEST`、`REPLAY 1`〜`REPLAY 4`、`RIVAL (名前)`が並び、その後にIRランキングが続きます。
上下・ページ移動・スクラッチ・マウスホイールで選び、決定するとG-BATTLEを開始します。

- ローカルの項目と、リプレイ公開に対応したIRは、フル入力のリプレイを独立した相手の判定に使います。
- リプレイが未検証、形式が合わない、譜面 / LNポリシーが合わない場合は開始せず、選曲画面に理由を表示します。
- リプレイが公開されていない相手は、配置を再現し、相手側をAUTOPLAYで再生します。
- `BATTLE OFF`を選んだ場合もSESSION MODEは変えず、相手側をAUTOPLAYにします。
- 2P側には、リプレイの有無にかかわらず、1P側で確定した配置と同じ配置を表示します。

相手を決定してもSESSION MODEは変えません。

- `NORMAL`では通常の5K / 7Kスキン、`G-BATTLE`では5K / 7KのBATTLEスキンのまま開始します。
- SESSION MODEで`G-BATTLE`を選んで曲を直接決定した場合は、相手選択画面を開かず`BATTLE OFF`で開始します。
- G-BATTLEは2K / 4K / 5K / 6K / 7K / 8K / 9K / 10K / 14Kで使えます。`AUTOPLAY BATTLE` / `G-BATTLE`でバトルスキンを使うのは5K / 7Kだけで、ほかのキーモードは通常のスキンを使います。

G-BATTLEの相手を指定したプレイでは、`CHART REPLICATION`で自分側の譜面を次のように決めます。

- `RIVALCHART`：相手の譜面オプションとseedを自分側にも適用します。
- `RIVALOPTION`：相手の譜面オプションだけを適用し、自分側のseedを保ちます。
- `NONE`：自分側の配置を変更しません。

7で選択中のrianIRのライバルとG-BATTLEの相手が異なる場合は、そのプレイで明示したG-BATTLEの相手を優先します。

相手選択中の表示と音は次のとおりです。

- 人物の表示に使うタイトル・サブタイトル・ジャンル・アーティスト以外の譜面情報は、選択元の曲のままです。
- IRランキングの行ではレベル欄にランキングの順位を表示し、それ以外の固定行ではレベル欄を表示しません。
- G-BATTLEの開閉や相手のカーソル移動では、現在の曲のプレビュー再生を続けます。
- G-BATTLEの開始時は、画面を閉じるSEを鳴らさず、決定BGMだけを再生します。

### コース

`COURSE`フォルダの`新規コース`を決定すると、LR2風のコース作成モードに入ります。

- 通常どおり曲フォルダ、難易度表、検索結果を移動し、所持譜面を決定すると課題曲へ追加します。
- 課題曲はキーモードを混ぜて最大10譜面まで追加でき、同じ譜面を重複して追加することもできます。
- 画面上のパネルで、コース名、制約、トロフィー、IR送信の可否の変更、曲順の変更、個別の削除、直前の追加の取り消し、保存、キャンセルを行えます。
- トロフィーの編集欄は既定で折りたたんでいて、新規コースにはトロフィーがありません。
- キーボードのBackspace / Deleteは直前の追加を取り消し、Escapeは作成をキャンセルします。
- 戻る操作は、フォルダ内では1階層戻り、ルートでは作成をキャンセルします。
- 保存したコースは`COURSE`フォルダへ追加します。
- 課題曲の検索やJSONの入出力などの詳しい編集は、BMZ メニューのツール「コース作成」で行います。

`COURSE`フォルダの`RANDOM MIX`を決定すると、現在のキーモードから最大5譜面を抽選し、同じ曲フォルダを重複させない一時的なコースとして開始します。
「選曲画面の 設定 → 選曲」で、目標レベル、レベルの上限・下限、BPMの上限・下限、先頭の曲を基準にしたBPMの幅、曲数を変更できます。
曲数を`RANDOM`にすると、2〜4曲を抽選します。

### 未所持譜面の取得

難易度表の未所持譜面を決定すると、「BMZ メニュー → ライブラリ」の「未所持譜面の取得」に従い、`IPFS > HTTP > ブラウザ`の順で使える方法を選びます。

- IPFS / HTTPは既定で無効です。有効にする場合は、使うAPIのURLを入力してください。
- 取得した譜面は`data/songs/ipfs` / `data/songs/http`へ保存し、完了後に自動でライブラリへ登録します。
- 取得に成功した保存先は、有効な再帰スキャン対象の曲フォルダとして設定にも保存します。有効な再帰スキャン対象の親フォルダが登録済みなら、重複して追加しません。
- 保存先自身を無効にしていた場合は、もう一度取得すると有効になります。

難易度表フォルダやレベルフォルダをまとめて取得する場合は、フォルダを選んでから「BMZ メニュー → ツール → 譜面ダウンロード」を開きます。
件数の確認、除外の条件、進捗の操作は[譜面ダウンロード](chart-downloads.md)を参照してください。

## プレイ画面

譜面の読み込みに失敗した場合は、決定画面・プレイ開始待ちのどちらでも開始を中止します。
選曲画面へ戻り、対象のパスを含むエラーを通知します。

### プレイ中の操作

プレイ画面（ロード中・READY・終了待ちを含む）では、E4をE1と同じ操作として扱います。
下の表のE1はE4に読み替えられます。たとえばE4 holdでHSの操作、E4+E2 長押しで中断、FAILED演出中のE4で別配置のクイックリトライになります。
E1とE4を同時に押している場合は、両方を離すまでE1 holdを保ちます。
選曲画面・リザルト画面では、E4はE1とは別の操作です。

| キー | 操作 |
| --- | --- |
| Left / Right | Normalは20段階を下げる / 上げる。Classic / Floatingは設定の刻みで倍率を下げる / 上げる |
| Up / Down | SUDDEN+の表示中はSUDDEN+、非表示中は有効なLIFT / HIDDEN+を調整。変化量は[レーンカバーとHS](#レーンカバーとhs)を参照 |
| E2 hold + Up / Down | Up / Downと同じ対象を1ずつ微調整 |
| マウスホイール | Up / Downと同じ対象を調整。上へ回すとカバーが上がる |
| E2 hold + マウスホイール | マウスホイールと同じ対象を、1目盛りで1ずつ微調整 |
| E1 hold + 鍵盤 | キーモードごとのHSの方向に従い、Normalは段階、Classic / Floatingは倍率を変更 |
| E1 hold + E2 | LIFT / HIDDEN+が両方有効なときは変更対象を切り替え。それ以外は、切り替えられる設定でFloatingを切り替え |
| E1 hold + Scratch Up / Down | Up / Downと同じ対象のカバー量を変更 |
| E2 hold + 鍵盤 | Floatingを使える設定では、E1と同じキーモードごとの方向に従い、緑数字を下げる / 上げる |
| E2 hold + Scratch Up / Down | Floatingを使える設定では、緑数字を下げる / 上げる |
| E1 2回押し | SUDDEN+が有効な場合だけ、SUDDEN+の表示を切り替え |
| 3 / Numpad3 | 描画の判定調整を+1ms |
| 9 / Numpad9 | 描画の判定調整を-1ms |
| 0 / Numpad0 | 自動判定調整を切り替え（押した瞬間だけ切り替わり、キーリピートでは切り替わらない） |
| Escape | プレイを中断して選曲画面へ戻る |
| E1+E2 長押し | プレイを中断 |
| E2+E3 | すぐにプレイを中断 |
| FAILED演出中にE1 | リザルトへ進まず、別配置でクイックリトライ |
| FAILED演出中にE2 | リザルトへ進まず、同じ配置でクイックリトライ |
| Autoplay / Replay中に1 / 2 / 3 / 4（上段またはテンキー）をhold | 再生速度を25% / 50% / 200% / 300%へ変更。離すと100%へ戻る |

### 中断とFAILED

- Escape / E1+E2 長押し / E2+E3で中断した場合、実プレイの開始前（譜面・音源のロード中とREADY演出中）なら、スキンの退出フェード（timer 2）を開始し、リザルトを表示せずに選曲画面へ戻ります。
- 実プレイの開始後に中断した場合は、FAILED演出を開始し、通常の終了処理へ進みます。
- 最終ノーツの処理後は、終了待ち時間（finishmargin）の間も含め、EscapeでE1と同じく退出演出をすぐ開始します。開始済みの退出演出はスキップしません。

途中でFAILEDになった場合は、閉店演出の開始時に、そのプレイのBGM・キー音（再生中と予約済み）を止めます。

- HARD / EXHARD / HAZARDなどのゲージが尽きたことによる途中FAILEDも同じ扱いです。
- 閉店の効果音、スキンの音声、リザルトのBGM / SEは通常どおり再生します。
- 最後まで演奏した場合（完走時のFAILEDランプを含む）や、全ノーツの処理後に終了操作をした場合は、譜面の音の余韻を残します。
- GASで別のゲージへ移ってプレイを続ける場合も、譜面の音を止めません。

詳しくは[Gameplay runtime](gameplay-runtime.md#途中failed時の譜面音声)を参照してください。

### クイックリトライとAutoplayの再生速度

- クイックリトライは、単曲の通常プレイでだけ使えます。
- Autoplay / Replayの速度操作のキーは固定で、キーコンフィグの対象外です。
- 再生中は、プレイカテゴリのショートカットより、上段の1〜4・テンキーの1〜4による速度変更を優先します。
- 現在のキーモードのレーン / スクラッチ、または共通のE1〜E4に同じキーを割り当てている場合は、その割り当てを優先し、速度変更には使いません。
- 割り当てのない複数のキーを同時にholdした場合は、数字の小さいキーを優先します。

### レーンカバーとHS

SUDDEN+、LIFT、HIDDEN+の有効 / 無効は、「BMZ メニュー → プロファイル」の「表示」と「選曲画面の 設定 → 表示」で、キーモードごとに変更できます。
無効なカバーは表示されず、量の変更の対象にもなりません。

- LIFTとHIDDEN+を同時に有効にした場合、プレイ開始時の変更対象はLIFTです。E1+E2を押すたびにLIFT / HIDDEN+を切り替えます。押す順序は問いません。
- この短押しでの切り替えと、E1+E2 長押しによる中断は両立します。
- HIDDEN+を変更対象にした場合だけ、増減の方向がSUDDEN+ / LIFTと逆になります。カーソルキーとE1 hold + ScratchのどちらでもUpでHIDDEN+の量が増え、Downで減ります。

カバー量は1000でレーン全体です。カーソルキーでの変化量は次のとおりです。

- Up / Downを押した瞬間に、入力設定の`LANE COVER STEP`（既定10）だけ動きます。
- `LANE COVER HOLD DELAY`（既定300ms）以上押し続けると、1/60秒ごとに`LANE COVER HOLD STEP`（既定3）ずつ動きます。OSのキーリピートは使いません。
- E2を押しながら操作した場合は、押した瞬間も押し続けている間も1ずつ動きます。E2を押しているかどうかは、Up / Downを押した時点で判定します。
- 3つの値はどれも1刻みで、範囲はそれぞれ`1..=1000`、`0..=1000ms`、`1..=100`です。

マウスホイールでの変化量は次のとおりです。

- 1目盛りで`LANE COVER WHEEL STEP`（既定5、beatoraja / EndlessDreamの0.005と同じ）だけ動きます。範囲は`1..=1000`です。
- E2を押しながら回すと、1目盛りで1ずつ動きます。
- 高分解能ホイールの細かい回転は積算して、1目盛り単位で適用します。トラックパッドなどのピクセル単位の回転は、40pxを1目盛りとみなします。
- 向きが反転したとき、または200ms以上回転が途切れたときは端数を捨てます。1回の入力で適用するのは20目盛りまでです。
- 操作対象、Floatingの再計算、カバーがすべて無効なときのHS操作は、Up / Downと同じです。HSを操作する場合は、1目盛りで1段階変わります。

E1 hold + Scratchのアナログ回転は、`ANALOG SCROLL`のtick数に届くたびにカバーを1動かします。
届かない回転量でも、スクラッチが反応した時点でFloatingのHSを再計算します。
LIFTが対象の場合はHS Auto AdjustがONのときだけ再計算し、HIDDEN+が対象の場合は再計算しません。

SUDDEN+、HIDDEN+、LIFTの量の既定値は150です。新規プロファイルのLIFTは既定でOFFです。
有効なカバーの量が0のままプレイを開始すると、開始時に150へ変更して保存します。
無効なカバー、CLIでの一時的な上書き中、コースのNoSpeed制約中は変更しません。

HS設定は`NORMAL` / `CLASSIC` / `FLOATING` / `NORMAL+FLOATING` / `CLASSIC+FLOATING` / `LR2`の6種類です。

- `NORMAL`、`CLASSIC`、`LR2`では、Floatingと緑数字の操作を無効にします。
- `FLOATING`ではFloatingに固定します。
- 末尾が`+FLOATING`の2つの設定だけ、E1 hold + E2で基準方式とFloatingを切り替えられます。

Normalの段階表と切り替え時の変換規則は[ハイスピード](hs.md)を参照してください。

SUDDEN+が無効または非表示で、LIFT / HIDDEN+も無効なため操作できるカバーがない場合、カバーの操作はEndlessDream互換のHS操作になります。

- HS Auto AdjustがOFFなら、デジタル入力は現在の方式の速度操作、アナログスクラッチは1 tickあたり0.01でHSの倍率を直接変更します。
- HS Auto AdjustがONのFloatingでは、SUDDEN+とLIFTを0として、現在のBPMでHSを再計算します。
- どちらの場合も、無効なSUDDEN+ / LIFT / HIDDEN+の量は変更・保存しません。

E1 / E2 hold中の鍵盤の方向は、譜面のキーモードごとに次のとおりです。
Downはハイスピードまたは緑数字を下げ、Upは上げます。10K / 14Kは1P / 2Pの両側に同じ規則を適用します。

| キーモード | Down | Up |
| --- | --- | --- |
| 4K | KEY1 / KEY4 | KEY2 / KEY3 |
| 5K | KEY1 / KEY3 / KEY5 | KEY2 / KEY4 |
| 6K | KEY1 / KEY3 / KEY4 / KEY6 | KEY2 / KEY5 |
| 7K | KEY1 / KEY3 / KEY5 / KEY7 | KEY2 / KEY4 / KEY6 |
| 8K（既定） | KEY2 / KEY4 / KEY5 / KEY7 | KEY1 / KEY3 / KEY6 / KEY8 |
| 9K | KEY1 / KEY3 / KEY5 / KEY7 / KEY9 | KEY2 / KEY4 / KEY6 / KEY8 |
| 10K（1P / 2P） | KEY1 / KEY3 / KEY5 | KEY2 / KEY4 |
| 14K（1P / 2P） | KEY1 / KEY3 / KEY5 / KEY7 | KEY2 / KEY4 / KEY6 |

- 8Kの各鍵盤の方向は、「選曲画面の 設定 → 入力 → キーコンフィグ → 8K」で個別にDown / Upへ変更できます。
- 譜面のレーンとしてスクラッチを持たない4K / 6K / 8K / 9Kでも、7Kのスクラッチの割り当てを使って、E1 / E2 hold中のレーンカバー・緑数字の操作ができます。このスクラッチ入力はHSの操作専用で、譜面の判定には使いません。
- コースのNoSpeed制約中は、HS 1.0、SUDDEN / LIFT / HIDDEN 0で開始し、HS MODE・ハイスピード・緑数字・レーンカバーの操作をすべて無効にします。制約中の一時的なレーンの状態は、プロファイルへ保存しません。

### プラクティス

次のどれかでプラクティス設定を開きます。どの場合も決定画面を経由します。

- 選曲画面でSESSION MODEをPRACTICEにして曲を決定する
- 選曲スキンのPRACTICEの操作を使う
- 譜面のパスと`--practice`を指定して起動する

コースではPRACTICEをNORMALとして扱います。

| キー | 操作 |
| --- | --- |
| Up / Down | 設定項目を移動 |
| Left / Right | 選択中の値を減らす / 増やす |
| Enter | 区間プレイを開始 |
| Escape / E1+E2 長押し / E2+E3 | 設定を保存して選曲画面へ戻る |
| Scratch Up / Down | 設定項目・開始・戻るを移動 |
| KEY2 / KEY4 / KEY6 | 選択中の値を減らす |
| KEY1 / KEY3 / KEY5 / KEY7 | 選択中の値を増やす。開始・戻るを選択中は、そのボタンを実行 |

- 入力には実際の譜面用のキー割り当てを使い、DPでは1P / 2Pのどちら側でも同じ規則です。
- E1 / E2を単独で押しても、開始・退出はしません。E1 / E2 hold中は、プレイ側のHS・レーンカバーの操作を優先します。
- マウスでも、各入力欄・選択肢・ボタンを直接操作できます。
- 設定ウィンドウは、タイトルバーをドラッグして移動できます。

設定できる項目は、開始・終了位置、ゲージの種別 / カテゴリ / 初期値、判定ランク、TOTAL、50〜200%の再生速度、グラフの種別、1P / 2Pの配置、DP FLIPです。

- 開始位置を変更すると、背面の譜面プレビューもすぐその位置へ移動します。
- 秒の線とBPM / STOPのガイドは、設定中だけ表示し、区間プレイ中には表示しません。
- 区間プレイの後は決定画面を挟まず、ロード済みの譜面・音源・BGAを再利用して、直前の判定グラフを表示した設定画面へ戻ります。
- 最終ノーツの処理後にE1 / E2 / Escapeで終了した場合も、リザルトを表示せず、直前の判定グラフを反映してプラクティス設定画面へ戻ります。

DX MODEでのゲージの初期値と上限は次のとおりです。

- 設定を新規作成する場合は、実プレイの定義から初期ゲージを選びます。7KなどのAssistEasy / Easy / Normalは22、9KのAssistEasyからExHardまでは30、それ以外は100です。
- DXでゲージの種別を切り替えた場合も、そのゲージの初期値へ戻ります。
- 設定済みの初期ゲージは20を含めて保持し、1から現在のゲージの上限までの範囲外だけ補正します。
- 上限は実際のゲージと同じで、DX 9KのAssistEasyからExHardまでは120、Hazardと段位系は100です。DX以外でも、ゲージの種別・カテゴリに対応する上限を使います。マウスとキー操作で範囲は同じです。
- DXのゲージカテゴリ・判定ランク・TOTALは実プレイ側で固定されるため、設定画面でも`POP / IIDX (DX MODE)`、`AUTO (DX MODE)`と表示し、マウス・キーのどちらでも変更しません。保存済みの各設定値は保持し、ほかのルールモードでは編集できます。

設定値は譜面のSHA-256ごとに保存します。
保存先はデータディレクトリ内の`profiles/<profile>/practice/<譜面SHA-256>.json`です。

- JSONの破損・型の不一致・読み取りの失敗時は、パスと理由をログへ警告し、譜面と現在のルールモードに対応する新しい設定で開きます。CLIでの開始・終了位置の指定も通常どおり適用します。
- 読み込むときは元のファイルを変更しません。
- 開始・区間終了・退出時の自動保存で破損データを置き換える場合は、同じフォルダの`<譜面SHA-256>.json.corrupt-<UUID>.bak`へ元のbytesをそのまま退避・同期してから、新しいJSONへ置き換えます。
- 既存ファイルの読み取り、退避、保存のどれかが失敗した場合は、元のファイルを残して警告します。

### Viewer

Viewer modeでは、通常プレイのカーソルキーの操作を使わず、編集確認向けの専用の操作になります。
キー操作、一時停止、シーク、待機中の操作、終了方法は[BMS作成ツール向けビューワー](viewer.md#viewer操作)を参照してください。

### 対応スキンでの操作

- `GRAPH DATA` / `INTERNET RANKING`タブをマウスでクリックすると、パネルを直接切り替えられます。
- Favoriteボタンは、現在の譜面をお気に入りの譜面へ追加 / 解除します。BMZはinvisible状態へは切り替えません。
- `resultIrScopeBinding = "active"`と`resultIrScopeToggle = "e1_press"`を宣言したリザルトスキンでは、IRパネルの表示中にE1で`RANKING`（全体）と`RIVAL`（自分 + IRライバル）を切り替えます。Rival scopeに対応していない場合、グラフパネルの表示中、退出演出中は何もしません。
- E2 / SELECTは、IRパネルとグラフパネルを切り替えます。
- IRランキングとtype 8 sliderを表示する対応スキンでは、IRパネルの表示中に、マウスホイール、上下キー、D-pad Up / Down、選曲用のScratch Up / Downで、ランキングを1行ずつスクロールできます。アナログスクラッチの感度とキー長押しのリピート間隔は、選曲画面の設定を使います。

## 互換・移行

- 既存のプロファイルで「LIFT有効・量0」になっているキーモードは、読み込み時にLIFTを無効にし、量を150へ移行します。以前の既定のLIFT設定で、プレイ開始時の補正により判定ラインが上がらないようにするためです。この移行はプロファイルの`version`が2未満のときに一度だけ行います。移行後にプレイ中の調整でLIFTを0にしても、読み込み時には無効にしません。
- 旧BMZの5K / 7Kのリプレイに混入した2P表示のレーンは、G-BATTLEの相手の再生時に除外します。入力時刻の微小な前後は、安定した時刻順へ補正します。Replay v3以前の配置seedも当時の方式で再現します。
