# KaleidBeat 動的条件分岐

BMZ は BMS / BMC の `#CONDITIONAL` を通常プレイ、AUTOPLAY、リプレイ、先頭からの Viewer 再生・動画出力で扱う。
仕様の出典は `.local/KaleidBeat/documents/format-header.html`。以下の境界処理、RATE、LAMP、途中終了の扱いは BMZ の実装仕様であり、Kaleid の実行結果との完全一致を確認したものではない。

```bms
#BPM 120
#WAV01 normal.wav
#WAV02 easy.wav
#CONDITIONAL 16.5
#WHEN MISS>=10
#01711:02000200
#ELSEWHEN GAUGE<30
#01711:02000000
#DEFAULT
#01711:01010101
#ENDCONDITIONAL
```

評価位置は 0 始まりの小節番号と小節内割合。各ブロックは一度だけ評価し、先頭から最初に成立した条件を選ぶ。該当しなければ必須の DEFAULT を選ぶ。比較演算子は `> >= < <= == !=`。複合式・入れ子・枝内のヘッダ定義は受け付けない。静的な RANDOM / IF / SWITCH は取り込み時に解決し、その選択記録は従来どおり別に保存する。

| 変数 | BMZ の値 |
| --- | --- |
| SCORE | 現在の EX スコア |
| RATE | EX スコア / (DEFAULT の採点ノーツ数 × 2) × 100。分母 0 は 0 |
| COMBO / MAXCOMBO | 現在 / 最大コンボ |
| PGREAT / GREAT / GOOD / BAD / POOR | FAST + SLOW の判定数。POOR に空 POOR は含めない |
| MISS | BAD + POOR + 空 POOR。未来の未判定分は含めない |
| GAUGE | 現在選択されているゲージ値 (%) |
| LAMP | プレイ開始前に現在の ScoreKey で保存されていたベストランプ |
| AUTO | フル AUTOPLAY は 1、それ以外は 0。部分オートは 0 |

LAMP は `0=NoPlay, 1=Failed, 2=AssistEasy, 3=LightAssistEasy, 4=Easy, 5=Normal, 6=Hard, 7=ExHard, 8=FullCombo, 9=Perfect, 10=Max`。
RATE は全曲 DEFAULT 分母なので、進行度や枝のノーツ数によってはリザルトの EX 率と異なり、100 を超える場合もある。

## 分岐境界

評価時刻 T より前の入力・見逃し・保持ゲージ更新を処理してから条件を評価する。同じ T のブロックは同じスコア / ゲージの状態を見る。採択後に T の入力を処理する。同位置の BPM と STOP は BPM → STOP の順で、新 BPM から STOP の長さを求める。

分岐は BMZ が取り込み済みの全チャンネルを対象とする。ノーツ、地雷、BGM、BGA、SCROLL、SPEED、判定ランク、音量、テキスト等に加え、03 / 08 / 09 / 02 も切り替えられる。各チャンネル本体の既存の制約はそのまま適用され、未対応チャンネルを新たに実装する機能ではない。

- 枝内の非ゼロオブジェクトは評価位置以降に置く。過去の書き換えは取り込みエラー。
- 小節長 02 は未開始の小節だけを変更できる。16.5 で変更できるのは 17 小節以降。16.0 なら 16 小節も変更できる。
- BPM / STOP / 小節長の変更は未確定のノーツ、BGM、BGA、後続の分岐、終了時刻へ反映する。
- 判定済みノーツ、BAD 入力を処理済みのノーツ、開始済み LN は旧譜面のまま固定する。LN の端点も維持し、その区間と衝突する新枝のノーツを除く。過去のスコアやゲージは戻さない。
- 分岐確定後に届いた過去時刻の人間入力は、最後の分岐時刻まで時刻を繰り上げて扱う。無制限の巻き戻しはしない。
- 共通部分と採択枝は原文順で結合する。BGM の重ね配置は保持し、同位置の STOP は後の記述を採用する。

## 音声

全枝の音源をプレイ前にロードする。通常の先行予約幅は維持し、分岐に合わせて予約を止めない。既に予約済み・再生中の旧枝音は取り消さない。切り替え後は T 以降の未予約イベントを予約する。共通 BGM の予約済み状態は位置と音源の識別情報で引き継ぐ。

予約済みの旧枝音と新枝音は重なり得る。長い音の残響も残る。更新頻度により境界の音は変わり得るが、それをノーツ数や判定へ反映しない。

## 集計・保存

- 選曲・library DB・事前密度は DEFAULT。取り込みバージョンを更新しており、既存登録は再スキャンで更新する。
- TOTAL と判定によるゲージ増減係数は、プレイ開始時の DEFAULT 基準で固定する。
- リザルトは実際に採用された譜面の採点ノーツ数を使う。Tap / LN / HLN は 1、CN / HCN は 2。見逃しを含み、非採択枝や地雷・空 POOR は含めない。
- リザルトの理論 EX と EX 率は実ノーツ数を分母にする。ベストスコアは既存の ScoreKey と比較方式を使う。
- 途中終了では未評価の枝を DEFAULT として確定する。その時点の譜面全体を結果の分母にし、未処理ノーツの POOR 補完は通常の結果処理に従う。
- Replay v9 にブロック番号・採択枝・評価時刻を保存する。再生時は記録を優先し、現在のベストランプで選び直さない。枝記録のない旧リプレイは DEFAULT を使う。
- 同一配置リトライも同じ配置 seed で DEFAULT から読み直し、前回の枝を引き継がず条件を評価し直す。
- ローカル保存は可能。IR の仕様対応が済むまでは、新規送信・バックフィルを除外し、分岐フラグ付き送信キューも拒否する。

## 実装範囲と確認事項

PRACTICE、BATTLE（譜面オプションも含む）、Viewer の途中再生は未対応としてエラーにする。途中開始時の条件状態復元と、対戦相手ごとの独立した分岐は後続作業。

Kaleid 管理人へ確認すると互換性を詰められる項目は、RATE が全曲分母か進行分母か、LAMP の数値対応、早押し済みノーツ / 開始済み LN の差し替え、途中終了時の未評価枝の扱い。これらは上記 BMZ 仕様で実装済みなので、通常プレイの実装は確認待ちにしない。

実装入口:

- `bmz-chart/src/conditional.rs`: 構文解析、中間譜面の結合、時刻再計算、安定したノーツ / 音声識別情報。
- `bmz-gameplay/src/session/conditional.rs`: 条件評価、確定済み判定の保護、音声カーソル引継ぎ。
- `bmz-player/src/screens/play_session/preload.rs`: 同じオプション / seed による枝の変換。
- `bmz-player/src/storage/replay.rs`: Replay v9 の記録と検証。

境界では譜面ファイルを再パースせず、ロード済み中間データを再正規化する。全組み合わせの事前展開は行わない。非常に大きい譜面や密な分岐での実測・最適化は今後の課題。
