# 譜面ダウンロード

## 難易度表の一括取得

選曲で難易度表フォルダ・レベルフォルダを選択して、F1 →「譜面ダウンロード」→
「未所持譜面を確認」を押します。表示中のフォルダも対象にできます。
対象総数・所持済み・自動取得可能・取得不可・重複を確認し、「キューへ追加」で確定します。
レベルフォルダではそのレベルのみ、難易度表フォルダでは全レベルが対象です。
現在の選曲のモード・難易度フィルタによる表示件数には限定しません。

表の譜面とローカル登録をまとめて照合し、SHA256/MD5の大小文字・前後空白を正規化します。
ハッシュなし・不正なハッシュだけのエントリは所持済みにせず、自動取得不可に集計します。
ブラウザによる手動取得は一括キューに混ぜません。実行履歴にはキュー登録・統合・成功・失敗の件数を表示します。
一括取得は現在のカーソル・フォルダ・フィルタを維持します。

## 進捗と操作

F1 →「譜面ダウンロード」で実行中・待機・完了・失敗・キャンセルの一覧を切り替えます。
各行にタイトル、取得方式、状態、取得量、エラーを表示し、行のボタンでキャンセル・再試行できます。
「待機中をすべてキャンセル」はまだ開始していない要求だけを対象にします。
総容量が不明な通信では取得済みバイト数だけを表示し、割合は表示しません。
全体の進捗は終了したタスク数です。一括取得の成功・失敗は対象譜面ごとに集計します。
複数譜面で共有するアーカイブは同じタスクへ統合される場合があります。
履歴は再起動時に消えます。失敗の詳細はエラー欄にマウスを重ねて確認できます。

未所持譜面の決定操作は、設定が有効ならIPFS、次にHTTPの順で自動取得を選びます。
どちらも利用できなければ、表に記載されたHTTP/HTTPSの配布ページをブラウザで開きます。
コース不足譜面の取得も同じキューを使います。

HTTPの同時実行数は `downloads.http_parallelism`（初期値3、実効値1〜5）です。
IPFSは1件、アーカイブ展開は全方式を合わせて1件に制限します。
待機中の要求ごとにスレッドや非同期タスクは作りません。

状態は待機、取得元確認、ダウンロード、展開、登録、完了、失敗、キャンセルです。
完了はアーカイブ保存だけではなく、要求したSHA256/MD5を持つ譜面が保存先の部分スキャンで
ライブラリDBに登録されたことを確認した状態です。対象が含まれないアーカイブは失敗になります。
スキャンは既存のキューへ追加し、Play/Result中の反映は次のSelectまで保留します。
転送はメニューを閉じた後や画面遷移後も継続します。

単一譜面の取得後は、同じフォルダで選曲操作をしていなければハッシュで対象を選択します。
選曲・フォルダ・フィルタを変更した場合は選択を奪わず、フィルタも変更しません。
所持済み行の通常復元にはChartIdを使い、同じファイルの複数の登録を区別します。

重複する対象ハッシュや解決済みアーカイブURLは、同じ取得元設定・保存先の範囲で共有します。
API URLの認証情報・クエリを含む文字列が違う場合は共有しません。
IPFSはAPI URLと追加パッケージを含むCID列が一致する場合に共有します。
共有アーカイブに対する各対象ハッシュは個別に登録確認します。

キャンセルは通信待ち・転送・展開に反映し、要求専用の一時アーカイブとstagingを削除します。
保存確定後の曲フォルダは削除せず、DBスキャンも安全に完了させます。
失敗・キャンセルは手動再試行でき、展開済みなら転送を繰り返さず登録を再試行します。
自動再試行、再起動後のレジュームは行いません。履歴はメモリ内に保持します。

通信8 GiB、展開16 GiB、単一ファイル4 GiB、10万エントリの既存制限を維持します。
HTTP/HTTPS以外のURL、保存先外のパス、リンクなどの非対応エントリを拒否し、
タスクごとに一意の一時パスと保存先を使います。
