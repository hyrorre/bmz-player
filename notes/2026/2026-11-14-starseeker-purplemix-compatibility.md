# starseekerとfivemania purpleMIXの表示互換

起点は `fb2c3f3b`。仕様は [スキン仕様](../../docs/skin.md) を参照。

- starseekerのカスタムフレーム `[CFM] LR2` の `Gauge Type - LR2` は小数部の画像を `digit = 0` としている。beatorajaの数値描画は指定された桁数だけ描くため、0桁では小数部が出ない。BMZの符号なし数値描画も0桁の場合は空にした。
- LR2のプレイ描画では各レーンのノーツ画像と描画位置を同じ番号で参照する。fivemania purpleMIX v1.11の5KEYS / 10KEYSも、1Pと2PのスクラッチをCSVの0と10に定義している。BMZのLR2変換が使う片側8枠に、画像・位置・高さの参照を揃えた。DP / BATTLEではスキンのオプション901による片側への再配置を適用しない。
- Windowsで比較用の譜面をオフライン動画に書き出し、修正前後の8秒時点を比較した。starseekerは検証用コピーに同梱の `Gauge Type - LR2` の左右フレームを適用し、`100%` の横に出ていた小数が消えることを確認した。purpleMIXは作者配布のv1.11で、5KEYSのスクラッチと、1Pターンテーブルを右に設定した10KEYSの両スクラッチ・鍵盤の描画を確認した。実機での手動プレイは未実施。
