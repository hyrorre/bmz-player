# コース中の単曲リザルトでBMZ メニューの設定変更を制限

対象は `main` の `3bbcf610` です。コース中の単曲リザルトは通常の単曲リザルトと同じ `Result` を使うため、BMZ メニューでプレイ設定やRandom Trainerを操作できました。

アプリ側でコース中の単曲リザルトを判定し、BMZ メニューには設定を変更できない旨を表示します。設定ページのウィジェットは組み立てず、遷移時にキーコンフィグの割り当て待ちを解除します。F1のIRランキングとデバッグ表示は利用できます。コース中の最終曲やFAILEDの単曲リザルトにも適用し、コース総合リザルトでは編集を再開できます。[設定画面の仕様](../../docs/settings.md#構成)

## 検証

- `cargo fmt --check`、`cargo check -p bmz-player --locked`、`cargo clippy -p bmz-player --all-targets --locked -- -D warnings` が通過しました。
- eguiで設定ページを開いた状態の回帰テストを追加しました。コース中の単曲リザルトに入るとデバッグ表示以外のページ本体が組み立てられず、コース総合リザルトに移ると再び表示されることを確認しました。関連テスト10件が通過しました。
- LinuxのXvfbとVulkanソフトウェアレンダリングで、同梱サンプル譜面を使った2曲コースをAutoplayで完走しました。「プレイ」ページを開いたまま進め、単曲リザルトでは変更不可の案内が表示され、総合リザルトでは設定項目が戻ることを画面で確認しました。
- 既定の英語ロケールで失敗した選曲・設定のテスト4件は、修正前の `main` でも再現しました。同梱スキンのsubmoduleを初期化し、修正ブランチで `LANGUAGE=ja_JP cargo test -p bmz-player --locked -- --test-threads=4` を実行しました。ライブラリテストは3,431件通過し、69件が既定で対象外でした。
