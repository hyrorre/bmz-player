# 共通・選曲のキー設定を統合（#109）

BMZ メニューと選曲画面の設定フォルダで、2つのカテゴリを「共通・選曲」ページにまとめた。
共通欄にはE1〜E4と、撮影・IRを開く・曲と譜面のお気に入りを表示する。
フォルダを開く／ハッシュをコピーする操作は選曲欄に置く。

既存の割り当てを使い、1P・2Pの個別設定はE1〜E4に提供する。
BMZ メニューの既定値復元は、ページ内の両方の欄から選択中のスロットの項目を戻す。
競合警告では撮影を全画面、IRを開く操作とお気に入りを選曲・リザルトに関連付ける。

操作は [キーコンフィグ](../../docs/settings.md#キーコンフィグ) と [操作ガイド](../../docs/controls.md) を参照。

Windowsでfmt、`bmz-player`のcheck、全ターゲットのClippy、全テストを確認した。
ライブラリテストは3,229件成功、89件ignore。画面の手動確認は未実施。

## 2026-11-18 一覧表示への変更

BMZ メニューと選曲画面の設定フォルダから「共通」「選曲」の見出しを取り除いた。
BMZ メニューは一つのグリッドに表示し、選曲画面は「戻る」の下に割り当て行を続けて表示する。
両方でデフォルトのキーボード割り当てを基準に、Q・W・E・R、1〜9・0、F3〜F12の順に並べる。未割り当ての項目は末尾に置く。
選曲画面のテストで、見出しがないこと、割り当ての順番、未割り当ての項目の位置を確認する。

Windowsでfmt、`bmz-player`のcheckと全ターゲットのClippyが通過した。全テストはローカルHTTP通信が可能な環境で実行し、3,327件成功、95件ignoreだった。画面の手動確認は未実施。
