# IR 監査ログテストの同時刻判定

`13f14615` の依存バージョンで `bun run test:ir:moderation` を12回実行し、BAN と解除のログが期待と逆順になる失敗を3回確認した。監査ログは `created_at` の降順で、同じミリ秒の行は UUID の降順で返る。テストは解除が常に先頭に来ると仮定していた。

テストは、対象ユーザーのログが2件であることと、各操作のレスポンスに対応するログ ID・操作種別・revision の組を検証する。関連仕様は [IR の監査ログ](../../docs/ir.md#監査ログ) を参照。

一時コピーで BAN と解除の記録時刻を同じミリ秒に固定し、UUID 降順で BAN が先になる条件を再現した。この条件で修正前のテストは失敗し、修正案で監査テスト75件が通った。通常の時計での `bun run test:ir` は272件成功。対象の Prettier と `vue-tsc --noEmit` も成功した。
