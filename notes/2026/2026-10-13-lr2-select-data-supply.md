# LR2選曲スキンへの値の供給（ゴースト・ライバル・レベルバー・履歴）

## 背景

[LR2選曲スキンの値のずれと条件の修正](2026-10-13-lr2-select-value-fixes.md) の後、
値を渡す仕組みが必要として残した項目を、BMZ内のデータの所在で分類し、次の順に対応した。

## 変更

### 描画状態へ渡すだけで済んだもの（`9185d973`）

- Play: number 150 / 151 / 155..158（自己ベスト / ターゲットのゴーストの現在進捗でのEXと率）、
  シングルプレイの2P番号（120..136）とoption 352..354（ターゲットのゴーストとの比較）。
  ターゲットはEXの線形換算だけを持つため、2Pのコンボ・判定数・ゲージは0のまま。
- Select: number 272..274（ライバルの理論値EX・レート・ノーツ数）、
  option 640..645 / 650..657（ライバルのランプ・ランク）、option 62..66（現在の設定で取れる最高ランプ）。

### 同じフォルダの各難易度（`5fbc79b2`）

- 選択中の譜面と同じ `folder_path` の譜面をライブラリから読み、難易度名でBEGINNER..INSANEに振り分け、
  譜面数・最高レベル・最良クリアを選択行のスナップショットへ渡す。
- number 45..49、option 70..79 / 500..519 / 520..565、bargraph 105..109を評価する。
  点滅しきい値はLR2の既定値（5 / 10鍵 9、7 / 14鍵 12、9鍵 42）。

### クリアオプション履歴とコースのステージレベル

- スコア履歴からオート以外のクリアを読み、LR2の `ConvertOptionHistory` と同じ規則で
  option 118..149のビットを作る。HIDDEN / SUDDENは記録されていないため、134..141は立たない。
- コース行のエントリ情報からステージのレベルを渡し、number 250..259を評価する。
- 同じフォルダの集計と履歴は選曲一覧の再読み込みで破棄する1つのキャッシュにまとめた。
  `WinitApp` のサイズ上限テスト（64 KiB）を超えたため、キャッシュはBoxで保持する。

## 未対応

IRの総プレイ回数（201）・自動更新時間（220）、ライバルのプレイ回数等（277..279）、
ライバルのIR順位（292..294）、IR状態の一部（600 / 605 / 607）、既定ターゲット率（13）、
連続コンボ・段位認定のレベル（38..40）は、元のデータがBMZに無いため対応していない。

## 検証

- bmz-skinに変換、bmz-renderに評価、bmz-playerに同フォルダ集計・履歴集計（DB）と
  コース行のスナップショットの回帰テストを追加した。
- `cargo fmt --check`、`cargo clippy --workspace --all-targets --locked -- -D warnings`、
  `cargo test --workspace --locked --no-fail-fast` は成功。
- GPUでの実画面確認、実際の選曲操作での同フォルダ集計の負荷確認は未実施。
