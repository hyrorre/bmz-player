# 選曲のスライダードラッグと同梱スキンのクリック座標

Luxez-Flat Select の IR ランキングで、見えているつまみの中心からクリック判定が32 px下にずれていました。beatoraja はボタンを押した後の移動でもスライダーを判定するため、最初の押下が範囲外でも、そのまま範囲に入ると操作できます。

BMZ の Select では、左ボタンを押したまま判定範囲に入った時点でドラッグを開始します。開始後は同じ表示先のスライダーが移動方向に沿って追従し、端に達すると止まります。操作中のスライダーは、同じ種別の別のスライダーの上を通っても切り替わりません。操作は左ボタンを離すか、ウィンドウを離れた時点で終了します。

- Luxez-Flat は `upstream` の `088c18b` を基点に、Select の曲リスト、IR の SCORE WINDOW と IR DATA、通常・コース Result の IR で、判定の始点をつまみの中心へ32 px上げました。本家向けの修正は `b454487`、`main` へのマージは `7f113ed` です。
- mz-select は本家 m-select を初回取り込みした `e56cf2de000b169a5047995c4f89a71fd00cd58a` を `upstream` にしました。曲リスト、Result IR、スキン設定で、判定範囲の上下を11 pxずつ狭め、つまみの中心の移動範囲に揃えました。本家向けの修正は `b75fbcb`、`main` へのマージは `1b5a853` です。

Windows の非表示ウィンドウで、範囲外からのドラッグ開始、同種スライダーとの区別、範囲外での追従と端での停止、再進入、解放を回帰テストで確認しました。両スキンは素材画像からつまみの中心を確認し、8箇所の座標の照合と、修正ブランチおよびマージ後の LuaJ 構文検査を行いました。実画面での手動操作は未確認です。

整形、ワークスペースの型検査と全ターゲットの Clippy が通りました。ワークスペースの通常テストでは、LR2 の常時表示スライダーに非表示を期待した検査が1件失敗しました。その検査を削除して該当テストを再実行し、通過を確認しました。

その後のレビューで、Result のスライダーも押下時の表示先をつかみ、範囲外で追従して端で止まるようにしました。判定範囲を狭めた同梱スキンの IR スクロールで、速く動かしても端まで届きます。
