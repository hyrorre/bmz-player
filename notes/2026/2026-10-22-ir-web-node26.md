# IR WebのNode.js 26移行の影響調査

2026-10-22に、IR Webのローカル開発環境をNode.js 24から26へ上げる影響を調べた。基点は `a7615105`。
同じ調査の途中で見つけたdev SSRの問題は [別の記録](2026-10-22-ir-web-dev-ssr-i18n.md) にまとめた。
IR Webの構成と検証コマンドは [IR](../../docs/ir.md) を参照する。

## 前提

- 本番はCloudflare Workers（workerd）で動くので、Nodeのバージョンは関係しない。
  Nodeを使うのはローカルのbuildと開発ツールだけである。
- `bun run` と `bunx` は、`#!/usr/bin/env node` を持つCLIをPATH上の `node` で起動する。
  `nuxt`、`wrangler`、`vue-tsc`、`scripts/generate-web-license-report.mjs` はNode 26で動き、
  `bun test` はBunのruntimeで動く。
- リポジトリには `engines`、`.nvmrc`、`packageManager` などのNodeのバージョン指定はない。
- 日程（nodejs/Releaseのschedule.json）: Node 24は2026-10-20からMaintenance、Node 26は2026-10-28にActive LTSになる。

## 調査結果

- インストール済みの1007パッケージに、Node 26を除外する `engines` はなかった。
  nuxt 4.4.8は `>=26.0.0` を明記しており、wranglerとminiflareは `>=22` を指定している。
- ネイティブアドオンはすべてN-APIなので、`NODE_MODULE_VERSION` 147になっても再ビルドは不要だった。
- Node 25/26で削除・変更されたAPI（`SlowBuffer`、`_stream_*`、`fs.F_OK` 系、`writeHeader`、
  `type: "module"` のextensionlessなCJS、`localStorage`、`Temporal`、Corepackの同梱終了）に、
  実際に壊れる使い方はなかった。
- Node 24とNode 26で `bun run build` した出力は、build ID、timestamp、並び順を除いて同じだった。
- Node 26でだけ出た差分は、`@tailwindcss/node` 4.3.0の `module.register()` が出すDEP0205の警告1件だった。

## tailwind系の更新

- `bun update tailwindcss @tailwindcss/vite @tailwindcss/postcss @tailwindcss/node @tailwindcss/oxide postcss` を実行した。
  tailwind系はすべて4.3.3になり、4.3.0の入れ子のコピーはなくなった。
  4.3.1以降の `@tailwindcss/node` はNode 26で `registerHooks` を使う。
- `@tailwindcss/postcss` 4.3.3は `postcss ^8.5.16` を要求する。postcssを一緒に更新しないと、
  8.5.31と8.5.15が並ぶため、postcssも8.5.31の1つにまとめた。
- `bun update` の仕様で、`package.json` の `tailwindcss` の下限が `^4.3.1` から `^4.3.3` に上がった。
- 生成CSSの差分:
  - `m-0`、`m-1` などのspacingが `0` や `var(--spacing)` の形になった（値は同じ）。
  - Firefoxのiframeの `:-moz-focusring` が変わった。
  - `--font-sans` の既定スタックが明示的なプラットフォームフォントになった。
    サイト本文のフォントは `bmz-ir-web/app/app.css` の `--default-font-family` で指定しているので変わらない。
    `--font-sans` を使うのはNuxt UIの `UKbd`（`font-sans` クラス）だけである。
- Web依存ライセンスのレポートの差分は、tailwindcssの版表記だけだった。

## 検証

macOSのNode 26.12.0で確認した。

- `bun run build` が成功し、DEP0205の警告は出なかった。
- devサーバーで `/`、`/en`、`/charts`、`/manual` が200を返し、スタイルが当たっていることを画面で確認した。
  サーバーエラーとDEP0205は出なかった。
- `bunx vue-tsc --noEmit`、`bun run test:ir`、`bun run test:i18n`、`bun install --frozen-lockfile`、
  `package.json` のPrettierチェックは成功した。
- `db:migrate` / `db:generate`、本番Workersへのdeploy、Windowsでのフォント表示は確認していない。
