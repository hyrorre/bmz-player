# モニター設定が再起動でプライマリに戻る問題の修正

問い合わせ: ①起動時のモニター設定がPC再起動のたびにプライマリモニターに戻る。②ボーダーレスウィンドウだと別モニターのリフレッシュレートが適用されプレイ画面がガタつく。

## 原因

- 保存値 `video.monitor_name` は「`\\.\DISPLAYn`＋仮想座標」の文字列で、DISPLAYn の番号は再起動・ドライバ更新・DisplayPort モニターの検出順で変わりうる。変わると完全一致が外れ、ログもなくプライマリへフォールバックしていた。設定の保存自体（自動保存＋atomic write）は正常だった。
- ②はアプリがボーダーレス時にレートを読む経路が無く（読むのは排他フルスクリーンのモード選択時のみ）、①で意図しないモニターに開くことが主因と判断した。切り分け用に、選択したモニターとリフレッシュレートを起動時ログへ出すようにした。

## 修正

- Windows では QueryDisplayConfig のターゲットデバイスパス（再起動しても変わらない）を識別子として保存する。照合は「デバイスパス → 従来形式の完全一致 → 座標が一意な場合の座標一致 → プライマリ＋警告ログ」の段階制にした。詳細は [設定ドキュメント](../../docs/settings.md) と [CLI ドキュメント](../../docs/cli-overrides.md)。
- 一致した場合はメモリ上の設定値を新しい識別子へ移行し、次の設定保存で永続化する。識別子の取得に一時的に失敗した状態では、保存済みのデバイスパスを従来形式へ退行させない。
- モニターだけの変更もその場で反映するようにした（従来は次回起動まで反映されなかった）。

## 検証

- Linux VM: `cargo fmt --check`、`cargo check -p bmz-player --locked`、`cargo clippy -p bmz-player --all-targets --locked -- -D warnings` 通過。単体テストは全件 3318 passed / 30 failed で、失敗は変更前からある30件と一致（新規失敗なし）。照合・移行の新規テスト14件を含む。
- Windows ターゲットのコンパイルは、依存クレートのビルドスクリプトが Windows 用 FFmpeg を要求するためこの VM では完走できなかった。使用する windows-sys 0.61 の型・フィールド・関数シグネチャは実際のバインディングと照合済み。
- Windows 実機での確認（再起動をまたいだモニター維持、`monitors list` の出力、設定 UI での即時移動）は未実施。

## 2026-11-19 追記 同じ座標へのフォールバック時の設定保持

- `main` の `48fa06ca` を基点に確認した。起動時の移行処理が、座標一致で一時選択した別モニターのデバイスパスを `video.monitor_name` に設定し、通常終了の保存で永続化していた。保存済みのデバイスパスを更新できる条件を、選択先のデバイスパスが一致する場合に限定した。従来形式からの移行と、座標による一時的な表示は引き続き行う。現在の保存規則は [設定ドキュメント](../../docs/settings.md) を参照。
- 回帰テストでは、Aの不在時に別IDのBを座標で選択してもAの保存値を保持し、AとBの両方が列挙されるとAのIDが優先されることを確認する。修正前はBのIDへの上書きで失敗した。
- Windowsの隔離したデータディレクトリで、2台の実モニターのIDを取得した。存在しないテスト用IDとBの座標を設定すると、起動ログは `matched=Some(Position)` となり、ボーダーレスのウィンドウがBに表示された。ウィンドウを閉じた後もテスト用IDが保存されていた。Aの実IDとBの座標を設定した起動では、`matched=Some(StableId)` でAに表示され、閉じると保存座標がAの現在位置に更新された。従来形式からAへの移行と、CLIでBを一時指定した際にAの設定が保存されることも確認した。物理的な取り外しと再接続は未実施。
- Windowsで `cargo fmt --check`、`bmz-player` のbuild・check・全ターゲットClippy（`-D warnings`）と、モニター照合・CLI設定保存の16テストが通過した。全体の単体テストでは、同梱スキン未取得による失敗25件を固定リビジョンの取得後に再実行し、25件とも通過した。基点でDBスキーマが39になった後も38を期待する移行テスト5件は失敗した。
