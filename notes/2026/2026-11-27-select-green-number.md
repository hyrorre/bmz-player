# 選曲スキンの緑数字

目標緑数字283、SUDDEN+ 224、LIFT 136、HIDDEN+ 150の設定で、選曲のFloating用の式はHIDDEN+の分だけ表示時間を472 msから376 msへ縮め、緑数字226を返していた。選曲で譜面に対応するキーモードの設定を読み、設定の「ノーツ表示時間」と対応する緑数字をそのまま312・313へ渡すようにした。[表示時間の仕様](../../docs/hs.md#計算式)

手元のbeatoraja参照ソースでは、選曲の312・313は選択譜面の設定にある表示時間を参照する。Playではレーン描画が求めた現在の表示時間を、その他のシーンでは曲データがある場合にそのモードの設定値を使う。

BMZの各シーンの経路をコードで確認した。

| シーン | 312・313の取得元 |
|---|---|
| Decide | 描画用の状態は表示時間を受け取れるが、通常のDecideへの遷移では表示時間を設定しないため0になる。 |
| Play | 現在のBPM、再生速度、実効HS、SCROLL / SPEED、SUDDEN+・LIFTから求めた表示時間。HIDDEN+は描画に反映する。 |
| Result / Course Result | プロファイルで有効になっているキーモードに設定された目標緑数字。 |

Windowsで整形チェック、型検査、全ターゲットのClippyと`bmz-player`の全テストが通過した。全テストは3,478件成功、100件はignore指定。Winitを使う該当のignoreテストも個別に実行し、7鍵→14鍵→7鍵で472 ms→400 ms→472 msになることを確認した。スキンを表示した実機での目視確認は未実施。
